## Component Tree

```
LineItemsGrid                       (root — full data grid for line items)
├── LineItemsGridHeader             (column header row)
├── LineItemsGridBody               (scrollable row container; min 5 rows visible)
│   └── LineItemRow[]               (one row per line item)
│       ├── LineNumberCell          (read-only auto-assigned, monospace)
│       ├── AccountCodeInput        (5-segment chartfield code entry with auto-lookup)
│       │   └── AccountLookupHint  (auto-populated account description below input)
│       ├── CurrencySelect          (currency ID dropdown)
│       ├── DebitAmountInput        (numeric; mutually exclusive with CreditAmountInput)
│       ├── CreditAmountInput       (numeric; mutually exclusive with DebitAmountInput)
│       ├── LineDescriptionInput    (free-text per-line description)
│       ├── ReferenceNumberInput    (free-text reference)
│       └── DeleteRowButton         (removes this line item)
├── LineItemsGridFooter             (Total + Difference summary rows — RC-005 component)
│   ├── TotalRow                    (sum of all debits + sum of all credits)
│   └── DifferenceRow               (totalDebits − totalCredits; red when non-zero)
└── AddLineButton                   (appends a new empty line item)
```

## States

### LineItemRow States
| State | Visual Change | Condition |
|-------|--------------|-----------|
| Default (editable) | White background; all editable inputs active | Entry is Unposted |
| Hover | `grey50` row background | Mouse hover |
| Read-only (Posted) | All inputs replaced by read-only display; no Delete button | Entry is Posted |
| Selected | `brand.blue` left border (3px); `#EFF6FF` row background | Row is focused/active for edit |
| Error | Red border on offending input; error message shown | Validation failure on this row |

### AccountCodeInput States
| State | Visual |
|-------|--------|
| Empty | Placeholder text (monospace); no description hint visible |
| Typing | Input active; no lookup yet |
| Looking up | Spinner icon inside input; "Validating…" in description area |
| Valid | Description auto-populated below input in `grey500` |
| Invalid | Red border; "Account not found" error message |
| Disabled | `grey100` background; read-only display |

### DebitAmountInput / CreditAmountInput States
| State | Visual |
|-------|--------|
| Default | Normal input, monospace font |
| Active (has value > 0) | Bold value; sibling input dims (50% opacity, not-clickable) |
| Sibling active | Dimmed (50% opacity); pointer-events none (enforces mutual exclusion) |
| Focus | `blueActive` border ring |
| Error | Red border + error message |
| Disabled (Posted) | `grey100` background |

### TotalRow / DifferenceRow States
| State | Visual |
|-------|--------|
| Balanced | Difference row: `grey900` text |

## Validation Rules
| Rule | Detail |
|------|--------|
| Account code format | Must be 5-segment `S1-S2-S3-S4-S5`; validated via GET /accounts/{accountCode} on blur |
| Account description | Must be populated after code entry; blocks save if code is invalid |
| Debit/Credit exclusion | Exactly one of debitAmount or creditAmount may be > 0 per row; both cannot be populated simultaneously |
| At least one non-zero | Each line must have either debit > 0 or credit > 0 |
| Account lookup timing | Response must arrive within 500ms (RC-004 NFR) |
| Min visible rows | Grid must show at least 5 rows without scrolling at 1280×800 |
| Scroll support | Grid container scrolls vertically when lines exceed visible area |
| Post restriction | No add/delete when entry is Posted (RC-004 security NFR) |

## Accessibility
| Requirement | Implementation |
|-------------|---------------|
| Keyboard navigation | Tab moves between cells; Enter/Space activates editable cells; arrow keys navigate within grid |
| ARIA grid role | `role="grid"` on table; `role="row"` on rows; `role="gridcell"` on cells |
| Column headers | `<th scope="col">` for all header cells |
| Summary rows | TotalRow and DifferenceRow use `role="row"` with `aria-label="Totals"` / `aria-label="Difference"` |
| Account lookup | Live region (`aria-live="polite"`) announces description when auto-populated |
| Mutual exclusion | When one amount field is disabled due to sibling value, `aria-disabled="true"` and a descriptive `aria-label` |
| Delete button | `aria-label="Delete line [lineNumber]"` on each delete button |
| Add line button | Descriptive `aria-label="Add a new line item"` |
| Read-only mode | Grid cells in Posted mode use `aria-readonly="true"` |
| Contrast | All numeric/text cell content meets WCAG AA 4.5:1 |
