## Component Tree

├── FirstButton                     (|◀ navigate to first record)

## Components

### RecordNavigationToolbar
| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| currentJournalId | `number` | Yes | — | Currently displayed journal entry ID |
| firstJournalId | `number \| null` | Yes | — | From GET /journal-entries/{journalId}/navigation; null = already first |
| previousJournalId | `number \| null` | Yes | — | null = already first |
| nextJournalId | `number \| null` | Yes | — | null = already last |
| lastJournalId | `number \| null` | Yes | — | null = already last |
| isFirst | `boolean` | Yes | — | True when current is the first entry in set |
| isLast | `boolean` | Yes | — | True when current is the last entry in set |
| isLoading | `boolean` | No | `false` | Shows loading spinner on active navigation button during data fetch |
| onNavigate | `(journalId: number) => void` | Yes | — | Callback with target journalId when a navigation button is clicked |

### NavigationButton (internal — used by all four buttons)
| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| direction | `"first" \| "previous" \| "next" \| "last"` | Yes | — | Which navigation direction this button represents |
| targetJournalId | `number \| null` | Yes | — | Null disables the button; otherwise passes to onNavigate |
| disabled | `boolean` | Yes | — | True at boundaries (first/last) |
| isLoading | `boolean` | No | `false` | Shows spinner when this direction is the active navigation in progress |
| onClick | `(journalId: number) => void` | Yes | — | Click handler |

## States

### RecordNavigationToolbar States
| State | Visual Change | Condition |
|-------|--------------|-----------|
| Mid-set (default) | All four buttons enabled | Current is neither first nor last |
| At first record | First and Previous buttons disabled (greyed out, not clickable) | `isFirst === true` |
| At last record | Next and Last buttons disabled | `isLast === true` |
| Single record | All four buttons disabled | `isFirst && isLast` (only one entry in set) |
| Loading | Active direction button shows spinner; all four buttons non-interactive during fetch | `isLoading === true` |

### NavigationButton States
| State | Visual |
|-------|--------|
| Default (enabled) | Icon button; `grey700` icon; hover background `grey100` |
| Disabled | `grey400` icon; 50% opacity; `cursor: not-allowed` |
| Hover (enabled) | `grey200` background; icon colour darkens to `grey900` |
| Active / focus | `blueActive` focus ring (2px, 2px offset) |
| Loading | Spinner replaces icon; button non-interactive |

## Validation Rules
| Rule | Detail |
|------|--------|
| Disabled at boundary | First/Previous disabled when `isFirst === true`; Next/Last disabled when `isLast === true` |
| Navigation loads full entry | Clicking a navigation button triggers GET /journal-entries/{targetId} and replaces the entire form content |
| No page reload | Navigation must update form content without a full browser page reload |
| Load time | Must complete within 1 second (RC-007 NFR) |
| Icon convention | Icons follow double-arrow / single-arrow convention: ⏮ First, ◀ Previous, ▶ Next, ⏭ Last |

## Accessibility
| Requirement | Implementation |
|-------------|---------------|
| Keyboard operable | All four buttons reachable via Tab; activated by Enter or Space |
| Descriptive labels | `aria-label` on each button: "Go to first journal entry", "Go to previous journal entry", "Go to next journal entry", "Go to last journal entry" |
| Disabled state | `disabled` attribute plus `aria-disabled="true"`; button remains in Tab order as focusable for discoverability (screen reader announces it as disabled) |
| Loading state | `aria-busy="true"` on toolbar during navigation; `aria-live="polite"` region announces "Loading journal entry [number]" |
| Focus management | After navigation completes, focus moves to the journal entry page title or first header field |
| Contrast | All icon states meet WCAG AA 3:1 minimum for graphical elements |
