## Component Tree

```
AppSidebar                          (root container — left panel)
├── SidebarHeader                   (bank logo + entity name + chevron)
├── SidebarSearch                   (search input)
├── NavMenu                         (full menu tree)
│   ├── NavSection[]                (repeating top-level collapsible section)
│   │   ├── NavSectionHeader        (icon + label + expand chevron + optional alert dot)
│   │   └── NavSubItemList          (collapsed by default; expands on click)
│   │       └── NavSubItem[]        (individual sub-level link items)
└── SidebarFooter                   (entity name + entity info + chevron)
```

## Components

### AppSidebar
| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| items | `NavItem[]` | Yes | — | Full navigation tree from GET /navigation/menu |
| activeRoute | `string` | Yes | — | Current page route; used to highlight active item |

### NavItem (data shape from BFF)
| Field | Type | Description |
|-------|------|-------------|
| id | `string` | Unique item identifier |
| label | `string` | Display text |
| route | `string` | Client-side route this item navigates to |
| level | `0 \| 1` | 0 = top-level section, 1 = sub-item |
| parentId | `string \| null` | Parent section ID; null for top-level |
| alertState | `boolean` | Whether an alert indicator is shown on this item |
| enabled | `boolean` | Whether the authenticated user can access this item |

### NavSection
| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|

| isExpanded | `boolean` | Yes | — | Controlled expand/collapse state |
| isActive | `boolean` | Yes | — | True if any child or the section itself matches activeRoute |

## States

### NavSection States
| State | Visual Change | Trigger |
|-------|--------------|---------|
| Default (collapsed) | Section header visible; sub-items hidden; chevron pointing right | Initial render |
| Expanded | Sub-items visible below header; chevron rotated 90° or pointing down | User clicks section header |
| Active | Left border 3px `brand.green`; label in `brand.green` | Child item route matches `activeRoute` |
| Hover | Background `grey200` (#E5E7EB) | Mouse hover |
| Alert | Alert dot (8px circle, `brand.greenLight`) visible beside label | `alertState === true` |
| Disabled | Text in `grey400`; pointer cursor removed; no navigation on click | `enabled === false` |

### NavSubItem States
| State | Visual Change | Trigger |
|-------|--------------|---------|
| Default | Text `grey700`; regular weight | Normal |
| Active | Text `brand.green`; semibold weight | `isActive === true` |
| Hover | Background `grey200` | Mouse hover |
| Disabled | Text `grey400`; pointer cursor removed | `enabled === false` |

### SidebarSearch States
| State | Visual Change |
|-------|--------------|
| Default | Border `grey300`; placeholder `grey400` |
| Focus | Border `blueActive`; focus ring 2px `blueActive` |

## Validation Rules
| Rule | Detail |
|------|--------|
| Expand/collapse timing | Must complete within 200ms (RC-001 NFR) — use `duration.normal` (200ms) from tokens |
| Alert trigger | Source of alertState is server-provided; component treats it as a boolean flag only |
| Item access | Items with `enabled === false` must not navigate; display is pending OQ-001b resolution (hide vs grey-out) |

## Accessibility
| Requirement | Implementation |
|-------------|---------------|
| Keyboard navigation | All nav items reachable via Tab; Enter/Space activates; arrow keys navigate within list |
| ARIA roles | `<nav>` wrapping NavMenu; `<ul>` / `<li>` for item lists; `role="button"` + `aria-expanded` on section headers |
| `aria-expanded` | Section header announces expand/collapse state to screen readers |
| `aria-current="page"` | Active sub-item gets `aria-current="page"` |
| Active item announcement | Screen readers announce active item on route change |
| Focus visible | All items have visible focus ring: 2px `brand.blueActive` outline (`.focus-ring` from components.css) |
| Alert indicator | Alert dot accompanied by `aria-label` on the nav item (e.g. "Journal Entry, has notifications") |
| Contrast | `grey900` on `grey100` background = >7:1; `brand.green` on white = ~6.8:1 (WCAG AA pass) |
