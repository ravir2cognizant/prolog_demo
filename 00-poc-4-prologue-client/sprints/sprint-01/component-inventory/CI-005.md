## Component Tree

```
LineItemsGridFooter                 (grid footer — part of LineItemsGrid from CI-004)
├── TotalRow                        (sum of all debits + sum of all credits)
│   ├── TotalLabel                  ("Total" text cell)
│   ├── TotalDebitsCell             (sum of debitAmount across all lines)
│   └── TotalCreditsCell            (sum of creditAmount across all lines)
└── DifferenceRow                   (totalDebits − totalCredits)
    ├── DifferenceLabel             ("Difference" text cell)
    ├── DifferenceDebitCell         (difference value in debit column when positive)
    └── DifferenceCreditCell        (difference value in credit column when negative)
```

These components are part of `LineItemsGrid` (CI-004). They are documented separately here because RC-005 owns their behaviour specification.

## Components

### LineItemsGridFooter
| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| lines | `LineItem[]` | Yes | — | Current line items; totals calculated from this array client-side |
| serverTotals | `JournalTotals \| null` | No | `null` | Server-computed totals from GET /journal-entries/{journalId}; used on initial load |

### JournalTotals (from BFF response)
| Field | Type | Description |
|-------|------|-------------|
| totalDebits | `number` | Server-computed sum of debit amounts |
| totalCredits | `number` | Server-computed sum of credit amounts |
| difference | `number` | totalDebits minus totalCredits |

### TotalRow
| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| totalDebits | `number` | Yes | — | Computed total debits |
| totalCredits | `number` | Yes | — | Computed total credits |

### DifferenceRow
| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| difference | `number` | Yes | — | totalDebits minus totalCredits |
| isUnbalanced | `boolean` | Yes | — | True when `difference !== 0`; triggers visual warning |

## States

### TotalRow States
| State | Visual Change |
|-------|--------------|
| Default | `grey100` background; `grey900` text; `semibold` font weight |
| Loading (initial fetch) | Skeleton placeholder cells |

### DifferenceRow States
| State | Visual Change | Condition |
|-------|--------------|-----------|
| Balanced | `grey900` text; shows `$0.00` | `difference === 0` |
| Unbalanced | `#DC2626` (red) text; non-zero amount shown | `difference !== 0` |

### Real-time Update Behaviour
| Event | Component Response |
|-------|--------------------|
| Line item added | Footer recalculates immediately from local state; no server round-trip |
| Line item edited (debit/credit) | Footer recalculates on every keypress |
| Line item deleted | Footer recalculates immediately |
| Entry saved | `serverTotals` prop refreshes from save response; client totals sync |

## Validation Rules
| Rule | Detail |
|------|--------|
| Real-time recalculation | Must update within 100ms of any line item change (RC-005 NFR) — client-side only |
| Display format | All monetary amounts formatted as currency with two decimal places (e.g. `$1,435.00`) |
| Balanced flag (header) | The `balanced` field on the header (`BalancedIndicator` in CI-002) is server-refreshed on save; the footer DifferenceRow is client-calculated in real-time — these may temporarily differ before save (OQ-001b) |
| Difference $0.00 | When `totalDebits === totalCredits`, DifferenceRow shows `$0.00` in default (non-red) style |

## Accessibility
| Requirement | Implementation |
|-------------|---------------|
| Summary rows | TotalRow has `aria-label="Total debits and credits"` on the row; DifferenceRow has `aria-label="Balance difference"` |
| Screen reader announcement | DifferenceRow wraps value in `aria-live="polite"` region so screen readers announce when balance changes |
| Unbalanced state | Color change alone is not sufficient; DifferenceRow also includes a visually-hidden `sr-only` text "unbalanced" when `isUnbalanced === true` |
| Contrast | Red (#DC2626) on white background = 5.74:1 — meets WCAG AA |
| Role | `role="row"` on both TotalRow and DifferenceRow; `role="cell"` on each cell |
