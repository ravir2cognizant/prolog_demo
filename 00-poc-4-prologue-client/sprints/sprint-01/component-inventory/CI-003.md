## States

### JournalEntryForm States
| State | Visual Change | Condition |
|-------|--------------|-----------|
| Create mode | All editable fields empty; CompanyIdSelect enabled; Save enabled | `mode === "create"` |
| Edit — Unposted | Editable fields populated from journalEntry; CompanyIdSelect disabled (pending OQ-004b) | `mode === "edit"` and `status === "Unposted"` |
| Edit — Posted | All fields read-only; Save button hidden or disabled | `mode === "edit"` and `status === "Posted"` |
| Saving | Save button shows spinner; form fields disabled | `isSaving === true` |
| Validation error | Error message below offending field; field border red | Any field fails validation on submit attempt |

## Validation Rules
| Field | Rule | Error Message |
|-------|------|---------------|
| Company ID | Required; must be non-empty | "Company is required" |
| Journal Entry Type | Required; must be non-empty | "Journal entry type is required" |
| Transaction Date | Required; must be a valid date | "Transaction date is required" |
| Description | Required; max 500 chars (pending OQ-005) | "Description is required" / "Description must be 500 characters or fewer" |
| Auto Reversal Date | Optional; if provided must be a valid date on or after Transaction Date | "Auto reversal date must be on or after transaction date" |
| Allocation Method ID | Optional; no format constraint defined in RC | — |
| Form save blocked | Entry status is "Posted" | No save possible; form renders in read-only mode |

## Accessibility
| Requirement | Implementation |
|-------------|---------------|
| Label association | All inputs use `<label htmlFor>` pattern; labels visible (not placeholder-only) |
| Required fields | `aria-required="true"` on required inputs; asterisk (*) in label for visual users |
| Error association | Error messages linked via `aria-describedby` to their input field |
| Keyboard submit | Form submits on Enter in single-line fields; Save button reachable via Tab |
| Focus management | On validation failure, focus moves to first errored field |
| Inline errors | Errors rendered as visible text below each field, not only as color change |
| Loading state | Save button announces "Saving" to screen readers via `aria-live="polite"` region |
| Disabled fields | `disabled` attribute used; screen readers announce field as unavailable |
| Contrast | All label/field text combinations meet WCAG AA 4.5:1 minimum |
