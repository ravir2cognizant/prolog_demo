## Component Tree

```
CompanyIdSelect                     (standalone dropdown — used inside JournalEntryForm from CI-003)
├── SelectInput                     (standard HTML select or custom dropdown)
│   └── CompanyOption[]             (one option per accessible company)
└── SelectLabel                     ("Company ID" field label)
```

`CompanyIdSelect` is documented in CI-003 as a prop-level component. This CI documents it at the standalone component level for reuse across the application.

## Components

### CompanyIdSelect
| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| companies | `Company[]` | Yes | — | List from GET /reference/companies |
| value | `string` | Yes | — | Currently selected companyId |
| onChange | `(companyId: string) => void` | Yes | — | Selection callback |
| disabled | `boolean` | No | `false` | True when Company ID is locked post-creation (pending OQ-004b) |
| error | `string \| null` | No | `null` | Inline validation error |
| loading | `boolean` | No | `false` | True while company list is fetching |

### Company (data shape)
| Field | Type | Description |
|-------|------|-------------|
| companyId | `string` | Company code (e.g. "0004") |
| companyName | `string` | Company name (e.g. "0004_company") |
| displayLabel | `string` | Combined: "{companyId} - {companyName}" |

## States

### CompanyIdSelect States
| State | Visual Change | Condition |
|-------|--------------|-----------|
| Default | Standard select with `grey300` border; chevron icon right | Unfocused, unselected |
| Open | Dropdown expanded; options list visible; border `blueActive` | User clicks/opens dropdown |
| Selected | Shows `displayLabel` of selected company; chevron indicates closed | Value is set |
| Focus | `blueActive` 2px border; focus ring | Keyboard or click focus |
| Hover | `grey400` border | Mouse hover |
| Error | `#DC2626` border; error message below | Validation failure (empty on submit) |
| Disabled | `grey100` background; `grey400` text; `cursor: not-allowed` | `disabled === true` (post-creation lock pending OQ-004b) |
| Loading | Spinner inside dropdown; options not yet available | `loading === true` |

### CompanyOption
Each option displays `displayLabel` (e.g. "0004 - 0004_company") — truncation avoided where possible (RC-008 usability NFR).

## Validation Rules
| Rule | Detail |
|------|--------|
| Required on create | Company must be selected before journal entry can be saved |
| Locked after creation | Company ID disabled post-creation pending OQ-004b resolution; design defaults to locked |
| Dropdown population timing | Must populate within 500ms of form load (RC-008 NFR) |
| Access filtering | Server provides only companies the user is authorised to access; no client-side filtering needed |
| Display format | Must show "code - name" format exactly, not code-only or name-only |

## Accessibility
| Requirement | Implementation |
|-------------|---------------|
| Label | `<label htmlFor>` pointing to the select element; visible label text "Company ID" |
| Keyboard access | Native `<select>` is keyboard-accessible by default; custom dropdown must implement `aria-haspopup="listbox"`, `role="listbox"`, `role="option"` |
| Error message | `aria-describedby` links error message to the select |
| Required | `aria-required="true"` on the select element |
| Disabled | `disabled` attribute; screen reader announces "Company ID, unavailable" when locked |
| Loading | `aria-busy="true"` + loading spinner with `aria-label="Loading companies"` |
| Contrast | Selected value text `grey900` on `white` = >10:1; disabled text `grey400` on `grey100` = 2.85:1 (acceptable for disabled state, WCAG 1.4.3 exemption) |
