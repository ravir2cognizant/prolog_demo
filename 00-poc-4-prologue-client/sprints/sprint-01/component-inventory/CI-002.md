## States

### JournalEntryHeader States
| State | Visual Change | Condition |
|-------|--------------|-----------|
| Unposted | Status badge amber/yellow; Posted Date/Time and Poster User ID show em-dash | `status === "Unposted"` |
| Posted | Status badge green; Posted Date/Time and Poster User ID populated | `status === "Posted"` |
| Loading | Skeleton placeholders in all fields | Data fetch in progress |

### ReadOnlyField States
| State | Visual Change |
|-------|--------------|
| Default | `grey100` background; `grey700` text; `grey200` border |
| Null/empty | Em-dash (`—`) displayed; text in `grey400` |

### StatusBadge States
| State | Background | Text Color |
|-------|-----------|------------|
| Unposted | `#FEF3C7` (amber-100) | `#92400E` (amber-800) |
| Posted | `#D1FAE5` (green-100) | `#065F46` (green-900) |

### BalancedIndicator States
| State | Display |
|-------|---------|
| `balanced === true` | Green badge: "Balanced" |
| `balanced === false` | Amber badge: "Unbalanced" |
| `recalculating === true` | Spinner with muted badge text |

## Validation Rules
| Rule | Detail |
|------|--------|
| All fields read-only | No field in the header view is user-editable in read mode |
| Null handling | All nullable fields must render em-dash, not empty string or "null" |
| Balanced flag | Must never render as an editable input; always a badge (HB-001 resolved) |
| Date formatting | `transactionDate` renders as locale short date; `editDateTime` renders as locale datetime |

## Accessibility
| Requirement | Implementation |
|-------------|---------------|
| Label association | Each `ReadOnlyField` wraps label in `<dt>` and value in `<dd>` within a `<dl>` description list |
| Status announcement | `StatusBadge` uses `role="status"` so screen readers announce status changes |
| Balanced indicator | `BalancedIndicator` includes `aria-label="Balanced status: [value]"` |
| Two-column layout | Implemented with CSS Grid; logical reading order matches visual order (left-to-right, top-to-bottom) |
| Contrast | `grey700` on `grey100` background meets WCAG AA; status badge colors meet WCAG AA on their backgrounds |
| Page load | Focus placed on page title or first meaningful header on navigation to journal entry |
