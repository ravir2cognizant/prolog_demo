## 1. Overview

This style system is extracted from the Fiserv Admin Tool UI screenshots provided as source material for sprint-01. It defines the canonical design language for the Prologue Client POC, covering color, typography, spacing, component states, motion, and accessibility guidance.

The Prologue GL Journal Entry module adapts this design system to a data-grid-heavy layout (two-column header + line items grid) while maintaining brand consistency with the broader Fiserv Admin Tool.

## 3. Typography

### 3.1 Font Family

**Primary:** Inter (preferred), falling back to `ui-sans-serif`, system-ui, Segoe UI, Roboto, Arial.

The Fiserv Admin Tool uses a neutral, humanist sans-serif throughout. Inter is the closest open-source match to the observed typeface. All body text, navigation items, form labels, and UI elements use this family.

**Monospace:** `ui-monospace`, Cascadia Code, Source Code Pro, Menlo, Consolas.

Use the monospace family for: GL chartfield account codes (5-segment format), journal numbers, numeric reference data where column alignment matters.

## 6. Motion

**Principle:** Motion should be fast and purposeful. No decorative animations.

| Category | Duration | Easing | Usage |
|----------|----------|--------|-------|
| Micro | 150ms | ease | Button hover, input focus |
| Standard | 200ms | ease | Nav expand/collapse (RC-001 requires <200ms), tab switches |
| Enter | 300ms | ease-out | Modal/panel slide-in |
| Exit | 200ms | ease-in | Modal/panel slide-out |

**Accessibility:** All animated transitions must respect `prefers-reduced-motion`. When the media query fires, set duration to 0ms or use opacity-only transitions.

## 8. Data Grid Guidance (Prologue GL)

The Prologue GL module requires a data grid for journal entry line items. The following style guidance bridges the Admin Tool design language to a grid context:

- **Grid header row:** `grey100` background, `grey900` text, `sm` (14px) / semibold, `grey200` bottom border
- **Grid data row:** `white` background, `grey900` text, `sm` / regular, `grey200` bottom border
- **Grid row hover:** `grey50` background
- **Grid selected row:** `brand.blue` left border (3px), `#EFF6FF` row background (Tailwind blue-50)
- **Grid footer (totals):** `grey100` background, `grey900` text, semibold; separated by `grey200` top border
- **Debit/Credit inputs:** monospace font for numeric entry; mutually exclusive per row (enforce via UI state)
- **Difference row when non-zero:** `#DC2626` text color to highlight imbalance (per RC-005 usability NFR)

## 10. Accessibility Rules

1. **Color contrast:** All text must meet WCAG 2.1 AA (4.5:1 for body text, 3:1 for large text). The `brand.navy` header with white text (~12:1) and `brand.green` button with white text (~6.8:1) meet this standard.
2. **Focus visible:** All interactive elements must have a visible focus ring (2px `blueActive` ring with 2px offset).
3. **Screen reader:** Status, labels, and error messages must use semantic HTML or ARIA. The grid Total/Difference rows must use `role="row"` with accessible `aria-label`.
4. **Keyboard navigation:** All interactive elements reachable by Tab; navigation sidebar and data grid fully keyboard-navigable (RC-001, RC-004 NFRs).
5. **Reduced motion:** Wrap all CSS transitions in `@media (prefers-reduced-motion: no-preference)`.
