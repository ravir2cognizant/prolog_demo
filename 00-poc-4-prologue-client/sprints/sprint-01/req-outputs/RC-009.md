## User Story
As a General Ledger accountant,
I want to attach or reference a source document to a journal entry,
So that the transaction has supporting documentation for audit and compliance purposes.

## Functional Requirements
1. The journal entry header must include a Source Document field that allows a document to be referenced or attached.
2. The Source Document field must display an icon indicating document attachment or linking capability.
3. The referenced source document must be persisted with the journal entry.
4. The attachment mechanism (file upload vs. reference code vs. external system link) is pending clarification — see OQ-011.

## Acceptance Criteria
1. Given the journal entry header is displayed, when the form is rendered, then the Source Document field is visible with its associated icon.
2. Given a source document has been attached or referenced, when the header is displayed, then the Source Document field shows the reference or attachment indicator.
3. Given no source document is attached, when the header is displayed, then the Source Document field is shown as empty — it is not hidden.
