## User Story
As a General Ledger accountant,
I want to see real-time running totals of debits and credits with a difference indicator,
So that I can identify and correct any imbalance before submitting the journal entry for posting.

## Functional Requirements
1. The line-items grid must display a "Total" footer row showing the sum of all Debit amounts and the sum of all Credit amounts across all lines.
2. The line-items grid must display a "Difference" footer row showing the result of (Total Debits − Total Credits).
3. The Total and Difference rows must update in real time as the user adds, edits, or deletes line items — they must not require a page reload or manual refresh.
4. When Total Debits equal Total Credits, the Difference must display as $0.00.
5. When Total Debits do not equal Total Credits, the Difference must display the non-zero imbalance amount.
6. The Total and Difference rows must be visually separated from the data rows (e.g. by a horizontal rule, bold formatting, or a distinct row style).
7. The journal entry header must display a read-only "Balanced" indicator that is system-calculated and reflects whether the system has determined the entry is balanced. This field is NOT user-editable. The recalculation trigger (e.g. on save, on demand) is pending OQ-001b.

## Acceptance Criteria
1. Given a journal entry with line items, when the grid is displayed, then a "Total" row appears at the bottom showing the sum of all Debit values and the sum of all Credit values.
2. Given a journal entry with line items, when the grid is displayed, then a "Difference" row appears below the Total row showing Debit total minus Credit total.
3. Given the user adds a new line item with a debit of $100.00, when the line is entered, then the Total Debit updates immediately to include the new amount.
4. Given Total Debits equal Total Credits, when the grid is displayed, then the Difference row shows $0.00.
5. Given Total Debits do not equal Total Credits, when the grid is displayed, then the Difference row shows the non-zero difference amount.
6. Given the user deletes a line item, when the deletion is applied, then the Total and Difference rows immediately reflect the removal.

## Non-Functional Requirements
| Category      | Requirement                                                              |
|---------------|--------------------------------------------------------------------------|
| Performance   | Total and Difference recalculation must complete within 100ms of any line item change. |
| Security      | No special access requirement — balance display is part of the entry view. |
| Accessibility | The Total and Difference rows must be labelled accessibly so screen readers announce them as summary rows. |
| Usability     | The Difference row must be visually distinct when non-zero (e.g. red colour or warning icon). |
| Other         | No additional non-functional requirements identified in source.          |
