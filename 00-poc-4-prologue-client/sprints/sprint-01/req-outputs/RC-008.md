## User Story
As a General Ledger accountant,
I want to select the company or entity context for a journal entry,
So that transactions are recorded against the correct organisational entity.

## Functional Requirements
1. The journal entry header must include a Company ID field that allows the user to select from available companies.
2. Company ID must be presented as a dropdown control populated with companies available to the authenticated user.
3. Each company in the dropdown must display the company code and company name together (e.g. "0004 - 0004_company").
4. The selected Company ID must be stored on the journal entry and used to scope all related data (accounts, posting rules, etc.).
5. The system must support multiple company codes (multi-company architecture is implied by the "0004" code prefix in the source).

## Acceptance Criteria
1. Given the journal entry form is open, when the Company ID dropdown is rendered, then it lists all companies the authenticated user has access to, each showing "code - name" format.
2. Given the user selects a company from the dropdown, when the selection is confirmed, then the Company ID field displays the selected "code - name" and the entry is scoped to that company.
3. Given Company ID "0004" is selected, when the header is displayed, then the field shows "0004 - 0004_company".
4. Given the system has multiple companies, when the dropdown is opened, then more than one company option is available for selection.

## Non-Functional Requirements
| Category      | Requirement                                                             |
|---------------|-------------------------------------------------------------------------|
| Performance   | Company dropdown must populate within 500ms of form load.               |
| Security      | Dropdown must only list companies the authenticated user is authorised to access. |
| Accessibility | Dropdown must be keyboard-accessible and labelled "Company ID".         |
| Usability     | Company name must be clearly readable in the dropdown — truncation should be avoided where possible. |
| Other         | No additional non-functional requirements identified in source.         |

## UI Components Affected
- Company ID dropdown in journal entry header

## BFF Endpoints Needed
