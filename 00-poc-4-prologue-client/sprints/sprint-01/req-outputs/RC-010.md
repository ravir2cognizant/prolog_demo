## User Story
As a General Ledger accountant,
I want to import journal entry data from an external source via a GL Import function,
So that I can bulk-load transactions without manual line-by-line entry.

## Functional Requirements
1. The journal entry header must display a "GL Import" action link or button.
2. Activating the GL Import function must initiate the import process; the full mechanism is pending OQ-012 resolution.
3. The complete functional requirements for GL Import are pending OQ-012 resolution (import file format, scope, and trigger behaviour must be confirmed).

## Acceptance Criteria
1. Given the journal entry header is displayed, when the form is rendered, then a "GL Import" control is visible in the header area.
2. Given the user activates the GL Import control, when the import is initiated, then the import process begins per the mechanism defined in OQ-012.

## Non-Functional Requirements
