## User Story
As a General Ledger accountant,
I want to view the full header details of a journal entry,
So that I can review the entry's metadata, status, and context before examining its line items.

## Functional Requirements
1. The system must display a journal entry header form showing all of the following fields: Company ID, Journal Entry Type, Journal Number, Status, Transaction Date, Edit Date/Time, Auto Reversal Date, Edit User ID, Description, Posting Session, Source Document reference, GL Import link, Allocation Method ID, Balanced indicator, Posted Date/Time, Poster User ID.
2. Company ID must display both the company code and company name (e.g. "0004 - 0004_company").
3. Journal Number must be displayed as a numeric identifier.
4. Status must display the current lifecycle state of the entry (e.g. "Unposted").
5. Edit Date/Time and Edit User ID must be displayed as read-only system-populated fields.
6. Posted Date/Time and Poster User ID must be empty when the entry has not been posted, and auto-populated when it has been posted.
7. All optional fields (Auto Reversal Date, Posting Session, Allocation Method ID) must be displayed in the form even when empty — they must not be hidden.
8. The Description field must display the full free-text entry label for the journal.

## Acceptance Criteria
1. Given a journal entry exists, when the user navigates to it, then all 16 header fields are visible in the form.
2. Given the entry status is "Unposted", when the header is displayed, then Posted Date/Time and Poster User ID fields are empty.
3. Given the entry has been edited, when the header is displayed, then Edit Date/Time shows the timestamp of the last edit and Edit User ID shows the user who made it.
4. Given Company ID "0004" is selected, when the header is displayed, then the field shows "0004 - 0004_company" (code + name format).
5. Given an optional field (e.g. Auto Reversal Date) has no value, when the header is displayed, then the field is shown as empty — it is not hidden or removed from the layout.
6. Given the entry status is "Unposted", when the header is displayed, then the Status field shows "Unposted".
