## User Story
As a General Ledger accountant,
I want to navigate the GL module through a hierarchical left-side menu,
So that I can access any GL function quickly without leaving the application.

## Functional Requirements
1. The application must display a persistent left-side navigation panel containing all GL module sections.
2. The navigation menu must be organised as a collapsible/expandable tree with top-level sections and nested sub-items.
3. The top-level sections must include: General Ledger (Reports, Lookups), Chartfield Processing, Account Maintenance and Inquiry, Journal Entry Financial & Statistical, Journal Entry Processing (Journal Entry Routing Process, GL Control), Accruals/Projects, Financial Report Designer, Fiscal Year / Period Control, Import Transaction Download.
4. The currently active section/page must be visually distinguished from inactive menu items (e.g. highlighted background or different text colour).
5. Individual menu items must be capable of displaying a secondary visual indicator (e.g. a distinct colour or badge) to signal a notification or alert state on that item.
6. Clicking a menu item must navigate the main content area to the corresponding GL function.
7. Sections with sub-items must expand to reveal sub-items when clicked and collapse when clicked again.

## Acceptance Criteria
1. Given the application is loaded, when the GL module is active, then the left-side navigation panel is visible and shows all required top-level sections.
2. Given the navigation tree, when a user clicks a collapsed section, then its sub-items become visible without a full page reload.
3. Given the navigation tree, when a user clicks an expanded section, then its sub-items are hidden.
4. Given the user is on the Journal Entry page, when the menu is rendered, then the "Journal Entry Financial & Statistical" item is visually distinguished as active.
5. Given a menu item has a notification/alert condition, when the menu is rendered, then that item displays a distinct visual indicator (colour or badge) different from non-alerted items.
6. Given a user clicks a menu item, when navigation completes, then the main content area displays the corresponding GL function.

## Non-Functional Requirements
