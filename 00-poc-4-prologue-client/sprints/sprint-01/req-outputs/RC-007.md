## User Story
As a General Ledger accountant,
I want to navigate between journal entries using First, Previous, Next, and Last controls,
So that I can browse entries sequentially without performing a separate search each time.

## Functional Requirements
1. The journal entry toolbar must include four navigation controls: First, Previous, Next, and Last.
2. Clicking "First" must load the first journal entry in the current navigation set into the form.
3. Clicking "Previous" must load the journal entry immediately before the current one in the navigation set.
4. Clicking "Next" must load the journal entry immediately after the current one in the navigation set.
5. Clicking "Last" must load the last journal entry in the current navigation set.
6. When the current entry is the first in the set, the "First" and "Previous" controls must be visually disabled.
7. When the current entry is the last in the set, the "Next" and "Last" controls must be visually disabled.
8. Navigating to a different entry must load that entry's full header and line items without a full page reload.

## Acceptance Criteria
1. Given the journal entry form is displayed, when the toolbar is rendered, then four navigation controls are visible: First, Previous, Next, Last.
2. Given the user clicks "Next", when the navigation completes, then the form displays the next journal entry's header and line items.
3. Given the user clicks "Previous", when the navigation completes, then the form displays the previous journal entry's header and line items.
4. Given the user clicks "First", when the navigation completes, then the form displays the first journal entry in the set and the "First" and "Previous" controls are disabled.
5. Given the user clicks "Last", when the navigation completes, then the form displays the last journal entry in the set and the "Next" and "Last" controls are disabled.
6. Given the current entry is the first in the set, when the toolbar is rendered, then the "First" and "Previous" controls are visually disabled (grayed out or non-clickable).
7. Given the current entry is the last in the set, when the toolbar is rendered, then the "Next" and "Last" controls are visually disabled.

## Non-Functional Requirements
| Category      | Requirement                                                               |
|---------------|---------------------------------------------------------------------------|
| Performance   | Navigation to the next/previous entry must complete within 1 second.      |
| Security      | Navigation must only traverse entries the authenticated user has view access to. |
| Accessibility | Navigation controls must be keyboard-operable and labelled with descriptive accessible names. |
| Usability     | Navigation arrows must match standard directional icon conventions (double-left, left, right, double-right). |
