## Endpoint Definitions

### Get Navigation Menu
| Field          | Value                                                                     |
|----------------|---------------------------------------------------------------------------|
| HTTP Method    | GET                                                                       |
| URL Path       | /navigation/menu                                                          |
| Authentication | Required (Bearer JWT)                                                     |
| Description    | Returns the full GL module navigation tree for the authenticated user, including each item's label, route, nesting level, and alert state. Items are filtered to sections the user has access to. |

#### Request Model
| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| (none) | — | — | — | No request body or query parameters. Authentication context provides user identity for access filtering. |

#### Response Model — 200 OK
| Field | Type | Description |
|-------|------|-------------|
| items | array\<NavItem\> | Ordered list of top-level navigation items |

**NavItem object:**
| Field | Type | Description |
|-------|------|-------------|
| id | string | Unique identifier for the menu item |
| label | string | Display label (e.g. "General Ledger") |
| route | string | Client-side route or URL path this item navigates to |
| level | integer | Nesting depth: 0 = top-level, 1 = sub-item |
| parentId | string \| null | ID of the parent item; null for top-level items |
| alertState | boolean | True if the item has an active alert/notification indicator |
| enabled | boolean | True if the authenticated user has access to this item |

#### Error Responses
| Status Code | Condition | Response Body |
|-------------|-----------|---------------|
| 401 | Unauthenticated | `{ "error": "Unauthorised" }` |
| 500 | Internal server error | `{ "error": "Internal server error" }` |

## Design Notes
- RC-001 OQ-001a (alert state trigger/clear) is open. The `alertState` boolean is the agreed design; the business trigger for setting it remains pending OQ-001a resolution.
- RC-001 OQ-001b (hidden vs disabled menu items) is open. The `enabled` boolean supports both behaviours; the UI decides whether to hide or grey out disabled items.
- The response is flat (level + parentId) rather than nested to keep the JSON structure simple; the client reconstructs the tree.
