## Deferred — Pending OQ-011

RC-009 (Source Document Attachment) received 4 CNCs at the T-GATE sign-off (A-02, A-03b, A-05, A-08). Endpoint design cannot proceed until OQ-011 is resolved.

**OQ-011:** What is the nature of the "Source Document" field on a journal entry?
Options under consideration:
- (a) File upload — the document is a binary attachment stored against the journal entry
- (b) Reference code — a free-text or structured reference to a document in another system
- (c) External link — a URL or deep-link to a document management system

The endpoint contract (and in some cases, the feasibility of a BFF endpoint at all) depends entirely on the resolution of OQ-011.

## Placeholder Endpoint Summary

The following is a placeholder only. Fields and HTTP methods will be finalized when OQ-011 is resolved.

| Scenario | Likely Endpoints |
|----------|-----------------|
| File upload | POST /journal-entries/{journalId}/source-document (multipart/form-data); GET /journal-entries/{journalId}/source-document; DELETE /journal-entries/{journalId}/source-document |
| Reference code | Part of PUT /journal-entries/{journalId} body (field: sourceDocument); no separate endpoint needed |
| External link | Part of PUT /journal-entries/{journalId} body (field: sourceDocumentUrl); no separate endpoint needed |
