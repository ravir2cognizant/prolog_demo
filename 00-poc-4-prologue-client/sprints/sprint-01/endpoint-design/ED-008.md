## Endpoint Definitions

### Get Companies Reference List
| Field          | Value                                                                           |
|----------------|---------------------------------------------------------------------------------|
| HTTP Method    | GET                                                                             |
| URL Path       | /reference/companies                                                            |
| Authentication | Required (Bearer JWT)                                                           |
| Description    | Returns the list of companies the authenticated user has access to, for use in the Company ID dropdown. **Shared endpoint** — also documented in ED-003 (RC-003 Create/Edit Journal Entry Header). |

#### Request Model
| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| (none) | — | — | — | No parameters. The list is filtered by the authenticated user's company access permissions. |

#### Response Model — 200 OK
| Field | Type | Description |
|-------|------|-------------|
| companies | array\<Company\> | List of accessible companies, ordered by company code |

**Company object:**
| Field | Type | Description |
|-------|------|-------------|
| companyId | string | Company code (e.g. "0004") |
| companyName | string | Company name (e.g. "0004_company") |
| displayLabel | string | Combined display label: "{companyId} - {companyName}" |

#### Error Responses
| Status Code | Condition | Response Body |
|-------------|-----------|---------------|
| 401 | Unauthenticated | `{ "error": "Unauthorised" }` |
| 500 | Internal server error | `{ "error": "Internal server error" }` |

## Design Notes
- This endpoint is identical to the one documented in ED-003. A single BFF implementation serves both RC-003 and RC-008.
- RC-008 OQ-004b (can Company ID be changed after initial save?) is open. The answer determines whether the Company ID field in the journal entry form is a one-time selection or an editable field. This does not affect the endpoint itself but will affect the PUT /journal-entries/{journalId} body in ED-003.
- The response must be populated within 500ms of form load (RC-008 performance requirement).
- Only companies the authenticated user is authorised to access must appear in the list (RC-008 security requirement).
