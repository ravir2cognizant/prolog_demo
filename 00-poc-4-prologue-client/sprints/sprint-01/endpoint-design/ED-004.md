## Endpoint Definitions

### Get Line Items for Journal Entry
| Field          | Value                                                                          |
|----------------|--------------------------------------------------------------------------------|
| HTTP Method    | GET                                                                            |
| URL Path       | /journal-entries/{journalId}/lines                                             |
| Authentication | Required (Bearer JWT)                                                          |
| Description    | Returns all line items for the specified journal entry, ordered by line number. This endpoint is available for targeted refresh scenarios; the initial page load uses the lines array embedded in GET /journal-entries/{journalId} (ED-002). |

#### Request Model
| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| journalId | integer (path) | Yes | Must be a positive integer | Parent journal entry identifier |

#### Response Model — 200 OK
| Field | Type | Description |
|-------|------|-------------|
| journalId | integer | Parent journal entry identifier |
| lines | array\<LineItem\> | All line items, ordered by lineNumber ascending |

**LineItem object:**
| Field | Type | Description |
|-------|------|-------------|
| lineId | integer | System-assigned unique line item identifier |
| lineNumber | integer | Sequential line number (1-based, auto-assigned) |
| accountCode | string | 5-segment chartfield code in format "S1-S2-S3-S4-S5" (S1 = Country; see RC-004 OQ-006 for S2–S5 meanings) |
| accountDescription | string | Account description auto-populated from account lookup |
| currencyId | string | Currency identifier (e.g. "USD"); multi-currency behaviour pending OQ-007 |
| debitAmount | number | Debit amount; 0.00 if this line is a credit line |
| creditAmount | number | Credit amount; 0.00 if this line is a debit line |
| description | string | Per-line free-text description |
| referenceNumber | string | Per-line reference number |

#### Error Responses
| Status Code | Condition | Response Body |
|-------------|-----------|---------------|
| 401 | Unauthenticated | `{ "error": "Unauthorised" }` |
| 403 | User does not have view access to this journal entry | `{ "error": "Forbidden" }` |
| 404 | Journal entry not found | `{ "error": "Journal entry not found" }` |
| 500 | Internal server error | `{ "error": "Internal server error" }` |

### Add Line Item
| Field          | Value                                                                          |
|----------------|--------------------------------------------------------------------------------|
| HTTP Method    | POST                                                                           |
| URL Path       | /journal-entries/{journalId}/lines                                             |
| Authentication | Required (Bearer JWT)                                                          |
| Description    | Adds a new line item to the specified journal entry. Only permitted on "Unposted" entries. The server auto-assigns the next sequential line number. |

#### Request Model
| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| journalId | integer (path) | Yes | Must be a positive integer | Parent journal entry identifier |
| accountCode | string | Yes | Must be non-empty; 5-segment format "S1-S2-S3-S4-S5" validated server-side | Chartfield account code |
| currencyId | string | Yes | Must match a valid currency code | Currency for this line |
| debitAmount | number | No | Must be >= 0; if provided and > 0, creditAmount must be 0 or absent | Debit amount for this line |
| creditAmount | number | No | Must be >= 0; if provided and > 0, debitAmount must be 0 or absent | Credit amount for this line |
| description | string | No | Optional free-text; max length pending OQ-005 | Per-line description |
| referenceNumber | string | No | Optional free-text | Per-line reference number |

**Mutual-exclusion rule:** At least one of `debitAmount` or `creditAmount` must be > 0. Both cannot be > 0 simultaneously.

#### Response Model — 201 Created
Returns the complete LineItem object as defined above, including the server-assigned `lineId`, `lineNumber`, and auto-populated `accountDescription`.

| Field | Type | Description |
|-------|------|-------------|
| lineId | integer | System-assigned unique identifier for the new line |
| lineNumber | integer | System-assigned sequential line number |
| accountCode | string | As submitted |
| accountDescription | string | Auto-populated from account lookup |
| currencyId | string | As submitted |
| debitAmount | number | As submitted (0.00 if not provided) |
| creditAmount | number | As submitted (0.00 if not provided) |
| description | string | As submitted |
| referenceNumber | string | As submitted |

#### Error Responses
| Status Code | Condition | Response Body |
|-------------|-----------|---------------|
| 400 | Validation failure (invalid account code, both debit and credit > 0, etc.) | `{ "error": "[message]", "field": "[fieldName]" }` |
| 401 | Unauthenticated | `{ "error": "Unauthorised" }` |
| 403 | Entry is "Posted" (no edits allowed) or user lacks edit access | `{ "error": "Forbidden" }` |
| 404 | Journal entry not found | `{ "error": "Journal entry not found" }` |
| 500 | Internal server error | `{ "error": "Internal server error" }` |

### Update Line Item

|----------------|--------------------------------------------------------------------------------|
| HTTP Method    | PUT                                                                            |
| URL Path       | /journal-entries/{journalId}/lines/{lineId}                                    |
| Authentication | Required (Bearer JWT)                                                          |
| Description    | Updates an existing line item on an "Unposted" journal entry. |

#### Request Model
| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| journalId | integer (path) | Yes | Must be a positive integer | Parent journal entry identifier |
| lineId | integer (path) | Yes | Must be a positive integer | Line item to update |
| accountCode | string | No | 5-segment format if provided | Updated chartfield account code |
| currencyId | string | No | Valid currency code if provided | Updated currency |
| debitAmount | number | No | >= 0; mutual exclusion enforced if provided | Updated debit amount |
| creditAmount | number | No | >= 0; mutual exclusion enforced if provided | Updated credit amount |
| description | string | No | Optional free-text | Updated per-line description |
| referenceNumber | string | No | Optional free-text | Updated reference number |

#### Response Model — 200 OK
Returns the complete updated LineItem object (same schema as POST 201 response).

#### Error Responses
| Status Code | Condition | Response Body |
|-------------|-----------|---------------|
| 400 | Validation failure | `{ "error": "[message]", "field": "[fieldName]" }` |
| 401 | Unauthenticated | `{ "error": "Unauthorised" }` |

### Account Code Lookup
| Field          | Value                                                                          |
|----------------|--------------------------------------------------------------------------------|
| HTTP Method    | GET                                                                            |
| URL Path       | /accounts/{accountCode}                                                        |
| Authentication | Required (Bearer JWT)                                                          |
| Description    | Validates a chartfield account code and returns its description. Used for auto-populate when user enters an account code on a line item. Response must arrive within 500ms (per RC-004 NFR). |

#### Request Model
| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| accountCode | string (path) | Yes | Must be URL-encoded if it contains hyphens | 5-segment chartfield code in format "S1-S2-S3-S4-S5" |

#### Response Model — 200 OK
| Field | Type | Description |
|-------|------|-------------|
| accountCode | string | The validated account code |
| accountDescription | string | Description / name of the account |
| isValid | boolean | True if the account code is active and valid |
| segment1 | string | Segment 1 value (Country code) |
| segment2 | string | Segment 2 value (business meaning pending OQ-006 resolution) |
| segment3 | string | Segment 3 value (business meaning pending OQ-006 resolution) |
| segment4 | string | Segment 4 value (business meaning pending OQ-006 resolution) |
| segment5 | string | Segment 5 value (business meaning pending OQ-006 resolution) |

#### Error Responses
| Status Code | Condition | Response Body |
|-------------|-----------|---------------|
| 400 | Account code format is invalid (not 5-segment) | `{ "error": "Invalid account code format", "field": "accountCode" }` |
| 401 | Unauthenticated | `{ "error": "Unauthorised" }` |
| 404 | Account code not found in system | `{ "error": "Account not found" }` |
| 500 | Internal server error | `{ "error": "Internal server error" }` |

## Design Notes
- HB-002 (chartfield S1 = Country confirmed; S2–S5 pending): The account lookup response includes individual segment fields to support future display of per-segment tooltips or validation. The full 5-segment string is accepted as-is by the API.
- OQ-006 (segment business meanings) is partially resolved. The API design is forward-compatible — segment field names will be updated when OQ-006 is fully resolved.
- OQ-007 (multi-currency per line): The `currencyId` field is included per line. The enforcement of single vs multi-currency is a server-side rule pending OQ-007 resolution.
- OQ-008 (line number renumbering after delete): The DELETE endpoint returns 204. Renumbering, if any, is a server-side concern; the GET /lines response will reflect the current state.
