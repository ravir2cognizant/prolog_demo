## Endpoint Definitions

### Get Navigation Context (Prev / Next / First / Last IDs)
| Field          | Value                                                                           |
|----------------|---------------------------------------------------------------------------------|
| HTTP Method    | GET                                                                             |
| URL Path       | /journal-entries/{journalId}/navigation                                         |
| Authentication | Required (Bearer JWT)                                                           |
| Description    | Returns the journal entry IDs for the first, previous, next, and last entries relative to the current one in the authenticated user's accessible navigation set. Null values indicate boundary conditions (current is first or last). |

#### Request Model
| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| journalId | integer (path) | Yes | Must be a positive integer | The current journal entry in the navigation set |
| sortField | string (query) | No | Allowed values: "journalNumber", "transactionDate", "editDateTime"; default: "journalNumber" (pending OQ-010 resolution) | The field used to order the navigation set |
| sortOrder | string (query) | No | Allowed values: "asc", "desc"; default: "asc" | Sort direction for the navigation set |
| companyId | string (query) | No | Must match an accessible company code if provided; default: scope to all accessible companies (pending OQ-010 resolution) | Restrict navigation to a specific company |

#### Response Model — 200 OK
| Field | Type | Description |
|-------|------|-------------|
| currentJournalId | integer | The requested journal entry ID |
| firstJournalId | integer \| null | ID of the first entry in the navigation set; null if current is already first |
| previousJournalId | integer \| null | ID of the previous entry; null if current is the first |
| nextJournalId | integer \| null | ID of the next entry; null if current is the last |
| lastJournalId | integer \| null | ID of the last entry in the navigation set; null if current is already last |
| isFirst | boolean | True if the current entry is the first in the navigation set |
| isLast | boolean | True if the current entry is the last in the navigation set |
| totalCount | integer | Total number of entries in the navigation set |

#### Error Responses
| Status Code | Condition | Response Body |
|-------------|-----------|---------------|
| 400 | Invalid journalId, sortField, or sortOrder value | `{ "error": "[message]", "field": "[fieldName]" }` |
| 401 | Unauthenticated | `{ "error": "Unauthorised" }` |
| 403 | User does not have view access to the specified journal entry | `{ "error": "Forbidden" }` |
| 404 | Journal entry not found | `{ "error": "Journal entry not found" }` |
| 500 | Internal server error | `{ "error": "Internal server error" }` |

## Design Notes
- OQ-010 (navigation scope and ordering) is open. The query parameters `sortField`, `sortOrder`, and `companyId` are included to support all likely resolutions without a breaking API change.
- Default sort is `journalNumber` ascending — this is the most predictable ordering for sequential navigation and the safest conservative default pending OQ-010 resolution.
- `isFirst` and `isLast` are derived booleans for convenience (equivalent to `previousJournalId == null` and `nextJournalId == null`), but explicit booleans improve UI code readability for enabling/disabling toolbar controls.
- `totalCount` is included to support future pagination or "entry N of M" display.
- Navigation only traverses entries the authenticated user has view access to (RC-007 security requirement).
