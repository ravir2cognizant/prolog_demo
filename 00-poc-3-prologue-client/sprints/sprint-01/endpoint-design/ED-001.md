## Endpoint Definitions

### Get Journal Entry

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /journal-entries/{id}                                  |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor        |
| Description    | Retrieve a single journal entry by ID including header fields, line items, audit fields, and current status. |

#### Request Model

| Field | Type   | Required | Validation        | Description             |
|-------|--------|----------|-------------------|-------------------------|
| id    | string | Yes      | Non-empty string  | Journal entry unique ID |

#### Response Model -- 200 OK

| Field              | Type     | Description                                              |
|--------------------|----------|----------------------------------------------------------|
| id                 | string   | Unique journal entry identifier                          |
| companyId          | string   | Company identifier                                       |
| entryType          | string   | Journal entry type code                                  |
| status             | string   | Lifecycle status: Unposted, Posted                       |
| transactionDate    | string   | Transaction date in ISO 8601 format (YYYY-MM-DD)         |
| autoReversalDate   | string   | Optional auto-reversal date (YYYY-MM-DD), null if not set|
| description        | string   | Entry description                                        |
| sourceDocument     | string   | Source document type code                                |
| allocationMethodId | string   | Optional allocation method identifier                    |
| routing            | string   | Optional routing rule or approver identifier             |
| posted             | boolean  | True when entry has been posted                          |
| postedAt           | string   | ISO 8601 timestamp of posting; null if not posted        |
| postedByUserId     | string   | User ID who posted the entry; null if not posted         |
| editedAt           | string   | ISO 8601 timestamp of last save                          |
| editedByUserId     | string   | User ID who last saved the entry                         |
| createdAt          | string   | ISO 8601 timestamp of creation                           |
| createdByUserId    | string   | User ID who created the entry                            |
| lines              | array    | Array of journal entry line objects (see ED-002)         |

#### Error Responses

| Status | Code              | Description                                  |
|--------|-------------------|----------------------------------------------|
| 401    | UNAUTHORIZED      | Missing or invalid authentication token      |
| 403    | FORBIDDEN         | User lacks permission to view this entry     |
| 404    | NOT_FOUND         | Journal entry with given ID does not exist   |
| 500    | INTERNAL_ERROR    | Unexpected server error                      |

### Create Journal Entry

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /journal-entries                                       |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | Create a new journal entry. System auto-assigns the entry ID and sets initial status to Unposted. |

#### Request Model

| Field              | Type     | Required | Validation                                 | Description                             |
|--------------------|----------|----------|--------------------------------------------|-----------------------------------------|
| companyId          | string   | Yes      | Must be in user's accessible company list  | Company identifier                      |
| entryType          | string   | Yes      | Must match a valid entry type code         | Journal entry type                      |
| transactionDate    | string   | Yes      | ISO 8601 date; must fall in an open period | Transaction date                        |
| autoReversalDate   | string   | No       | ISO 8601 date; must be after transactionDate| Auto-reversal date                     |
| description        | string   | Yes      | Max 500 characters                         | Entry description                       |
| sourceDocument     | string   | No       | Must match a valid source document code    | Source document type                    |
| allocationMethodId | string   | No       | Must reference a valid allocation method   | Allocation method identifier            |
| routing            | string   | No       | Max 100 characters                         | Routing rule or approver identifier     |
| lines              | array    | No       | Array of line objects (see ED-002)         | Journal entry line items                |

#### Response Model -- 200 OK

| Field   | Type   | Description                          |
|---------|--------|--------------------------------------|
| id      | string | System-assigned journal entry ID     |
| status  | string | Always "Unposted" on creation        |
| createdAt | string | ISO 8601 creation timestamp        |
| createdByUserId | string | User ID who created the entry |

#### Error Responses

| Status | Code                  | Description                                                     |
|--------|-----------------------|-----------------------------------------------------------------|
| 400    | VALIDATION_ERROR      | One or more request fields failed validation; details in errors array |
| 401    | UNAUTHORIZED          | Missing or invalid authentication token                         |
| 403    | FORBIDDEN             | User lacks gl-accountant permission                             |
| 422    | PERIOD_CLOSED         | Transaction date falls in a closed or undefined accounting period|
| 500    | INTERNAL_ERROR        | Unexpected server error                                         |

### Update Journal Entry Header

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | PUT                                                    |
| URL Path       | /journal-entries/{id}                                  |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | Update journal entry header fields and line items. Server sets editedAt and editedByUserId. Posted entries are rejected. |

#### Request Model

| Field              | Type     | Required | Validation                                  | Description                         |
|--------------------|----------|----------|---------------------------------------------|-------------------------------------|
| id                 | string   | Yes      | Non-empty; entry must exist and be Unposted | Journal entry ID (path param)       |
| companyId          | string   | No       | Must be in user's accessible company list   | Updated company identifier          |
| entryType          | string   | No       | Must match a valid entry type code          | Updated entry type                  |
| transactionDate    | string   | No       | ISO 8601 date; must fall in an open period  | Updated transaction date            |
| autoReversalDate   | string   | No       | ISO 8601 date; must be after transactionDate| Updated auto-reversal date          |
| description        | string   | No       | Max 500 characters                          | Updated description                 |
| sourceDocument     | string   | No       | Must match a valid source document code     | Updated source document             |
| allocationMethodId | string   | No       | Must reference a valid allocation method    | Updated allocation method           |
| routing            | string   | No       | Max 100 characters                          | Updated routing identifier          |
| lines              | array    | No       | Array of line objects (see ED-002)          | Full replacement of line items      |

#### Response Model -- 200 OK

| Field          | Type   | Description                          |
|----------------|--------|--------------------------------------|
| id             | string | Journal entry identifier             |
| editedAt       | string | ISO 8601 timestamp of this update    |
| editedByUserId | string | User ID who performed the update     |

#### Error Responses

| Status | Code                  | Description                                               |
|--------|-----------------------|-----------------------------------------------------------|
| 400    | VALIDATION_ERROR      | One or more fields failed validation                      |
| 401    | UNAUTHORIZED          | Missing or invalid authentication token                   |
| 403    | FORBIDDEN             | User lacks permission or entry is Posted                  |
| 404    | NOT_FOUND             | Journal entry not found                                   |
| 409    | ENTRY_POSTED          | Cannot edit a posted journal entry                        |
| 422    | PERIOD_CLOSED         | Transaction date falls in a closed accounting period      |
| 500    | INTERNAL_ERROR        | Unexpected server error                                   |
