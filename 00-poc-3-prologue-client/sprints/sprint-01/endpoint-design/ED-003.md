## Endpoint Definitions

RC-003 (balance totals) has no dedicated BFF endpoints. Totals are calculated client-side from line data. Server-side balance enforcement is applied in POST /journal-entries and PUT /journal-entries/{id} (ED-001) and POST /journal-entries/{id}/post (ED-004).

This ED documents the server-side validation contract for balance checks so that BFF test cases (TC-BFF-*) can reference a single authoritative specification.

### Balance Validation Contract (enforced in POST/PUT /journal-entries and POST /journal-entries/{id}/post)

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | POST                                                        |
| URL Path       | /journal-entries                                            |
| Authentication | Bearer JWT; roles: gl-accountant                            |
| Description    | Server enforces balance validation on save and post. Unbalanced entries (totalDebit != totalCredit) are rejected at the post action. The response always includes computed totals for client rendering. |

#### Request Model

Refer to ED-001 POST /journal-entries. No additional fields for balance validation.

#### Response Model -- 200 OK (balance totals extension)

These fields are appended to the standard journal entry response (ED-001) to provide server-computed totals:

| Field          | Type   | Description                                                 |
|----------------|--------|-------------------------------------------------------------|
| totalDebit     | number | Sum of all line debit amounts (2 decimal places)            |
| totalCredit    | number | Sum of all line credit amounts (2 decimal places)           |
| difference     | number | totalDebit minus totalCredit; 0.00 when balanced            |
| isBalanced     | boolean| True when difference equals 0.00                           |

#### Error Responses

| Status | Code                  | Description                                                             |
|--------|-----------------------|-------------------------------------------------------------------------|
| 400    | VALIDATION_ERROR      | One or more fields failed validation                                    |
| 422    | ENTRY_NOT_BALANCED    | Post action rejected: totalDebit does not equal totalCredit             |
| 401    | UNAUTHORIZED          | Missing or invalid authentication token                                 |
| 403    | FORBIDDEN             | User lacks required permission                                          |
| 500    | INTERNAL_ERROR        | Unexpected server error                                                 |

The ENTRY_NOT_BALANCED error response body must include:

| Field      | Type   | Description                                                        |
|------------|--------|--------------------------------------------------------------------|
| code       | string | "ENTRY_NOT_BALANCED"                                               |
| message    | string | "Journal entry is not balanced. Total debits must equal total credits." |
| totalDebit | number | Computed total debit                                               |
| totalCredit| number | Computed total credit                                              |
| difference | number | Computed difference (non-zero)                                     |
