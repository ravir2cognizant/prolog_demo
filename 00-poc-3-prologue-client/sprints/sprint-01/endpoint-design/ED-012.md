## Endpoint Definitions

### List Saved Report Designs

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /report-designs                                        |
| Authentication | Bearer JWT; roles: finance-reporting-manager           |
| Description    | List all saved financial report designs accessible to the current user. |

#### Request Model

Query parameters:

| Field  | Type   | Required | Validation | Description              |
|--------|--------|----------|------------|--------------------------|
| search | string | No       | Min 1 char | Filter by design name    |

#### Response Model -- 200 OK

| Field             | Type   | Description                                       |
|-------------------|--------|---------------------------------------------------|
| items             | array  | Array of report design summary objects            |
| items[].id        | string | Report design identifier                          |
| items[].name      | string | Report design display name                        |
| items[].createdAt | string | ISO 8601 creation timestamp                       |
| items[].updatedAt | string | ISO 8601 last-updated timestamp                   |
| items[].createdBy | string | User ID of the design creator                     |

#### Error Responses

| Status | Code           | Description                                     |
|--------|----------------|-------------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token         |
| 403    | FORBIDDEN      | User lacks finance-reporting-manager permission |
| 500    | INTERNAL_ERROR | Unexpected server error                         |

### Save New Report Design

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /report-designs                                        |
| Authentication | Bearer JWT; roles: finance-reporting-manager           |
| Description    | Save a new financial report design with selected accounts and periods. |

#### Request Model

| Field          | Type   | Required | Validation                               | Description                              |
|----------------|--------|----------|------------------------------------------|------------------------------------------|
| name           | string | Yes      | Max 200 characters; unique for user      | Report design name                       |
| description    | string | No       | Max 1000 characters                      | Optional description                     |
| rowDefinitions | array  | Yes      | At least 1 row; each row has accountId or accountGroupId | Report row definitions      |
| rowDefinitions[].label      | string | Yes | Max 200 chars                 | Row display label                        |
| rowDefinitions[].accountId  | string | No  | Valid account ID              | Account to include in this row           |
| rowDefinitions[].accountGroupId | string | No | Valid account group ID    | Account group to include in this row     |
| columnPeriods  | array  | Yes      | At least 1 period; each is a periodId   | Periods to show as report columns        |

#### Response Model -- 200 OK

| Field     | Type   | Description                              |
|-----------|--------|------------------------------------------|
| id        | string | System-assigned report design identifier |
| createdAt | string | ISO 8601 creation timestamp              |

#### Error Responses

| Status | Code              | Description                                         |
|--------|-------------------|-----------------------------------------------------|
| 400    | VALIDATION_ERROR  | One or more fields failed validation                |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token             |
| 403    | FORBIDDEN         | User lacks finance-reporting-manager permission     |
| 409    | NAME_CONFLICT     | A report design with this name already exists       |
| 500    | INTERNAL_ERROR    | Unexpected server error                             |

### Update Report Design

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | PUT                                                    |
| URL Path       | /report-designs/{id}                                   |
| Authentication | Bearer JWT; roles: finance-reporting-manager           |
| Description    | Update an existing report design definition. |

#### Request Model

Same fields as POST /report-designs. All fields are optional; provided fields replace existing values.

| Field | Type   | Required | Validation       | Description           |
|-------|--------|----------|------------------|-----------------------|
| id    | string | Yes      | Non-empty string | Design ID (path param)|

#### Response Model -- 200 OK

| Field     | Type   | Description                |
|-----------|--------|----------------------------|
| id        | string | Report design identifier   |
| updatedAt | string | ISO 8601 update timestamp  |

#### Error Responses

| Status | Code              | Description                                     |
|--------|-------------------|-------------------------------------------------|
| 400    | VALIDATION_ERROR  | Invalid field values                            |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token         |
| 403    | FORBIDDEN         | User lacks permission                           |
| 404    | NOT_FOUND         | Report design not found                         |
| 500    | INTERNAL_ERROR    | Unexpected server error                         |

### Run Report Design

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /report-designs/{id}/run                               |
| Authentication | Bearer JWT; roles: finance-reporting-manager           |
| Description    | Execute a report design and return the report data with GL balances for the defined accounts and periods. Results include allocated amounts from the Account Balance Allocation module (RC-011). |

#### Request Model

| Field         | Type   | Required | Validation                       | Description                           |
|---------------|--------|----------|----------------------------------|---------------------------------------|
| id            | string | Yes      | Non-empty; design must exist     | Design ID (path param)                |
| dataSourceType| string | No       | "operational" or "consolidated"; default "operational" | GL data source to use |

#### Response Model -- 200 OK

| Field                       | Type   | Description                                          |
|-----------------------------|--------|------------------------------------------------------|
| reportDesignId              | string | The report design identifier                         |
| generatedAt                 | string | ISO 8601 timestamp when report was generated         |
| rows                        | array  | Array of report row objects                          |
| rows[].label                | string | Row label                                            |
| rows[].values               | array  | Array of period balance values in column order       |
| rows[].values[].periodId    | string | Period identifier                                    |
| rows[].values[].periodName  | string | Period display name                                  |
| rows[].values[].balance     | number | GL balance for this account/period                   |
| rows[].values[].allocated   | number | Allocated amount included in balance                 |

#### Error Responses

| Status | Code           | Description                                     |
|--------|----------------|-------------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token         |
| 403    | FORBIDDEN      | User lacks permission                           |
| 404    | NOT_FOUND      | Report design not found                         |
| 500    | INTERNAL_ERROR | Unexpected server error                         |

### Export Report

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /report-designs/{id}/export                            |
| Authentication | Bearer JWT; roles: finance-reporting-manager           |
| Description    | Export the most recently run report to a downloadable file in the requested format. |

#### Request Model

Query parameters:

| Field  | Type   | Required | Validation             | Description           |
|--------|--------|----------|------------------------|-----------------------|
| id     | string | Yes      | Non-empty string       | Design ID (path param)|
| format | string | Yes      | "pdf" or "xlsx"        | Export file format    |

#### Response Model -- 200 OK

Binary file download. Response headers:

| Header              | Value                                               |
|---------------------|-----------------------------------------------------|
| Content-Type        | application/pdf or application/vnd.openxmlformats-officedocument.spreadsheetml.sheet |
| Content-Disposition | attachment; filename="{reportName}-{date}.{ext}"   |

#### Error Responses

| Status | Code              | Description                                     |
|--------|-------------------|-------------------------------------------------|
| 400    | VALIDATION_ERROR  | Invalid format parameter                        |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token         |
| 403    | FORBIDDEN         | User lacks permission                           |
| 404    | NOT_FOUND         | Report design not found                         |
| 500    | INTERNAL_ERROR    | Unexpected server error                         |
