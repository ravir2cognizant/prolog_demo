## Endpoint Definitions

### List Routing Rules

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /routing-rules                                         |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor        |
| Description    | List available routing rule configurations for use in the Routing field of a journal entry header. |

#### Request Model

No request body or query parameters.

#### Response Model -- 200 OK

| Field             | Type   | Description                              |
|-------------------|--------|------------------------------------------|
| items             | array  | Array of routing rule objects            |
| items[].id        | string | Routing rule identifier                  |
| items[].name      | string | Routing rule display name                |
| items[].description| string| Routing rule description                 |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 500    | INTERNAL_ERROR | Unexpected server error                  |

### Submit Journal Entry for Approval

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | POST                                                        |
| URL Path       | /journal-entries/{id}/submit-for-approval                   |
| Authentication | Bearer JWT; roles: gl-accountant                            |
| Description    | Submit an Unposted journal entry to the routing/approval workflow. Entry status transitions to a routing-pending state. |

#### Request Model

| Field | Type   | Required | Validation       | Description             |
|-------|--------|----------|------------------|-------------------------|
| id    | string | Yes      | Non-empty string | Journal entry ID (path) |

No request body required.

#### Response Model -- 200 OK

| Field          | Type   | Description                                            |
|----------------|--------|--------------------------------------------------------|
| id             | string | Journal entry identifier                               |
| status         | string | "PendingApproval"                                      |
| routingRuleId  | string | Routing rule applied to this entry                     |
| submittedAt    | string | ISO 8601 timestamp of submission                       |

#### Error Responses

| Status | Code                  | Description                                                  |
|--------|-----------------------|--------------------------------------------------------------|
| 400    | NO_ROUTING_RULE       | Entry has no Routing value set                               |
| 401    | UNAUTHORIZED          | Missing or invalid authentication token                      |
| 403    | FORBIDDEN             | User lacks permission                                        |
| 404    | NOT_FOUND             | Journal entry not found                                      |
| 409    | INVALID_STATUS        | Entry is not in Unposted status                              |
| 500    | INTERNAL_ERROR        | Unexpected server error                                      |

---

### Approve a Journal Entry

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | POST                                                        |
| URL Path       | /journal-entries/{id}/approve                               |
| Authentication | Bearer JWT; roles: gl-supervisor (designated approver)      |
| Description    | Approve a journal entry that is pending routing approval. Entry status transitions to Approved, enabling it to be posted. |

#### Request Model

| Field | Type   | Required | Validation       | Description             |
|-------|--------|----------|------------------|-------------------------|
| id    | string | Yes      | Non-empty string | Journal entry ID (path) |

No request body required.

#### Response Model -- 200 OK

| Field        | Type   | Description                                      |
|--------------|--------|--------------------------------------------------|
| id           | string | Journal entry identifier                         |
| status       | string | "Approved"                                       |
| approvedAt   | string | ISO 8601 timestamp of approval                   |
| approvedById | string | User ID of the approver                          |

#### Error Responses

| Status | Code                  | Description                                                            |
|--------|-----------------------|------------------------------------------------------------------------|
| 401    | UNAUTHORIZED          | Missing or invalid authentication token                                |
| 403    | FORBIDDEN             | User is not a designated approver for this routing rule                |
| 404    | NOT_FOUND             | Journal entry not found                                                |
| 409    | INVALID_STATUS        | Entry is not in PendingApproval status                                 |
| 500    | INTERNAL_ERROR        | Unexpected server error                                                |

### Reject a Journal Entry

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | POST                                                        |
| URL Path       | /journal-entries/{id}/reject                                |
| Authentication | Bearer JWT; roles: gl-supervisor (designated approver)      |
| Description    | Reject a journal entry pending routing approval. Entry reverts to Unposted status. Rejection reason is stored and displayed to the originator. |

#### Request Model

| Field           | Type   | Required | Validation           | Description                             |
|-----------------|--------|----------|----------------------|-----------------------------------------|
| id              | string | Yes      | Non-empty string     | Journal entry ID (path param)           |
| rejectionReason | string | Yes      | Min 1 char, max 1000 | Mandatory reason for rejection          |

#### Response Model -- 200 OK

| Field            | Type   | Description                                    |
|------------------|--------|------------------------------------------------|
| id               | string | Journal entry identifier                       |
| status           | string | "Unposted"                                     |
| rejectionReason  | string | The rejection reason stored against the entry  |
| rejectedAt       | string | ISO 8601 timestamp of rejection                |
| rejectedById     | string | User ID of the approver who rejected           |

#### Error Responses

| Status | Code                  | Description                                                  |
|--------|-----------------------|--------------------------------------------------------------|
| 400    | VALIDATION_ERROR      | rejectionReason missing or empty                             |
| 401    | UNAUTHORIZED          | Missing or invalid authentication token                      |
| 403    | FORBIDDEN             | User is not a designated approver for this routing rule      |
| 404    | NOT_FOUND             | Journal entry not found                                      |
| 409    | INVALID_STATUS        | Entry is not in PendingApproval status                       |
| 500    | INTERNAL_ERROR        | Unexpected server error                                      |

### Get Approval Queue

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | GET                                                         |
| URL Path       | /journal-entries                                            |
| Authentication | Bearer JWT; roles: gl-supervisor                            |
| Description    | Filter journal entries by pendingApproval=true to retrieve the approval queue for a specific approver. Reuses the list endpoint (ED-006) with additional filter parameters. |

#### Request Model (additional parameters for approval queue)

| Field          | Type    | Required | Validation                     | Description                                  |
|----------------|---------|----------|--------------------------------|----------------------------------------------|
| pendingApproval| boolean | No       | true to filter approval queue  | When true, return only PendingApproval entries|
| approverId     | string  | No       | Must be a valid user ID        | Filter to entries assigned to this approver  |

Refer to ED-006 for the full parameter list.

#### Response Model -- 200 OK

Refer to ED-006 response model. Status values may include "PendingApproval" and "Approved" in addition to "Unposted" and "Posted".

#### Error Responses

| Status | Code              | Description                                          |
|--------|-------------------|------------------------------------------------------|
| 401    | UNAUTHORIZED      | Missing or invalid authentication token              |
| 403    | FORBIDDEN         | User lacks gl-supervisor permission                  |
| 500    | INTERNAL_ERROR    | Unexpected server error                              |
