## Endpoint Definitions

The Financial Review screen uses GET /journal-entries (ED-006) with additional filter parameters. This ED documents the extended filtering contract and the export endpoint specific to the review screen.

### Get Journal Entries for Financial Review

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | GET                                                         |
| URL Path       | /journal-entries                                            |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor, finance-manager |
| Description    | Retrieve a filtered list of journal entries for the Financial Review screen. Supports all standard filters (ED-006) plus review-specific filters. Returns only entries for companies the user has access to. |

#### Request Model

All parameters from ED-006 apply. Additional parameters for the review screen:

| Field          | Type    | Required | Validation                      | Description                                  |
|----------------|---------|----------|---------------------------------|----------------------------------------------|
| companyId      | string  | Yes      | Non-empty; user must have access| Filter by company                            |
| fromDate       | string  | No       | ISO 8601 date                   | Filter: Transaction Date on or after         |
| toDate         | string  | No       | ISO 8601 date                   | Filter: Transaction Date on or before        |
| status         | string  | No       | Unposted, Posted, PendingApproval| Filter by entry status                      |
| entryType      | string  | No       | Valid entry type code           | Filter by journal entry type                 |
| hasOpenQuestions| boolean| No       | true or false                   | When true, return only flagged/open entries  |

#### Response Model -- 200 OK

Refer to ED-006 response model. All standard journal entry summary fields are returned, plus:

| Field                  | Type    | Description                                                 |
|------------------------|---------|-------------------------------------------------------------|
| items[].hasOpenQuestions| boolean| True when the entry has unresolved open questions or flags  |

#### Error Responses

| Status | Code              | Description                                          |
|--------|-------------------|------------------------------------------------------|
| 400    | VALIDATION_ERROR  | Invalid filter parameter values                      |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token              |
| 403    | FORBIDDEN         | User does not have access to the specified company   |
| 500    | INTERNAL_ERROR    | Unexpected server error                              |

### Export Journal Entry Review List

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | GET                                                         |
| URL Path       | /journal-entries/export                                     |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor, finance-manager |
| Description    | Export the filtered journal entry list to a downloadable file. Applies the same filter parameters as the review list endpoint. |

#### Request Model

Query parameters:

| Field     | Type   | Required | Validation                | Description                                     |
|-----------|--------|----------|---------------------------|-------------------------------------------------|
| companyId | string | Yes      | Non-empty                 | Filter by company                               |
| fromDate  | string | No       | ISO 8601 date             | Filter by Transaction Date on or after          |
| toDate    | string | No       | ISO 8601 date             | Filter by Transaction Date on or before         |
| status    | string | No       | Unposted, Posted          | Filter by status                                |
| format    | string | No       | "csv" or "xlsx"; default "csv" | Export file format                          |

#### Response Model -- 200 OK

Binary file download. Response headers:

| Header               | Value                                               |
|----------------------|-----------------------------------------------------|
| Content-Type         | text/csv or application/vnd.openxmlformats-officedocument.spreadsheetml.sheet |
| Content-Disposition  | attachment; filename="journal-entries-{date}.{ext}" |

#### Error Responses

| Status | Code              | Description                                    |
|--------|-------------------|------------------------------------------------|
| 400    | VALIDATION_ERROR  | Invalid parameter values                       |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token        |
| 403    | FORBIDDEN         | User lacks access to the specified company     |
| 500    | INTERNAL_ERROR    | Unexpected server error                        |
