## Endpoint Definitions

### Get Budget Data

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /budgets                                               |
| Authentication | Bearer JWT; roles: finance-manager                     |
| Description    | Retrieve budget amounts for a company and fiscal year in a grid-ready structure (accounts as rows, periods as columns). |

#### Request Model

Query parameters:

| Field      | Type    | Required | Validation              | Description                       |
|------------|---------|----------|-------------------------|-----------------------------------|
| companyId  | string  | Yes      | User must have access   | Company identifier                |
| fiscalYear | integer | Yes      | 4-digit year            | Fiscal year to retrieve budgets for|

#### Response Model -- 200 OK

| Field                         | Type   | Description                                              |
|-------------------------------|--------|----------------------------------------------------------|
| companyId                     | string | Company identifier                                       |
| fiscalYear                    | integer| Fiscal year                                              |
| periods                       | array  | Ordered list of period objects for this fiscal year      |
| periods[].id                  | string | Period identifier                                        |
| periods[].name                | string | Period display name                                      |
| rows                          | array  | Array of budget row objects (one per account)            |
| rows[].accountId              | string | Account identifier                                       |
| rows[].accountCode            | string | Account code                                             |
| rows[].accountDescription     | string | Account description                                      |
| rows[].budgets                | array  | Array of budget amounts, one per period in period order  |
| rows[].budgets[].periodId     | string | Period identifier                                        |
| rows[].budgets[].amount       | number | Budget amount for this account and period                |

#### Error Responses

| Status | Code              | Description                                         |
|--------|-------------------|-----------------------------------------------------|
| 400    | VALIDATION_ERROR  | Missing or invalid query parameters                 |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token             |
| 403    | FORBIDDEN         | User lacks access to the specified company          |
| 500    | INTERNAL_ERROR    | Unexpected server error                             |

### Update Budget Amounts

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | PUT                                                    |
| URL Path       | /budgets                                               |
| Authentication | Bearer JWT; roles: finance-manager                     |
| Description    | Update one or more budget amounts for a company and fiscal year. Accepts an array of account/period/amount tuples; partial updates are supported. |

#### Request Model

| Field               | Type    | Required | Validation                         | Description                           |
|---------------------|---------|----------|------------------------------------|---------------------------------------|
| companyId           | string  | Yes      | User must have access              | Company identifier                    |
| fiscalYear          | integer | Yes      | 4-digit year                       | Fiscal year                           |
| updates             | array   | Yes      | At least 1 entry                   | Array of budget update objects        |
| updates[].accountId | string  | Yes      | Valid account ID for the company   | Account to update budget for          |
| updates[].periodId  | string  | Yes      | Valid period ID for the fiscal year| Period to update budget for           |
| updates[].amount    | number  | Yes      | Non-negative                       | New budget amount                     |

#### Response Model -- 200 OK

| Field        | Type    | Description                                    |
|--------------|---------|------------------------------------------------|
| updatedCount | integer | Number of budget records updated               |
| updatedAt    | string  | ISO 8601 timestamp of the update               |

#### Error Responses

| Status | Code              | Description                                         |
|--------|-------------------|-----------------------------------------------------|
| 400    | VALIDATION_ERROR  | One or more update entries are invalid              |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token             |
| 403    | FORBIDDEN         | User lacks finance-manager permission               |
| 500    | INTERNAL_ERROR    | Unexpected server error                             |

### Import Budget Data

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /budgets/import                                        |
| Authentication | Bearer JWT; roles: finance-manager                     |
| Description    | Import budget data from an uploaded file. Validates all rows before writing. Invalid rows are reported per-row; valid rows are imported. Accepted file formats: CSV, XLSX. |

#### Request Model

Multipart form data:

| Field      | Type   | Required | Validation                         | Description                              |
|------------|--------|----------|------------------------------------|------------------------------------------|
| companyId  | string | Yes      | User must have access              | Company identifier                       |
| fiscalYear | integer| Yes      | 4-digit year                       | Target fiscal year                       |
| file       | binary | Yes      | CSV or XLSX; max 10 MB             | Budget import file                       |
| mode       | string | No       | "replace" or "merge"; default "merge" | Whether to replace all or merge with existing data |

#### Response Model -- 200 OK

| Field             | Type    | Description                                          |
|-------------------|---------|------------------------------------------------------|
| importedCount     | integer | Number of budget rows successfully imported          |
| errorCount        | integer | Number of rows with validation errors                |
| errors            | array   | Array of per-row error objects (empty if no errors)  |
| errors[].rowNumber| integer | Row number in the source file                        |
| errors[].field    | string  | Field that failed validation                         |
| errors[].message  | string  | Validation error description                         |

#### Error Responses

| Status | Code              | Description                                         |
|--------|-------------------|-----------------------------------------------------|
| 400    | INVALID_FILE      | File is not a valid CSV or XLSX format              |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token             |
| 403    | FORBIDDEN         | User lacks finance-manager permission               |
| 413    | FILE_TOO_LARGE    | Uploaded file exceeds 10 MB size limit              |
| 500    | INTERNAL_ERROR    | Unexpected server error                             |

### Export Budget Data

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /budgets/export                                        |
| Authentication | Bearer JWT; roles: finance-manager                     |
| Description    | Export budget data for a company and fiscal year as a downloadable file. |

#### Request Model

Query parameters:

| Field      | Type    | Required | Validation       | Description                     |
|------------|---------|----------|------------------|---------------------------------|
| companyId  | string  | Yes      | User must have access | Company identifier           |
| fiscalYear | integer | Yes      | 4-digit year     | Fiscal year to export           |
| format     | string  | No       | "csv" or "xlsx"; default "csv" | Export file format   |

#### Response Model -- 200 OK

Binary file download. Response headers:

| Header              | Value                                               |
|---------------------|-----------------------------------------------------|
| Content-Type        | text/csv or application/vnd.openxmlformats-officedocument.spreadsheetml.sheet |
| Content-Disposition | attachment; filename="budget-{companyId}-{fiscalYear}.{ext}" |

#### Error Responses

| Status | Code              | Description                                     |
|--------|-------------------|-------------------------------------------------|
| 400    | VALIDATION_ERROR  | Missing or invalid query parameters             |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token         |
| 403    | FORBIDDEN         | User lacks access to the specified company      |
| 500    | INTERNAL_ERROR    | Unexpected server error                         |
