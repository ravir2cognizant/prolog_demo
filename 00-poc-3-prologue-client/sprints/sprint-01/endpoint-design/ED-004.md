## Endpoint Definitions

### Post a Journal Entry

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | POST                                                        |
| URL Path       | /journal-entries/{id}/post                                  |
| Authentication | Bearer JWT; roles: gl-supervisor (post permission required) |
| Description    | Post a balanced, Unposted journal entry. Records postedAt timestamp and postedByUserId. Entry status changes to Posted. Rejected if entry is unbalanced, in a closed period, or pending routing approval. |

#### Request Model

| Field | Type   | Required | Validation       | Description             |
|-------|--------|----------|------------------|-------------------------|
| id    | string | Yes      | Non-empty string | Journal entry ID (path) |

No request body required.

#### Response Model -- 200 OK

| Field          | Type    | Description                                    |
|----------------|---------|------------------------------------------------|
| id             | string  | Journal entry identifier                       |
| status         | string  | "Posted"                                       |
| posted         | boolean | true                                           |
| postedAt       | string  | ISO 8601 timestamp of posting                  |
| postedByUserId | string  | User ID who performed the post action          |

#### Error Responses

| Status | Code                    | Description                                                                     |
|--------|-------------------------|---------------------------------------------------------------------------------|
| 400    | ENTRY_NOT_BALANCED      | totalDebit does not equal totalCredit; body includes difference detail          |
| 401    | UNAUTHORIZED            | Missing or invalid authentication token                                         |
| 403    | FORBIDDEN               | User lacks post permission                                                      |
| 404    | NOT_FOUND               | Journal entry not found                                                         |
| 409    | ALREADY_POSTED          | Entry is already in Posted status                                               |
| 422    | PERIOD_CLOSED           | Transaction date falls in a closed accounting period                            |
| 422    | PENDING_APPROVAL        | Entry is pending routing approval and cannot be posted until approved           |
| 500    | INTERNAL_ERROR          | Unexpected server error                                                         |

---

### Unpost a Journal Entry

| Field          | Value                                                          |
|----------------|----------------------------------------------------------------|
| HTTP Method    | POST                                                           |
| URL Path       | /journal-entries/{id}/unpost                                   |
| Authentication | Bearer JWT; roles: gl-supervisor (unpost permission required)  |
| Description    | Revert a Posted journal entry to Unposted status. Rejected if the entry's accounting period is closed. Clears postedAt and postedByUserId. |

#### Request Model

| Field | Type   | Required | Validation       | Description             |
|-------|--------|----------|------------------|-------------------------|
| id    | string | Yes      | Non-empty string | Journal entry ID (path) |

No request body required.

#### Response Model -- 200 OK

| Field          | Type    | Description                                    |
|----------------|---------|------------------------------------------------|
| id             | string  | Journal entry identifier                       |
| status         | string  | "Unposted"                                     |
| posted         | boolean | false                                          |
| postedAt       | string  | null (cleared)                                 |
| postedByUserId | string  | null (cleared)                                 |
| editedAt       | string  | ISO 8601 timestamp of the unpost operation     |
| editedByUserId | string  | User ID who performed the unpost action        |

#### Error Responses

| Status | Code              | Description                                                       |
|--------|-------------------|-------------------------------------------------------------------|
| 401    | UNAUTHORIZED      | Missing or invalid authentication token                           |
| 403    | FORBIDDEN         | User lacks unpost permission                                      |
| 404    | NOT_FOUND         | Journal entry not found                                           |
| 409    | NOT_POSTED        | Entry is already Unposted                                         |
| 422    | PERIOD_CLOSED     | Cannot unpost: accounting period is closed                        |
| 500    | INTERNAL_ERROR    | Unexpected server error                                           |
