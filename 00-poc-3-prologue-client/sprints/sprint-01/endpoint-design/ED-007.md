## Endpoint Definitions

RC-007 has no dedicated BFF endpoints. Audit trail fields (editedAt, editedByUserId, createdAt, createdByUserId) are set server-side and returned in the standard journal entry response (ED-001 GET /journal-entries/{id}). Clients must not send these fields; server ignores any client-supplied values.

This ED documents the audit field contract to give A-05 (backend developer) and A-08 (BFF tester) a single authoritative reference for how audit data is enforced at the API layer.

### Audit Trail Fields in Journal Entry Endpoints

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | GET                                                         |
| URL Path       | /journal-entries/{id}                                       |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor             |
| Description    | Audit fields are included in every journal entry response. The server sets editedAt and editedByUserId on every successful POST or PUT. The server sets createdAt and createdByUserId on the initial POST only. |

#### Request Model

Refer to ED-001. No audit-specific request fields.

#### Response Model -- 200 OK (audit fields)

| Field           | Type   | Description                                                         |
|-----------------|--------|---------------------------------------------------------------------|
| createdAt       | string | ISO 8601 timestamp of initial entry creation; never changes         |
| createdByUserId | string | User ID who created the entry; never changes                        |
| editedAt        | string | ISO 8601 timestamp of the most recent save (header or lines)        |
| editedByUserId  | string | User ID who performed the most recent save                          |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 403    | FORBIDDEN      | User lacks permission to view this entry |
| 404    | NOT_FOUND      | Journal entry not found                  |
| 500    | INTERNAL_ERROR | Unexpected server error                  |
