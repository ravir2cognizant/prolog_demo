## Endpoint Definitions

### List Consolidation Sources

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /consolidation/sources                                 |
| Authentication | Bearer JWT; roles: group-finance-manager               |
| Description    | List all configured consolidation source connections. |

#### Request Model

No request body or query parameters.

#### Response Model -- 200 OK

| Field              | Type   | Description                                      |
|--------------------|--------|--------------------------------------------------|
| items              | array  | Array of consolidation source objects            |
| items[].id         | string | Source identifier                                |
| items[].name       | string | Source display name                              |
| items[].sourceType | string | "database" or "file"                             |
| items[].status     | string | "Active" or "Inactive"                           |
| items[].lastRunAt  | string | ISO 8601 timestamp of last consolidation run using this source; null if never run |

#### Error Responses

| Status | Code           | Description                                       |
|--------|----------------|---------------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token           |
| 403    | FORBIDDEN      | User lacks group-finance-manager permission       |
| 500    | INTERNAL_ERROR | Unexpected server error                           |

### Add Consolidation Source

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /consolidation/sources                                 |
| Authentication | Bearer JWT; roles: group-finance-manager               |
| Description    | Add a new consolidation source connection (database connection or file import configuration). |

#### Request Model

| Field          | Type   | Required | Validation                              | Description                              |
|----------------|--------|----------|-----------------------------------------|------------------------------------------|

| id        | string | System-assigned source identifier        |

| Status | Code              | Description                                             |

| 401    | UNAUTHORIZED      | Missing or invalid authentication token                 |

### Run Consolidation

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /consolidation/run                                     |
| Authentication | Bearer JWT; roles: group-finance-manager               |
| Description    | Execute the GL data consolidation process for all active sources. Merges GL data from each source into the consolidation reporting layer, applies inter-company elimination rules, and records a run history entry. |

#### Request Model

| Field      | Type    | Required | Validation              | Description                       |
|------------|---------|----------|-------------------------|-----------------------------------|
| fiscalYear | integer | Yes      | 4-digit year            | Fiscal year to consolidate        |
| periodId   | string  | No       | Valid period ID         | Optional: restrict to a single period |

#### Response Model -- 200 OK

| Field       | Type   | Description                                              |
|-------------|--------|----------------------------------------------------------|
| runId       | string | System-assigned consolidation run identifier             |
| status      | string | "Completed", "PartialSuccess", or "Failed"               |
| startedAt   | string | ISO 8601 timestamp when run started                      |
| completedAt | string | ISO 8601 timestamp when run completed                    |
| sourceCount | integer| Number of sources processed                             |
| errorCount  | integer| Number of sources with errors                           |

#### Error Responses

| Status | Code              | Description                                         |
|--------|-------------------|-----------------------------------------------------|
| 400    | VALIDATION_ERROR  | Invalid fiscal year                                 |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token             |
| 403    | FORBIDDEN         | User lacks group-finance-manager permission         |
| 409    | RUN_IN_PROGRESS   | A consolidation run is already in progress          |
| 500    | INTERNAL_ERROR    | Unexpected server error                             |

### Get Consolidation Run Report

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /consolidation/runs/{id}/report                        |
| Authentication | Bearer JWT; roles: group-finance-manager               |
| Description    | Get the detailed report for a specific consolidation run, including per-source results and errors. |

#### Request Model

| Field | Type   | Required | Validation       | Description            |
|-------|--------|----------|------------------|------------------------|
| id    | string | Yes      | Non-empty string | Run ID (path param)    |

#### Response Model -- 200 OK

| Field                       | Type   | Description                                            |
|-----------------------------|--------|--------------------------------------------------------|
| runId                       | string | Consolidation run identifier                           |
| status                      | string | Overall run status                                     |
| fiscalYear                  | integer| Fiscal year consolidated                              |
| sources                     | array  | Array of per-source result objects                     |
| sources[].sourceId          | string | Source identifier                                      |
| sources[].sourceName        | string | Source display name                                    |
| sources[].status            | string | "Success", "PartialSuccess", or "Failed"               |
| sources[].recordsProcessed  | integer| Number of GL records processed from this source       |
| sources[].errors            | array  | Array of error objects; empty if no errors             |
| sources[].errors[].code     | string | Error code                                             |
| sources[].errors[].message  | string | Error description                                      |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 403    | FORBIDDEN      | User lacks permission                    |
| 404    | NOT_FOUND      | Consolidation run not found              |
| 500    | INTERNAL_ERROR | Unexpected server error                  |
