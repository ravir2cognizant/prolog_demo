## Endpoint Definitions

The Auto Reversal Date field is set through POST /journal-entries and PUT /journal-entries/{id} (ED-001). This ED documents the manual-trigger reversal endpoint and the scheduled-trigger contract for internal use.

### Trigger Journal Entry Reversal

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | POST                                                        |
| URL Path       | /journal-entries/{id}/reverse                               |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor; or internal service token for scheduled execution |
| Description    | Generate a reversing journal entry for the specified posted entry. Swaps debit and credit amounts on all lines, sets the reversal entry Transaction Date to the autoReversalDate (or a provided override date), and creates the reversal in Unposted status. The reversal entry Description references the originating journal entry ID. |

#### Request Model

| Field               | Type   | Required | Validation                                         | Description                                      |
|---------------------|--------|----------|----------------------------------------------------|--------------------------------------------------|
| id                  | string | Yes      | Non-empty; entry must be Posted and have an autoReversalDate or body reversalDate | Journal entry ID (path param) |
| reversalDate        | string | No       | ISO 8601 date; must fall in an open period; if omitted, autoReversalDate is used | Override reversal date |

#### Response Model -- 200 OK

| Field               | Type   | Description                                                        |
|---------------------|--------|--------------------------------------------------------------------|
| reversalEntryId     | string | System-assigned ID of the newly created reversing entry            |
| reversalEntryStatus | string | Always "Unposted"                                                  |
| reversalDate        | string | Transaction date used for the reversal entry (ISO 8601)            |
| originatingEntryId  | string | ID of the original journal entry that was reversed                 |

#### Error Responses

| Status | Code                    | Description                                                                |
|--------|-------------------------|----------------------------------------------------------------------------|
| 400    | VALIDATION_ERROR        | reversalDate provided but invalid                                          |
| 401    | UNAUTHORIZED            | Missing or invalid authentication token                                    |
| 403    | FORBIDDEN               | User lacks permission to trigger reversal                                  |
| 404    | NOT_FOUND               | Journal entry not found                                                    |
| 409    | ENTRY_NOT_POSTED        | Reversal can only be triggered for Posted entries                          |
| 409    | NO_REVERSAL_DATE        | No autoReversalDate set and no reversalDate provided in request            |
| 422    | PERIOD_CLOSED           | Reversal date falls in a closed accounting period                          |
| 500    | INTERNAL_ERROR          | Unexpected server error                                                    |
