## Endpoint Definitions

### List Accrual/Prepaid Schedules

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /accrual-schedules                                     |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | List all accrual and prepaid journal entry schedules for the current user's accessible companies. |

#### Request Model

Query parameters:

| Field     | Type   | Required | Validation      | Description                  |
|-----------|--------|----------|-----------------|------------------------------|
| companyId | string | No       | Valid company ID| Filter by company            |
| status    | string | No       | Active, Cancelled| Filter by schedule status   |

#### Response Model -- 200 OK

| Field                  | Type   | Description                                       |
|------------------------|--------|---------------------------------------------------|
| items                  | array  | Array of accrual schedule summary objects         |
| items[].id             | string | Accrual schedule identifier                       |
| items[].companyId      | string | Company this schedule belongs to                  |
| items[].description    | string | Schedule description                              |
| items[].scheduleType   | string | Schedule type (e.g. Monthly, Quarterly, Custom)   |
| items[].startDate      | string | Schedule start date (ISO 8601)                    |
| items[].endDate        | string | Schedule end date (ISO 8601); null if open-ended  |
| items[].status         | string | Active or Cancelled                               |
| items[].entryCount     | integer| Number of generated journal entries               |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 403    | FORBIDDEN      | User lacks gl-accountant permission      |
| 500    | INTERNAL_ERROR | Unexpected server error                  |

### Create Accrual/Prepaid Schedule

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /accrual-schedules                                     |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | Create a new accrual or prepaid journal entry schedule. The system generates journal entries and their reversals according to the schedule definition. |

#### Request Model

| Field           | Type   | Required | Validation                              | Description                               |
|-----------------|--------|----------|-----------------------------------------|-------------------------------------------|
| companyId       | string | Yes      | User must have access to company        | Company identifier                        |
| description     | string | Yes      | Max 500 characters                      | Schedule description                      |
| scheduleType    | string | Yes      | Monthly, Quarterly, or Custom           | Recurrence pattern                        |
| startDate       | string | Yes      | ISO 8601 date; must be in an open period| First entry date                          |
| endDate         | string | No       | ISO 8601 date; must be after startDate  | Last entry date; null for open-ended      |
| baseEntry       | object | Yes      | Valid journal entry object (header + lines) | Template entry for generation         |
| reversalOffset  | integer| No       | Number of days after entry date; default 1 | Days after entry date to create reversal|

#### Response Model -- 200 OK

| Field        | Type   | Description                              |
|--------------|--------|------------------------------------------|
| id           | string | System-assigned schedule identifier      |
| status       | string | "Active"                                 |
| entryCount   | integer| Number of journal entries generated      |
| createdAt    | string | ISO 8601 timestamp of creation           |

#### Error Responses

| Status | Code              | Description                                               |
|--------|-------------------|-----------------------------------------------------------|
| 400    | VALIDATION_ERROR  | One or more request fields failed validation              |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token                   |
| 403    | FORBIDDEN         | User lacks gl-accountant permission                       |
| 422    | PERIOD_CLOSED     | Start date falls in a closed period                       |
| 500    | INTERNAL_ERROR    | Unexpected server error                                   |

### Update Accrual/Prepaid Schedule

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | PUT                                                    |
| URL Path       | /accrual-schedules/{id}                                |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | Update an active accrual/prepaid schedule. Changes apply to future-period entries only; already-generated entries are not modified. |

#### Request Model

| Field        | Type   | Required | Validation                          | Description              |
|--------------|--------|----------|-------------------------------------|--------------------------|
| id           | string | Yes      | Non-empty; schedule must be Active  | Schedule ID (path param) |
| description  | string | No       | Max 500 characters                  | Updated description      |
| endDate      | string | No       | ISO 8601 date; after last generated entry date | Updated end date |

#### Response Model -- 200 OK

| Field     | Type   | Description                    |
|-----------|--------|--------------------------------|
| id        | string | Schedule identifier            |
| status    | string | "Active"                       |
| updatedAt | string | ISO 8601 timestamp of update   |

#### Error Responses

| Status | Code              | Description                                       |
|--------|-------------------|---------------------------------------------------|
| 400    | VALIDATION_ERROR  | Invalid field values                              |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token           |
| 403    | FORBIDDEN         | User lacks permission                             |
| 404    | NOT_FOUND         | Schedule not found                                |
| 409    | SCHEDULE_CANCELLED| Cannot update a cancelled schedule               |
| 500    | INTERNAL_ERROR    | Unexpected server error                           |

### Cancel Accrual/Prepaid Schedule

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | DELETE                                                 |
| URL Path       | /accrual-schedules/{id}                                |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | Cancel an active accrual/prepaid schedule. No further entries are generated for future periods. Already-generated entries are not deleted. |

#### Request Model

| Field | Type   | Required | Validation       | Description              |
|-------|--------|----------|------------------|--------------------------|
| id    | string | Yes      | Non-empty string | Schedule ID (path param) |

#### Response Model -- 200 OK

| Field        | Type   | Description                      |
|--------------|--------|----------------------------------|
| id           | string | Schedule identifier              |
| status       | string | "Cancelled"                      |
| cancelledAt  | string | ISO 8601 timestamp of cancellation|

#### Error Responses

| Status | Code              | Description                              |
|--------|-------------------|------------------------------------------|
| 401    | UNAUTHORIZED      | Missing or invalid authentication token  |
| 403    | FORBIDDEN         | User lacks permission                    |
| 404    | NOT_FOUND         | Schedule not found                       |
| 409    | ALREADY_CANCELLED | Schedule is already cancelled            |
| 500    | INTERNAL_ERROR    | Unexpected server error                  |

### List Entries for a Schedule

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /accrual-schedules/{id}/entries                        |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | List all journal entries generated for a given accrual/prepaid schedule, including both base entries and their corresponding reversal entries. |

#### Request Model

| Field | Type   | Required | Validation       | Description              |
|-------|--------|----------|------------------|--------------------------|
| id    | string | Yes      | Non-empty string | Schedule ID (path param) |

#### Response Model -- 200 OK

| Field                  | Type   | Description                                        |
|------------------------|--------|----------------------------------------------------|
| scheduleId             | string | The accrual schedule identifier                    |
| items                  | array  | Array of journal entry summary objects             |
| items[].entryId        | string | Journal entry identifier                           |
| items[].entryType      | string | "Accrual" or "Reversal"                            |
| items[].transactionDate| string | Transaction date (ISO 8601)                        |
| items[].status         | string | Unposted, Posted, or Cancelled                     |
| items[].totalDebit     | number | Computed total debit for this entry                |
| items[].totalCredit    | number | Computed total credit for this entry               |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 403    | FORBIDDEN      | User lacks permission                    |
| 404    | NOT_FOUND      | Schedule not found                       |
| 500    | INTERNAL_ERROR | Unexpected server error                  |
