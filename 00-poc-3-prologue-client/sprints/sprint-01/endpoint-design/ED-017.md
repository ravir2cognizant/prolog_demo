## Endpoint Definitions

### Search and List Accounts

| Field          | Value                                                        |
|----------------|--------------------------------------------------------------|
| HTTP Method    | GET                                                          |
| URL Path       | /accounts                                                    |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor, gl-administrator |
| Description    | Search and list GL accounts in the chart of accounts. Supports type-ahead search by code or description. Returns only accounts for the specified company. Used by the Account Maintenance screen and the account picker in journal entry lines. |

#### Request Model

Query parameters:

| Field      | Type    | Required | Validation            | Description                                        |
|------------|---------|----------|-----------------------|----------------------------------------------------|
| companyId  | string  | Yes      | User must have access | Company identifier                                 |
| search     | string  | No       | Min 1 char            | Partial account code or description                |
| activeOnly | boolean | No       | Default: false        | When true, exclude inactive accounts               |
| type       | string  | No       | asset, liability, equity, revenue, expense | Filter by account type    |
| page       | integer | No       | Min 1; default 1      | Page number for pagination                         |
| pageSize   | integer | No       | 1-100; default 20     | Number of accounts per page                        |

#### Response Model -- 200 OK

| Field                | Type    | Description                                         |
|----------------------|---------|-----------------------------------------------------|
| items                | array   | Array of account summary objects                    |
| items[].id           | string  | Unique account identifier                           |
| items[].code         | string  | Account code (structured format)                    |
| items[].description  | string  | Account description / display name                  |
| items[].type         | string  | asset, liability, equity, revenue, or expense       |
| items[].active       | boolean | Whether the account is active                       |
| totalCount           | integer | Total matching accounts across all pages            |
| page                 | integer | Current page number                                 |
| pageSize             | integer | Page size returned                                  |

#### Error Responses

| Status | Code              | Description                                        |
|--------|-------------------|----------------------------------------------------|
| 400    | VALIDATION_ERROR  | companyId missing or invalid                       |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token            |
| 403    | FORBIDDEN         | User does not have access to the specified company |
| 500    | INTERNAL_ERROR    | Unexpected server error                            |

### Get Account Detail

| Field          | Value                                                        |
|----------------|--------------------------------------------------------------|
| HTTP Method    | GET                                                          |
| URL Path       | /accounts/{id}                                               |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor, gl-administrator |
| Description    | Retrieve the full detail of a single GL account by identifier. |

#### Request Model

| Field | Type   | Required | Validation       | Description             |
|-------|--------|----------|------------------|-------------------------|
| id    | string | Yes      | Non-empty string | Account ID (path param) |

#### Response Model -- 200 OK

| Field          | Type    | Description                                              |
|----------------|---------|----------------------------------------------------------|
| id             | string  | Unique account identifier                                |
| companyId      | string  | Company this account belongs to                          |
| code           | string  | Account code in structured format                        |
| description    | string  | Account description                                      |
| type           | string  | asset, liability, equity, revenue, or expense            |
| active         | boolean | Whether the account is active                            |
| createdAt      | string  | ISO 8601 creation timestamp                              |
| createdByUserId| string  | User ID who created the account                          |
| updatedAt      | string  | ISO 8601 last-updated timestamp                          |
| updatedByUserId| string  | User ID who last updated the account                     |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 403    | FORBIDDEN      | User lacks access to this account        |
| 404    | NOT_FOUND      | Account not found                        |
| 500    | INTERNAL_ERROR | Unexpected server error                  |

### Create Account

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /accounts                                              |
| Authentication | Bearer JWT; roles: gl-administrator                    |
| Description    | Create a new GL account in the chart of accounts. Account code must conform to the structured format. New accounts are Active by default. |

#### Request Model

| Field       | Type    | Required | Validation                                     | Description                        |
|-------------|---------|----------|------------------------------------------------|------------------------------------|
| companyId   | string  | Yes      | User must have gl-administrator access         | Company identifier                 |
| code        | string  | Yes      | Must match structured account code format; unique per company | Account code            |
| description | string  | Yes      | Max 200 characters                             | Account description                |
| type        | string  | Yes      | asset, liability, equity, revenue, or expense  | Account type classification        |
| active      | boolean | No       | Default: true                                  | Active status                      |

#### Response Model -- 200 OK

| Field     | Type   | Description                              |
|-----------|--------|------------------------------------------|
| id        | string | System-assigned account identifier       |
| code      | string | Assigned account code                    |
| createdAt | string | ISO 8601 creation timestamp              |

#### Error Responses

| Status | Code              | Description                                                   |
|--------|-------------------|---------------------------------------------------------------|
| 400    | VALIDATION_ERROR  | One or more fields failed validation                          |
| 400    | INVALID_CODE_FORMAT | Account code does not match the required structured format  |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token                       |
| 403    | FORBIDDEN         | User lacks gl-administrator permission                        |
| 409    | CODE_CONFLICT     | An account with this code already exists for the company      |
| 500    | INTERNAL_ERROR    | Unexpected server error                                       |

### Update Account

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | PUT                                                    |
| URL Path       | /accounts/{id}                                         |
| Authentication | Bearer JWT; roles: gl-administrator                    |
| Description    | Update an existing GL account record. All fields are optional; provided fields replace existing values. Setting active=false marks the account as inactive and removes it from account picker results. |

#### Request Model

| Field       | Type    | Required | Validation                                       | Description                        |
|-------------|---------|----------|--------------------------------------------------|------------------------------------|
| id          | string  | Yes      | Non-empty string                                 | Account ID (path param)            |
| description | string  | No       | Max 200 characters                               | Updated account description        |
| type        | string  | No       | asset, liability, equity, revenue, or expense    | Updated account type               |
| active      | boolean | No       | true or false                                    | Updated active status              |

#### Response Model -- 200 OK

| Field     | Type   | Description                      |
|-----------|--------|----------------------------------|
| id        | string | Account identifier               |
| updatedAt | string | ISO 8601 update timestamp        |
| updatedByUserId | string | User ID who performed update |

#### Error Responses

| Status | Code              | Description                              |
|--------|-------------------|------------------------------------------|
| 400    | VALIDATION_ERROR  | Invalid field values                     |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token  |
| 403    | FORBIDDEN         | User lacks gl-administrator permission   |
| 404    | NOT_FOUND         | Account not found                        |
| 500    | INTERNAL_ERROR    | Unexpected server error                  |

### Get Account Balances by Period

| Field          | Value                                                        |
|----------------|--------------------------------------------------------------|
| HTTP Method    | GET                                                          |
| URL Path       | /accounts/{id}/balances                                      |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor, gl-administrator |
| Description    | Retrieve the GL balance for an account for each accounting period in a fiscal year. Used by the account inquiry view in Account Maintenance. |

#### Request Model

| Field        | Type   | Required | Validation                  | Description                           |
|--------------|--------|----------|-----------------------------|---------------------------------------|
| id           | string | Yes      | Non-empty string            | Account ID (path param)               |
| fiscalYearId | string | Yes      | Must reference existing fiscal year | Fiscal year to retrieve balances for |

#### Response Model -- 200 OK

| Field                   | Type   | Description                                           |
|-------------------------|--------|-------------------------------------------------------|
| accountId               | string | Account identifier                                    |
| accountCode             | string | Account code                                          |
| accountDescription      | string | Account description                                   |
| fiscalYearId            | string | Fiscal year identifier                                |
| periods                 | array  | Array of period balance objects ordered by sequence   |
| periods[].periodId      | string | Period identifier                                     |
| periods[].periodName    | string | Period display name                                   |
| periods[].openingBalance| number | Opening balance for this period                       |
| periods[].debit         | number | Total debits posted in this period                    |
| periods[].credit        | number | Total credits posted in this period                   |
| periods[].closingBalance| number | Closing balance for this period                       |

#### Error Responses

| Status | Code              | Description                              |
|--------|-------------------|------------------------------------------|
| 400    | VALIDATION_ERROR  | fiscalYearId missing or invalid          |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token  |
| 403    | FORBIDDEN         | User lacks access to this account        |
| 404    | NOT_FOUND         | Account or fiscal year not found         |
| 500    | INTERNAL_ERROR    | Unexpected server error                  |
