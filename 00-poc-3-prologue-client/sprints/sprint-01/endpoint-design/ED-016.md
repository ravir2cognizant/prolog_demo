## Endpoint Definitions

### Import Transactions

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | POST                                                        |
| URL Path       | /transactions/import                                        |
| Authentication | Bearer JWT; roles: gl-accountant                            |
| Description    | Upload and process a transaction import file. Valid rows are created as Unposted journal entries. Invalid rows are reported per-row. The import is processed asynchronously; this endpoint returns a job ID for polling. Accepted file formats: CSV, XLSX. |

#### Request Model

Multipart form data:

| Field     | Type    | Required | Validation                        | Description                                |
|-----------|---------|----------|-----------------------------------|--------------------------------------------|
| companyId | string  | Yes      | User must have access             | Target company for the imported entries    |
| file      | binary  | Yes      | CSV or XLSX; max 50 MB            | Transaction import file                    |

#### Response Model -- 202 Accepted

| Field     | Type   | Description                                                          |
|-----------|--------|----------------------------------------------------------------------|
| jobId     | string | Import job identifier; use for status polling                        |
| status    | string | "Queued" or "Processing"                                             |
| submittedAt | string | ISO 8601 timestamp when import was submitted                       |

#### Error Responses

| Status | Code              | Description                                         |
|--------|-------------------|-----------------------------------------------------|
| 400    | INVALID_FILE      | File is not a valid CSV or XLSX format              |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token             |
| 403    | FORBIDDEN         | User lacks gl-accountant permission                 |
| 413    | FILE_TOO_LARGE    | Uploaded file exceeds 50 MB size limit              |
| 500    | INTERNAL_ERROR    | Unexpected server error                             |

### Get Import Job Status

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | GET                                                         |
| URL Path       | /transactions/import/{jobId}/status                         |
| Authentication | Bearer JWT; roles: gl-accountant                            |
| Description    | Poll the status of a transaction import job. Returns the current processing state, counts, and a link to errors when complete. |

#### Request Model

| Field  | Type   | Required | Validation       | Description            |
|--------|--------|----------|------------------|------------------------|
| jobId  | string | Yes      | Non-empty string | Import job ID (path)   |

#### Response Model -- 200 OK

| Field          | Type    | Description                                                    |
|----------------|---------|----------------------------------------------------------------|
| jobId          | string  | Import job identifier                                          |
| status         | string  | "Queued", "Processing", "Completed", or "Failed"               |
| totalRows      | integer | Total rows in the import file                                  |
| processedRows  | integer | Rows processed so far                                          |
| importedCount  | integer | Number of entries successfully created (available when Completed) |
| errorCount     | integer | Number of rows with errors (available when Completed)         |
| completedAt    | string  | ISO 8601 timestamp of completion; null if not yet complete     |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 403    | FORBIDDEN      | User lacks permission to view this job   |
| 404    | NOT_FOUND      | Import job not found                     |
| 500    | INTERNAL_ERROR | Unexpected server error                  |

### List Import Errors

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | GET                                                         |
| URL Path       | /transactions/import/{jobId}/errors                         |
| Authentication | Bearer JWT; roles: gl-accountant                            |
| Description    | Retrieve the list of per-row validation errors from a completed import job. Only available after the job reaches Completed status. |

#### Request Model

| Field    | Type    | Required | Validation         | Description             |
|----------|---------|----------|--------------------|-------------------------|
| jobId    | string  | Yes      | Non-empty string   | Import job ID (path)    |
| page     | integer | No       | Min 1; default 1   | Page number             |
| pageSize | integer | No       | 1-100; default 50  | Errors per page         |

#### Response Model -- 200 OK

| Field              | Type    | Description                                        |
|--------------------|---------|----------------------------------------------------|
| jobId              | string  | Import job identifier                              |
| totalErrors        | integer | Total number of validation errors                  |
| items              | array   | Array of per-row error objects                     |
| items[].rowNumber  | integer | Row number in the source file (1-based)            |
| items[].field      | string  | Field that failed validation; null for row-level errors |
| items[].code       | string  | Validation error code                              |
| items[].message    | string  | Human-readable error description                   |

#### Error Responses

| Status | Code              | Description                                           |
|--------|-------------------|-------------------------------------------------------|
| 400    | JOB_NOT_COMPLETE  | Import job has not yet completed; no errors available |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token               |
| 403    | FORBIDDEN         | User lacks permission to view this job                |
| 404    | NOT_FOUND         | Import job not found                                  |
| 500    | INTERNAL_ERROR    | Unexpected server error                               |

### Export Transactions

| Field          | Value                                                       |
|----------------|-------------------------------------------------------------|
| HTTP Method    | GET                                                         |
| URL Path       | /transactions/export                                        |
| Authentication | Bearer JWT; roles: gl-accountant                            |
| Description    | Export GL transactions for a company and date range as a downloadable file. |

#### Request Model

Query parameters:

| Field     | Type   | Required | Validation                       | Description                              |
|-----------|--------|----------|----------------------------------|------------------------------------------|
| companyId | string | Yes      | User must have access            | Company identifier                       |
| fromDate  | string | Yes      | ISO 8601 date                    | Export transactions from this date       |
| toDate    | string | Yes      | ISO 8601 date; after fromDate    | Export transactions up to and including this date |
| format    | string | No       | "csv" or "xlsx"; default "csv"   | Export file format                       |

#### Response Model -- 200 OK

Binary file download. Response headers:

| Header              | Value                                               |
|---------------------|-----------------------------------------------------|
| Content-Type        | text/csv or application/vnd.openxmlformats-officedocument.spreadsheetml.sheet |
| Content-Disposition | attachment; filename="transactions-{companyId}-{fromDate}-{toDate}.{ext}" |

#### Error Responses

| Status | Code              | Description                                     |
|--------|-------------------|-------------------------------------------------|
| 400    | VALIDATION_ERROR  | Missing or invalid query parameters             |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token         |
| 403    | FORBIDDEN         | User lacks access to the specified company      |
| 500    | INTERNAL_ERROR    | Unexpected server error                         |
