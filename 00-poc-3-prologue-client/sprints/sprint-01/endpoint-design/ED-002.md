## Endpoint Definitions

Journal entry lines are submitted as part of the journal entry payload (POST/PUT /journal-entries defined in ED-001). This card documents the line object schema and the reference data endpoints specific to line management.

### Search Chart of Accounts

| Field          | Value                                                      |
|----------------|------------------------------------------------------------|
| HTTP Method    | GET                                                        |
| URL Path       | /accounts                                                  |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor            |
| Description    | Search the chart of accounts for use in the account picker on journal entry lines. Returns only active accounts accessible to the given company. |

#### Request Model

Query parameters:

| Field     | Type    | Required | Validation           | Description                                     |
|-----------|---------|----------|----------------------|-------------------------------------------------|
| search    | string  | No       | Min 1 char           | Partial account code or description to search   |
| companyId | string  | Yes      | Non-empty            | Restrict results to accounts for this company   |
| activeOnly| boolean | No       | Default: true        | When true, exclude inactive accounts            |
| page      | integer | No       | Min 1; default 1     | Page number for pagination                      |
| pageSize  | integer | No       | 1-100; default 20    | Number of results per page                      |

#### Response Model -- 200 OK

| Field                   | Type    | Description                                    |
|-------------------------|---------|------------------------------------------------|
| items                   | array   | Array of account objects                       |
| items[].id              | string  | Unique account identifier                      |
| items[].code            | string  | Account code (structured format, e.g. 1-394-7005-008-96) |
| items[].description     | string  | Account description / display name             |
| items[].type            | string  | Account type: asset, liability, equity, revenue, expense |
| items[].active          | boolean | Whether the account is active                  |
| totalCount              | integer | Total matching records across all pages        |
| page                    | integer | Current page number                            |
| pageSize                | integer | Page size used for this response               |

#### Error Responses

| Status | Code           | Description                                       |
|--------|----------------|---------------------------------------------------|
| 400    | VALIDATION_ERROR | companyId missing or invalid                    |
| 401    | UNAUTHORIZED   | Missing or invalid authentication token           |
| 403    | FORBIDDEN      | User does not have access to the specified company|
| 500    | INTERNAL_ERROR | Unexpected server error                           |

### List Currencies

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /currencies                                            |
| Authentication | Bearer JWT; any authenticated user                     |
| Description    | List valid currency codes for the Currency ID dropdown on journal entry lines. |

#### Request Model

No request body or query parameters.

#### Response Model -- 200 OK

| Field             | Type   | Description                           |
|-------------------|--------|---------------------------------------|
| items             | array  | Array of currency objects             |
| items[].code      | string | ISO 4217 currency code (e.g. USD)     |
| items[].name      | string | Currency display name (e.g. US Dollar)|
| items[].isBase    | boolean| True if this is the company base currency |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 500    | INTERNAL_ERROR | Unexpected server error                  |

### Journal Entry Line Object Schema

Line items are nested within the POST /journal-entries and PUT /journal-entries/{id} request and response bodies (ED-001). The line object schema is:

#### Line Request Fields

| Field       | Type    | Required | Validation                                          | Description                          |
|-------------|---------|----------|-----------------------------------------------------|--------------------------------------|
| lineNumber  | integer | No       | Auto-assigned by server; ignored on input           | Sequential line number               |
| accountId   | string  | Yes      | Must reference an active account for the company    | Account identifier from chart of accounts |
| currencyId  | string  | Yes      | Must match a valid ISO 4217 currency code           | Currency code for this line          |
| debit       | number  | Yes      | Non-negative; 0 if credit is non-zero               | Debit amount (2 decimal places)      |
| credit      | number  | Yes      | Non-negative; 0 if debit is non-zero                | Credit amount (2 decimal places)     |
| description | string  | No       | Max 500 characters                                  | Line description                     |
| referenceNo | string  | No       | Max 100 characters                                  | Reference number                     |

#### Line Response Fields

| Field              | Type    | Description                                        |
|--------------------|---------|----------------------------------------------------|
| lineNumber         | integer | Server-assigned sequential line number             |
| accountId          | string  | Account identifier                                 |
| accountCode        | string  | Account code (auto-populated from account master)  |
| accountDescription | string  | Account description (auto-populated)               |
| currencyId         | string  | Currency code                                      |
| debit              | number  | Debit amount                                       |
| credit             | number  | Credit amount                                      |
| description        | string  | Line description                                   |
| referenceNo        | string  | Reference number                                   |
