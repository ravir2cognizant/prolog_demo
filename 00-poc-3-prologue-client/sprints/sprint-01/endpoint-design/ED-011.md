## Endpoint Definitions

### List Allocation Rules

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /allocation-rules                                      |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | List all defined allocation rules accessible to the current user. |

#### Request Model

Query parameters:

| Field     | Type   | Required | Validation      | Description              |
|-----------|--------|----------|-----------------|--------------------------|
| companyId | string | No       | Valid company ID| Filter by company        |

#### Response Model -- 200 OK

| Field                    | Type   | Description                                         |
|--------------------------|--------|-----------------------------------------------------|
| items                    | array  | Array of allocation rule summary objects            |
| items[].id               | string | Allocation rule identifier                          |
| items[].name             | string | Rule display name                                   |
| items[].sourceAccountId  | string | Source account identifier                           |
| items[].sourceAccountCode| string | Source account code                                 |
| items[].allocationBasis  | string | "Percentage" or "FixedAmount"                       |
| items[].targetCount      | integer| Number of target accounts in this rule              |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 403    | FORBIDDEN      | User lacks gl-accountant permission      |
| 500    | INTERNAL_ERROR | Unexpected server error                  |

### Create Allocation Rule

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /allocation-rules                                      |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | Create a new account balance allocation rule. For percentage-based rules, the server validates that target percentages sum to 100 before saving. |

#### Request Model

| Field            | Type   | Required | Validation                                        | Description                         |
|------------------|--------|----------|---------------------------------------------------|-------------------------------------|
| companyId        | string | Yes      | User must have access                             | Company identifier                  |
| name             | string | Yes      | Max 200 characters                                | Rule display name                   |
| sourceAccountId  | string | Yes      | Must reference an active account                  | Source account                      |
| allocationBasis  | string | Yes      | "Percentage" or "FixedAmount"                     | Allocation basis type               |
| targets          | array  | Yes      | At least 1 target; percentages must sum to 100    | Array of target allocation objects  |
| targets[].accountId | string | Yes | Must reference an active account               | Target account identifier           |
| targets[].value  | number | Yes      | For Percentage: 0.01-100.00; for FixedAmount: positive | Allocation amount or percentage |

#### Response Model -- 200 OK

| Field     | Type   | Description                                  |
|-----------|--------|----------------------------------------------|
| id        | string | System-assigned allocation rule identifier   |
| createdAt | string | ISO 8601 timestamp of creation               |

#### Error Responses

| Status | Code                     | Description                                                         |
|--------|--------------------------|---------------------------------------------------------------------|
| 400    | VALIDATION_ERROR         | One or more fields failed validation                                |
| 400    | PERCENTAGES_NOT_100      | Percentage targets do not sum to 100%; body includes computed total |
| 401    | UNAUTHORIZED             | Missing or invalid authentication token                             |
| 403    | FORBIDDEN                | User lacks gl-accountant permission                                 |
| 500    | INTERNAL_ERROR           | Unexpected server error                                             |

### Update Allocation Rule

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | PUT                                                    |
| URL Path       | /allocation-rules/{id}                                 |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | Update an existing allocation rule definition. Percentage total validation applies. |

#### Request Model

| Field            | Type   | Required | Validation                                        | Description                         |
|------------------|--------|----------|---------------------------------------------------|-------------------------------------|
| id               | string | Yes      | Non-empty; rule must exist                        | Rule ID (path param)                |
| name             | string | No       | Max 200 characters                                | Updated rule name                   |
| sourceAccountId  | string | No       | Must reference an active account                  | Updated source account              |
| allocationBasis  | string | No       | "Percentage" or "FixedAmount"                     | Updated allocation basis            |
| targets          | array  | No       | If provided, replaces all existing targets        | Updated target allocations          |

#### Response Model -- 200 OK

| Field     | Type   | Description                |
|-----------|--------|----------------------------|
| id        | string | Allocation rule identifier |
| updatedAt | string | ISO 8601 update timestamp  |

#### Error Responses

| Status | Code                     | Description                                                |
|--------|--------------------------|------------------------------------------------------------|
| 400    | VALIDATION_ERROR         | Invalid field values                                       |
| 400    | PERCENTAGES_NOT_100      | Percentage targets do not sum to 100%                      |
| 401    | UNAUTHORIZED             | Missing or invalid authentication token                    |
| 403    | FORBIDDEN                | User lacks permission                                      |
| 404    | NOT_FOUND                | Allocation rule not found                                  |
| 500    | INTERNAL_ERROR           | Unexpected server error                                    |

### Delete Allocation Rule

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | DELETE                                                 |
| URL Path       | /allocation-rules/{id}                                 |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | Delete an allocation rule. Cannot delete a rule that is referenced by a journal entry header as the Allocation Method ID. |

#### Request Model

| Field | Type   | Required | Validation       | Description           |
|-------|--------|----------|------------------|-----------------------|
| id    | string | Yes      | Non-empty string | Rule ID (path param)  |

#### Response Model -- 200 OK

| Field     | Type   | Description                |
|-----------|--------|----------------------------|
| id        | string | Deleted rule identifier    |
| deletedAt | string | ISO 8601 deletion timestamp|

#### Error Responses

| Status | Code              | Description                                                      |
|--------|-------------------|------------------------------------------------------------------|
| 401    | UNAUTHORIZED      | Missing or invalid authentication token                          |
| 403    | FORBIDDEN         | User lacks permission                                            |
| 404    | NOT_FOUND         | Allocation rule not found                                        |
| 409    | RULE_IN_USE       | Rule is referenced by one or more journal entries and cannot be deleted |
| 500    | INTERNAL_ERROR    | Unexpected server error                                          |

### Run Allocation Rule

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /allocation-rules/{id}/run                             |
| Authentication | Bearer JWT; roles: gl-accountant                       |
| Description    | Execute an allocation rule for a given period. Reads the source account balance, applies the allocation formula, and generates journal entries distributing the balance to target accounts. Generated entries reference the allocation rule ID. |

#### Request Model

| Field          | Type   | Required | Validation                           | Description                                 |
|----------------|--------|----------|--------------------------------------|---------------------------------------------|
| id             | string | Yes      | Non-empty; rule must exist           | Rule ID (path param)                        |
| fiscalYearId   | string | Yes      | Must reference an existing fiscal year| Fiscal year for the allocation run         |
| periodId       | string | Yes      | Must be an open period in the fiscal year | Accounting period for the allocation    |

#### Response Model -- 200 OK

| Field              | Type    | Description                                            |
|--------------------|---------|--------------------------------------------------------|
| allocationRunId    | string  | Unique identifier for this allocation run              |
| generatedEntryIds  | array   | Array of journal entry IDs created by this run         |
| entryCount         | integer | Number of journal entries generated                    |
| sourceBalance      | number  | Source account balance used for the allocation         |

#### Error Responses

| Status | Code              | Description                                               |
|--------|-------------------|-----------------------------------------------------------|
| 400    | VALIDATION_ERROR  | Missing or invalid period/fiscal year                     |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token                   |
| 403    | FORBIDDEN         | User lacks gl-accountant permission                       |
| 404    | NOT_FOUND         | Allocation rule not found                                 |
| 422    | PERIOD_CLOSED     | Specified period is closed                                |
| 500    | INTERNAL_ERROR    | Unexpected server error                                   |
