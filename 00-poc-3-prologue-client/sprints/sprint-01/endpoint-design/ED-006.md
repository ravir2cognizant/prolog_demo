## Endpoint Definitions

Navigation traverses the user's current filtered result set. The BFF maintains navigation context via cursor-based pagination. GET /journal-entries/{id} (ED-001) handles loading a specific entry once the ID is resolved.

### List and Navigate Journal Entries

| Field          | Value                                                        |
|----------------|--------------------------------------------------------------|
| HTTP Method    | GET                                                          |
| URL Path       | /journal-entries                                             |
| Authentication | Bearer JWT; roles: gl-accountant, gl-supervisor              |
| Description    | Return a paginated, cursor-navigable list of journal entries for the current user. Supports First/Previous/Next/Last navigation by returning cursor tokens. Only entries for companies the user has access to are included. |

#### Request Model

Query parameters:

| Field      | Type    | Required | Validation                              | Description                                      |
|------------|---------|----------|-----------------------------------------|--------------------------------------------------|
| companyId  | string  | Yes      | Non-empty; user must have access        | Filter by company                                |
| cursor     | string  | No       | Opaque cursor token from prior response | Starting position for pagination                 |
| direction  | string  | No       | "next" or "prev"; default "next"        | Direction of navigation from cursor              |
| pageSize   | integer | No       | 1-100; default 20                       | Number of entries per page                       |
| fromDate   | string  | No       | ISO 8601 date                           | Filter by Transaction Date on or after this date |
| toDate     | string  | No       | ISO 8601 date                           | Filter by Transaction Date on or before this date|
| status     | string  | No       | "Unposted" or "Posted"                  | Filter by entry status                           |
| entryType  | string  | No       | Valid entry type code                   | Filter by journal entry type                     |

#### Response Model -- 200 OK

| Field                  | Type    | Description                                                        |
|------------------------|---------|--------------------------------------------------------------------|
| items                  | array   | Array of journal entry summary objects                             |
| items[].id             | string  | Journal entry identifier                                           |
| items[].transactionDate| string  | Transaction date (ISO 8601)                                        |
| items[].description    | string  | Entry description                                                  |
| items[].status         | string  | Unposted or Posted                                                 |
| items[].entryType      | string  | Entry type code                                                    |
| items[].totalDebit     | number  | Computed total debit                                               |
| items[].totalCredit    | number  | Computed total credit                                              |
| firstCursor            | string  | Cursor pointing to the first entry in the full result set          |
| lastCursor             | string  | Cursor pointing to the last entry in the full result set           |
| nextCursor             | string  | Cursor for the next page; null if this is the last page            |
| prevCursor             | string  | Cursor for the previous page; null if this is the first page       |
| totalCount             | integer | Total number of entries matching the filters                       |
| isFirst                | boolean | True when current page starts at the first entry in the result set |
| isLast                 | boolean | True when current page ends at the last entry in the result set    |

#### Error Responses

| Status | Code              | Description                                          |
|--------|-------------------|------------------------------------------------------|
| 400    | VALIDATION_ERROR  | Invalid query parameter values                       |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token              |
| 403    | FORBIDDEN         | User does not have access to the specified company   |
| 500    | INTERNAL_ERROR    | Unexpected server error                              |
