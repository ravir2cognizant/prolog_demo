## Endpoint Definitions

### List Fiscal Years

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /fiscal-years                                          |
| Authentication | Bearer JWT; roles: finance-administrator, gl-accountant, gl-supervisor |
| Description    | List all defined fiscal years for the current context. Returns summary including year name, date range, and overall status. |

#### Request Model

Query parameters:

| Field     | Type   | Required | Validation      | Description              |
|-----------|--------|----------|-----------------|--------------------------|
| companyId | string | Yes      | User must have access | Company identifier  |

#### Response Model -- 200 OK

| Field              | Type    | Description                                          |
|--------------------|---------|------------------------------------------------------|
| items              | array   | Array of fiscal year objects                         |
| items[].id         | string  | Fiscal year identifier                               |
| items[].name       | string  | Fiscal year display name (e.g. "FY2026")             |
| items[].startDate  | string  | ISO 8601 start date of the fiscal year               |
| items[].endDate    | string  | ISO 8601 end date of the fiscal year                 |
| items[].periodCount| integer | Number of accounting periods in this year            |
| items[].status     | string  | "Open", "Closed", or "YearEndClosed"                 |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 403    | FORBIDDEN      | User lacks access to the specified company|
| 500    | INTERNAL_ERROR | Unexpected server error                  |

### Create Fiscal Year

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /fiscal-years                                          |
| Authentication | Bearer JWT; roles: finance-administrator               |
| Description    | Define a new fiscal year with a start date, end date, and period structure. System automatically generates the accounting periods. |

#### Request Model

| Field        | Type    | Required | Validation                                       | Description                              |
|--------------|---------|----------|--------------------------------------------------|------------------------------------------|
| companyId    | string  | Yes      | User must have access                            | Company identifier                       |
| name         | string  | Yes      | Max 100 characters                               | Fiscal year name (e.g. "FY2026")         |
| startDate    | string  | Yes      | ISO 8601 date                                    | First day of the fiscal year             |
| endDate      | string  | Yes      | ISO 8601 date; must be after startDate           | Last day of the fiscal year              |
| periodCount  | integer | Yes      | 12 or 13 (13 for adjustment period support)      | Number of accounting periods             |

#### Response Model -- 200 OK

| Field        | Type    | Description                                  |
|--------------|---------|----------------------------------------------|
| id           | string  | System-assigned fiscal year identifier       |
| periodCount  | integer | Number of periods generated                  |
| createdAt    | string  | ISO 8601 creation timestamp                  |

#### Error Responses

| Status | Code              | Description                                               |
|--------|-------------------|-----------------------------------------------------------|
| 400    | VALIDATION_ERROR  | Missing or invalid fields                                 |
| 401    | UNAUTHORIZED      | Missing or invalid authentication token                   |
| 403    | FORBIDDEN         | User lacks finance-administrator permission               |
| 409    | YEAR_OVERLAP      | Date range overlaps with an existing fiscal year          |
| 500    | INTERNAL_ERROR    | Unexpected server error                                   |

### List Periods for Fiscal Year

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | GET                                                    |
| URL Path       | /fiscal-years/{id}/periods                             |
| Authentication | Bearer JWT; roles: finance-administrator, gl-accountant, gl-supervisor |
| Description    | List all accounting periods within a fiscal year with their open/closed status. |

#### Request Model

| Field | Type   | Required | Validation       | Description                |
|-------|--------|----------|------------------|----------------------------|
| id    | string | Yes      | Non-empty string | Fiscal year ID (path param)|

#### Response Model -- 200 OK

| Field                | Type   | Description                                        |
|----------------------|--------|----------------------------------------------------|
| fiscalYearId         | string | Fiscal year identifier                             |
| items                | array  | Array of period objects ordered by sequence        |
| items[].id           | string | Period identifier                                  |
| items[].name         | string | Period display name (e.g. "Period 1 - Jan 2026")   |
| items[].startDate    | string | ISO 8601 period start date                         |
| items[].endDate      | string | ISO 8601 period end date                           |
| items[].status       | string | "Open" or "Closed"                                 |
| items[].sequence     | integer| Period sequence number (1-based)                  |

#### Error Responses

| Status | Code           | Description                              |
|--------|----------------|------------------------------------------|
| 401    | UNAUTHORIZED   | Missing or invalid authentication token  |
| 403    | FORBIDDEN      | User lacks access                        |
| 404    | NOT_FOUND      | Fiscal year not found                    |
| 500    | INTERNAL_ERROR | Unexpected server error                  |

### Open a Period

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | PUT                                                    |
| URL Path       | /fiscal-years/{id}/periods/{periodId}/open             |
| Authentication | Bearer JWT; roles: finance-administrator               |
| Description    | Change the status of a period from Closed to Open, allowing journal entry posting to that period. |

#### Request Model

| Field    | Type   | Required | Validation       | Description                 |
|----------|--------|----------|------------------|-----------------------------|
| id       | string | Yes      | Non-empty string | Fiscal year ID (path param) |
| periodId | string | Yes      | Non-empty string | Period ID (path param)      |

No request body required.

#### Response Model -- 200 OK

| Field    | Type   | Description                           |
|----------|--------|---------------------------------------|
| periodId | string | Period identifier                     |
| status   | string | "Open"                                |
| updatedAt| string | ISO 8601 timestamp of status change   |

#### Error Responses

| Status | Code              | Description                                        |
|--------|-------------------|----------------------------------------------------|
| 401    | UNAUTHORIZED      | Missing or invalid authentication token            |
| 403    | FORBIDDEN         | User lacks finance-administrator permission        |
| 404    | NOT_FOUND         | Fiscal year or period not found                    |
| 409    | ALREADY_OPEN      | Period is already Open                             |
| 409    | YEAR_END_CLOSED   | Cannot reopen a period in a year-end closed fiscal year |
| 500    | INTERNAL_ERROR    | Unexpected server error                            |

### Initiate Year-End Close

| Field          | Value                                                  |
|----------------|--------------------------------------------------------|
| HTTP Method    | POST                                                   |
| URL Path       | /fiscal-years/{id}/year-end-close                      |
| Authentication | Bearer JWT; roles: finance-administrator               |
| Description    | Initiate the year-end close process for a fiscal year. Closes all open periods, carries forward balance sheet account balances as opening balances for the next fiscal year. Rejected if any period has unposted entries. |

#### Request Model

| Field | Type   | Required | Validation       | Description                |
|-------|--------|----------|------------------|----------------------------|
| id    | string | Yes      | Non-empty string | Fiscal year ID (path param)|

No request body required.

#### Response Model -- 200 OK

| Field              | Type   | Description                                             |
|--------------------|--------|---------------------------------------------------------|
| fiscalYearId       | string | Fiscal year identifier                                  |
| status             | string | "YearEndClosed"                                         |
| closedAt           | string | ISO 8601 timestamp of year-end close                    |
| carryForwardCount  | integer| Number of balance sheet accounts with carried-forward balances |

#### Error Responses

| Status | Code                    | Description                                                      |
|--------|-------------------------|------------------------------------------------------------------|
| 401    | UNAUTHORIZED            | Missing or invalid authentication token                          |
| 403    | FORBIDDEN               | User lacks finance-administrator permission                      |
| 404    | NOT_FOUND               | Fiscal year not found                                            |
| 409    | ALREADY_CLOSED          | Fiscal year has already been year-end closed                     |
| 422    | UNPOSTED_ENTRIES_EXIST  | One or more periods have unposted entries; must post or delete before closing |
| 500    | INTERNAL_ERROR          | Unexpected server error                                          |
