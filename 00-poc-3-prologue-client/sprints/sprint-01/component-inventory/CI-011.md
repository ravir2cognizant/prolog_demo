# CI-011 -- Account Balance Allocation

## Overview

Standalone screen for defining and running account balance allocation rules. Includes the allocation rule list, rule creation/edit form, and run action.

---

## Components

### AllocationPage (page)

Top-level page for the Account Balance Allocation module.

**Children:** AllocationRuleList, CreateRuleButton.

---

### AllocationRuleList (organism)

List of defined allocation rules with source account, basis type, target count, and actions.

| Prop       | Type            | Required | Default | Description                         |
|------------|-----------------|----------|---------|-------------------------------------|
| rules      | AllocationRule[]| Yes      | —       | Loaded from GET /allocation-rules   |
| isLoading  | boolean         | No       | false   | Skeleton while loading              |
| onEdit     | function        | Yes      | —       | Open edit form                      |
| onDelete   | function        | Yes      | —       | Delete rule (with confirm)          |
| onRun      | function        | Yes      | —       | Opens run dialog                    |

---

### AllocationRuleForm (organism)

Form for creating or editing an allocation rule.

| Prop       | Type            | Required | Default | Description                             |
|------------|-----------------|----------|---------|-----------------------------------------|
| rule       | AllocationRule  | No       | null    | Existing rule; null = new               |
| onSave     | function        | Yes      | —       | POST/PUT handler                        |
| onClose    | function        | Yes      | —       | Close form                              |

**Key fields:** Rule Name (TextInputField), Source Account (AccountCell/AccountPickerDialog from CI-002), Allocation Basis (radio: Percentage / Fixed Amount), Targets grid (AllocationTargetsGrid).

---

### AllocationTargetsGrid (molecule)

Editable grid of target accounts and their allocation values. Shows running percentage total for validation.

| Prop              | Type     | Required | Default | Description                                    |
|-------------------|----------|----------|---------|------------------------------------------------|
| targets           | Target[] | Yes      | —       | Array of `{accountId, value}` objects          |
| basis             | string   | Yes      | —       | "Percentage" \| "FixedAmount"                  |
| onTargetsChange   | function | Yes      | —       | Full replacement callback                      |
| percentageTotal   | number   | Yes      | —       | Computed sum of percentages (for validation)   |

**Children:** TargetRow (×n), AddTargetButton, PercentageTotalDisplay.

---

### PercentageTotalDisplay (atom)

Shows the running sum of target percentages. Highlights in error when not equal to 100.

| Prop   | Type    | Required | Default | Description                    |
|--------|---------|----------|---------|--------------------------------|
| total  | number  | Yes      | —       | Computed percentage total      |

---

### AllocationRunDialog (molecule)

Dialog for selecting fiscal year/period and confirming an allocation rule run.

| Prop       | Type     | Required | Default | Description                              |
|------------|----------|----------|---------|------------------------------------------|
| isOpen     | boolean  | Yes      | —       | Visibility                               |
| rule       | AllocationRule | Yes | —      | Rule being run                           |
| fiscalYears| FiscalYear[] | Yes | —      | Available fiscal years                   |
| onConfirm  | function | Yes      | —       | `(fiscalYearId, periodId) => void`       |
| onClose    | function | Yes      | —       | Cancel                                   |

---

## States

### AllocationTargetsGrid States

| State               | Visual                                                            |
|---------------------|-------------------------------------------------------------------|
| Empty               | One blank row; Add Target button prominent                        |
| Percentage valid    | PercentageTotalDisplay shows green "100.0%"                       |
| Percentage invalid  | PercentageTotalDisplay shows red total; Save disabled            |
| Fixed amount        | PercentageTotalDisplay hidden; no percentage validation           |

### AllocationRunDialog States

| State      | Visual                                           |
|------------|--------------------------------------------------|
| Idle       | Period/year selects empty, Confirm disabled      |
| Period selected | Confirm enabled                             |
| Running    | Confirm spinner, disabled                        |
| Success    | Dialog closes; success toast shown               |
| Error      | Error message in dialog body                     |

## Accessibility

| Component              | Requirement                                                                         |
|------------------------|-------------------------------------------------------------------------------------|
| AllocationPage         | `<main>`, `<h1>` "Account Balance Allocation"                                       |
| AllocationRuleList     | `<table>` with column headers and keyboard-navigable rows                           |
| AllocationRuleForm     | `<form>` with `aria-label`; all inputs labelled; radio group `role="radiogroup"`    |
| AllocationTargetsGrid  | `<table>` with `<caption>` "Allocation Targets"; column headers `scope="col"`       |
| PercentageTotalDisplay | `role="status"` so running total is announced as it changes                         |
| AllocationRunDialog    | `role="dialog"`, `aria-modal`, focus trap, Escape to cancel                         |
| Delete action          | Confirm dialog before destructive delete; `aria-label="Delete rule {name}"`         |
| Run action             | `aria-label="Run allocation rule {name}"`                                            |
