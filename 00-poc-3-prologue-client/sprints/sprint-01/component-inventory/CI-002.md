## Overview

This CI covers the editable journal entry lines grid below the header (RC-001 / CI-001). Components include the line grid, account picker dialog, per-line inputs, and the add/delete line controls. Lines are submitted as part of the journal entry payload (POST/PUT /journal-entries).

---

## Components

### JournalEntryLinesGrid (organism)

Editable data grid for journal entry line items. Manages line-level state and delegates to row sub-components.

| Prop          | Type            | Required | Default | Description                                          |
|---------------|-----------------|----------|---------|------------------------------------------------------|
| lines         | JELine[]        | Yes      | —       | Current line items                                   |
| isPosted      | boolean         | Yes      | —       | When true all cells are read-only                    |
| companyId     | string          | Yes      | —       | Used to scope account picker to correct company      |
| currencies    | Currency[]      | Yes      | —       | Currency options for each line                       |
| onLinesChange | function        | Yes      | —       | `(lines: JELine[]) => void` — full replacement       |

**Children:** JELineRow (×n), AddLineButton, grid header row.

---

### JELineRow (molecule)

Renders one editable or read-only row in the lines grid.

| Prop          | Type      | Required | Default | Description                                 |
|---------------|-----------|----------|---------|---------------------------------------------|
| line          | JELine    | Yes      | —       | Line data object                            |
| lineIndex     | number    | Yes      | —       | 0-based row index                           |
| isPosted      | boolean   | Yes      | —       | When true all cells read-only               |
| currencies    | Currency[]| Yes      | —       | Options for currency dropdown               |
| onLineChange  | function  | Yes      | —       | `(index, field, value) => void`             |
| onDeleteLine  | function  | Yes      | —       | `(index) => void`                           |
| onOpenAccountPicker | function | Yes | —    | `(index) => void` — opens account dialog    |

**Cells:** line number (read-only), AccountCell, AccountDescriptionCell (auto-populated, read-only), CurrencyCell, DebitCell, CreditCell, DescriptionCell, ReferenceCell, DeleteButton.

---

### AccountCell (atom)

Clickable/typeable account code cell. Opens the AccountPickerDialog on click or Enter.

| Prop         | Type     | Required | Default | Description                              |
|--------------|----------|----------|---------|------------------------------------------|
| value        | string   | No       | ''      | Current account code                     |
| disabled     | boolean  | No       | false   | Read-only when posted                    |
| onOpen       | function | Yes      | —       | Triggered to open account picker         |
| onChange     | function | Yes      | —       | `(accountId: string) => void`            |
| error        | string   | No       | ''      | Inline validation error                  |

---

### AccountPickerDialog (organism)

Modal dialog for searching and selecting GL accounts. Calls GET /accounts with debounced search.

| Prop         | Type     | Required | Default | Description                              |
|--------------|----------|----------|---------|------------------------------------------|
| isOpen       | boolean  | Yes      | —       | Controls dialog visibility               |
| companyId    | string   | Yes      | —       | Scopes account search                    |
| onSelect     | function | Yes      | —       | `(account: Account) => void`             |
| onClose      | function | Yes      | —       | Close without selection                  |

**Children:** SearchInput, AccountResultsList, LoadingSpinner (during search), EmptyState.

---

### NumericInputCell (atom)

Right-aligned numeric input for Debit and Credit amounts. Supports formatted display (thousands separators, 2 decimal places).

| Prop          | Type     | Required | Default | Description                                     |
|---------------|----------|----------|---------|-------------------------------------------------|
| value         | number   | No       | 0       | Current numeric value                           |
| disabled      | boolean  | No       | false   | Read-only when posted                           |
| onChange      | function | Yes      | —       | `(value: number) => void`                       |
| error         | string   | No       | ''      | Validation error (e.g. both debit and credit >0)|

---

### AddLineButton (atom)

Button below the grid to append a new blank line.

| Prop      | Type     | Required | Default | Description              |
|-----------|----------|----------|---------|--------------------------|
| disabled  | boolean  | No       | false   | Disabled when posted     |
| onClick   | function | Yes      | —       | Appends a blank line     |

## States

### JournalEntryLinesGrid States

| State              | Trigger                                | Visual Change                                              |
|--------------------|----------------------------------------|------------------------------------------------------------|
| Empty              | No lines added yet                     | Empty state message and visible AddLineButton              |
| Editing            | isPosted = false, lines present        | All cells editable; delete buttons visible                 |
| Posted (read-only) | isPosted = true                        | All cells read-only; delete buttons hidden; AddLine hidden |
| Row hover          | Mouse over a row                       | Row background `colors.primary.50`                         |

### AccountPickerDialog States

| State      | Visual                                                                 |
|------------|------------------------------------------------------------------------|
| Opening    | Modal slides/fades in (`motion.moderate`, `easeInOut`)                  |
| Idle       | Empty search input, no results shown                                    |
| Searching  | LoadingSpinner visible; results list shows skeleton rows                |
| Results    | AccountResultsList populated; keyboard-navigable                        |
| No results | EmptyState message: "No accounts match your search"                    |
| Selected   | Dialog closes; AccountCell shows chosen code; description auto-fills   |

### NumericInputCell States

| State    | Visual                                                         |
|----------|----------------------------------------------------------------|
| Default  | Right-aligned; `0.00` shown as placeholder                     |
| Focused  | `border.focus` outline; raw number editable                    |
| Blurred  | Formatted with comma separators and 2 decimal places           |
| Error    | `border.error` border (both debit and credit non-zero)         |
| Disabled | `neutral.100` background; `text.disabled` text                 |

## Accessibility

| Component             | Requirement                                                                                     |
|-----------------------|-------------------------------------------------------------------------------------------------|
| JournalEntryLinesGrid | `<table>` element with `<caption>` "Journal Entry Lines"; `<th>` cells with `scope="col"`      |
| JELineRow             | Each cell is a `<td>` with appropriate input; line number `<td>` is `aria-label="Line N"`       |
| AccountCell           | Button or input triggers account picker; `aria-haspopup="dialog"`                               |
| AccountPickerDialog   | `role="dialog"`, `aria-modal="true"`, `aria-label="Select Account"`; focus trapped inside modal |
| AccountPickerDialog   | Escape closes dialog and returns focus to triggering AccountCell                                 |
| SearchInput (in dialog)| Auto-focused on open; `aria-label="Search accounts"`; results linked via `aria-controls`        |
| AccountResultsList    | `role="listbox"` or `<ul>` with `role="option"` items; `aria-activedescendant` tracks selection |
| NumericInputCell      | `<input type="text" inputmode="decimal">`; `aria-label="Debit amount, line N"` (or Credit)     |
| DeleteButton          | `aria-label="Delete line N"` (not just an icon)                                                 |
| AddLineButton         | `aria-label="Add journal entry line"`                                                            |
| Keyboard grid nav     | Tab moves between cells left-to-right; Shift+Tab reverses; Enter/Space opens pickers            |
| Screen reader updates | Account description auto-populate announced via `aria-live="polite"` region                     |
| Contrast              | All text in cells meets 4.5:1; numeric cells use monospace for readability                      |
