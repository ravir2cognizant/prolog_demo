# CI-017 -- Account Maintenance and Inquiry

## Overview

Standalone screen for creating, editing, and searching GL accounts (chart of accounts). Includes an account detail form with structured account-code validation and an account inquiry balance view showing balances by accounting period.

---

## Components

### AccountMaintenancePage (page)

Top-level page for Account Maintenance and Inquiry.

**Children:** AccountSearchBar, AccountList, CreateAccountButton. Selecting an account loads AccountDetailForm or AccountBalanceView depending on action.

---

### AccountSearchBar (molecule)

Type-ahead search input for filtering accounts by code or description.

| Prop           | Type     | Required | Default | Description                                  |
|----------------|----------|----------|---------|----------------------------------------------|
| value          | string   | Yes      | —       | Controlled search term                       |
| onChange       | function | Yes      | —       | `(term: string) => void`                     |
| onSearch       | function | Yes      | —       | Triggers GET /accounts?search={term}         |
| showInactive   | boolean  | Yes      | —       | Toggle to include inactive accounts          |
| onToggleInactive| function| Yes      | —       | Toggle callback                              |

---

### AccountList (organism)

Paginated table of GL accounts matching the current search filter.

| Prop        | Type       | Required | Default | Description                                  |
|-------------|------------|----------|---------|----------------------------------------------|
| accounts    | Account[]  | Yes      | —       | From GET /accounts                           |
| isLoading   | boolean    | No       | false   | Skeleton while loading                       |
| onEdit      | function   | Yes      | —       | Open AccountDetailForm for edit              |
| onViewBalance| function  | Yes      | —       | Open AccountBalanceView                      |

**Columns:** Account Code, Description, Type, Status (Active / Inactive badge), Actions.

---

### AccountDetailForm (organism)

Form for creating or editing a GL account. Rendered in a side panel or modal.

| Prop     | Type    | Required | Default | Description                             |
|----------|---------|----------|---------|-----------------------------------------|
| account  | Account | No       | null    | Existing account; null = new            |
| onSave   | function| Yes      | —       | POST /accounts or PUT /accounts/{id}    |
| onClose  | function| Yes      | —       | Close panel                             |

**Children:** AccountCodeInput, TextInputField (Description), AccountTypeSelect, ActiveStatusToggle.

---

### AccountCodeInput (molecule)

Structured input for account codes matching the segment pattern (e.g. `1-394-7005-008-96`). Validates format on blur and on save. Displays a format hint below the input.

| Prop         | Type     | Required | Default | Description                                       |
|--------------|----------|----------|---------|---------------------------------------------------|
| value        | string   | Yes      | —       | Controlled account code string                    |
| onChange     | function | Yes      | —       | `(code: string) => void`                          |
| hasError     | boolean  | No       | false   | Applies `border.error` and shows validation message|
| errorMessage | string   | No       | ''      | Specific format error text                        |

---

### AccountTypeSelect (molecule)

Dropdown for selecting account type.

| Prop     | Type     | Required | Default | Description                                       |
|----------|----------|----------|---------|---------------------------------------------------|
| value    | string   | Yes      | —       | One of: Asset / Liability / Equity / Revenue / Expense |
| onChange | function | Yes      | —       | `(type: string) => void`                          |

---

### ActiveStatusToggle (molecule)

Toggle switch for Active / Inactive status with a visible label.

| Prop     | Type     | Required | Default | Description                       |
|----------|----------|----------|---------|-----------------------------------|
| isActive | boolean  | Yes      | —       | Current status                    |
| onChange | function | Yes      | —       | `(isActive: boolean) => void`     |
| disabled | boolean  | No       | false   | Locked when account has balances  |

---

### AccountBalanceView (organism)

Read-only inquiry view showing an account's balance for each accounting period in a selected fiscal year.

| Prop        | Type        | Required | Default | Description                                     |
|-------------|-------------|----------|---------|-------------------------------------------------|
| account     | Account     | Yes      | —       | Account being viewed                            |
| fiscalYears | FiscalYear[]| Yes      | —       | Selector options                                |
| balances    | Balance[]   | Yes      | —       | From GET /accounts/{id}/balances                |
| isLoading   | boolean     | No       | false   | Skeleton while balances load                    |
| onClose     | function    | Yes      | —       | Return to account list                          |

**Children:** FiscalYearSelector, AccountBalanceGrid.

---

### AccountBalanceGrid (molecule)

Table showing period name, opening balance, debit, credit, and closing balance columns.

| Prop     | Type      | Required | Default | Description                              |
|----------|-----------|----------|---------|------------------------------------------|
| balances | Balance[] | Yes      | —       | One row per accounting period            |

## States

### AccountList States

| State   | Trigger              | Visual                                                   |
|---------|----------------------|----------------------------------------------------------|
| Loading | isLoading = true     | Skeleton rows                                            |
| Populated| Accounts returned   | Full table with edit and balance inquiry action links    |
| Empty   | No accounts match   | EmptyState: "No accounts found. Try a different search." |

### AccountDetailForm States

| State    | Trigger                  | Visual                                              |
|----------|--------------------------|-----------------------------------------------------|
| New      | account = null           | All fields empty; Save enabled when required fields complete |
| Editing  | account provided         | Fields pre-filled; Save enabled when any field dirty |
| Saving   | Save in flight           | Save button spinner; fields disabled               |
| Error    | Validation failure       | AccountCodeInput shows error border and message    |

### ActiveStatusToggle States

| State    | Trigger                  | Visual                                                        |
|----------|--------------------------|---------------------------------------------------------------|
| Active   | isActive = true          | Toggle on, `accent.500` track colour, "Active" label          |
| Inactive | isActive = false         | Toggle off, `neutral.300` track colour, "Inactive" label      |
| Disabled | Account has GL balances  | Greyed out; tooltip "Cannot deactivate account with balances" |

### AccountBalanceGrid States

| State   | Trigger            | Visual                                            |
|---------|--------------------|---------------------------------------------------|
| Loading | isLoading = true   | Skeleton rows for each expected period            |
| Populated| Balances returned | Table rows with monospace right-aligned amounts   |
| Empty   | No balances        | "No balance data for selected fiscal year"        |

## Accessibility

| Component               | Requirement                                                                                          |
|-------------------------|------------------------------------------------------------------------------------------------------|
| AccountMaintenancePage  | `<main>`, `<h1>` "Account Maintenance and Inquiry"                                                   |
| AccountSearchBar        | `<input type="search">` with `<label>` "Search accounts"; results region has `aria-live="polite"`   |
| AccountList             | `<table>` with `<caption>` "GL Accounts"; column headers `<th scope="col">`                         |
| AccountDetailForm       | `<form>` with `aria-label`; all inputs have associated `<label>` elements                           |
| AccountCodeInput        | Error message linked via `aria-describedby`; format hint always visible below field                  |
| AccountTypeSelect       | `<select>` with `<label>`; or combobox pattern if custom dropdown                                   |
| ActiveStatusToggle      | `role="switch"` with `aria-checked`; visible label not inside the toggle track                      |
| AccountBalanceView      | `<section>` with heading; back button `aria-label="Back to account list"`                           |
| AccountBalanceGrid      | `<table>` with `<caption>` "Account Balances"; `<th scope="col">` for period/debit/credit columns   |
| Inactive account badge  | Text label "Inactive" — not colour alone; `neutral.500` text on `neutral.100` background            |
