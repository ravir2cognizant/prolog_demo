## Overview

Components for the auto-reversal feature: the Auto Reversal Date field in the header, the scheduled-reversal indicator badge, and the read-only lock behaviour after posting. Auto Reversal Date is part of the JournalEntryHeaderForm (CI-001); this CI documents the incremental components specific to RC-005.

---

## Components

### AutoReversalDateField (molecule)

Optional date picker field for scheduling an auto-reversal. Becomes read-only after the entry is posted.

| Prop        | Type     | Required | Default | Description                                     |
|-------------|----------|----------|---------|-------------------------------------------------|
| value       | string   | No       | ''      | ISO 8601 date; empty when not scheduled         |
| isPosted    | boolean  | Yes      | —       | When true, field is read-only                   |
| minDate     | string   | No       | ''      | Transaction date — reversal must be after it    |
| onChange    | function | Yes      | —       | `(date: string) => void`                        |
| onClear     | function | Yes      | —       | Clears the reversal date (pre-post only)        |

**Reuses:** DatePickerField (CI-001). Adds a clear (×) button visible when a date is set and entry is Unposted.

---

### AutoReversalBadge (atom)

Visual indicator in the journal entry header showing that a reversal is scheduled. Displays the reversal date.

| Prop         | Type   | Required | Default | Description                                    |
|--------------|--------|----------|---------|------------------------------------------------|
| reversalDate | string | Yes      | —       | ISO 8601 date to display                       |
| visible      | boolean| Yes      | —       | Only shown when autoReversalDate is set        |

---

### ReversalEntryLink (atom)

Link rendered on the original entry after the reversal has been generated, navigating to the reversal entry.

| Prop            | Type     | Required | Default | Description                                  |
|-----------------|----------|----------|---------|----------------------------------------------|
| reversalEntryId | string   | Yes      | —       | ID of the generated reversal entry           |
| onClick         | function | Yes      | —       | Navigate to reversal entry                   |

## States

### AutoReversalDateField States

| State          | Trigger                        | Visual                                                          |
|----------------|--------------------------------|-----------------------------------------------------------------|
| Empty (default)| No date set                    | DatePickerField placeholder, no clear button                    |
| Date set       | Date value present, not posted | Date shown, clear (×) button visible on right                   |
| Posted lock    | isPosted = true                | Field read-only (`field-readonly` class), clear button hidden   |
| Error          | Reversal date before tx date   | `border.error` border, error message below                      |

### AutoReversalBadge States

| State   | Visual                                                                        |
|---------|-------------------------------------------------------------------------------|
| Hidden  | Not rendered when no reversal date                                            |
| Visible | Info-style badge with calendar icon and date; `state.infoLight` background   |
