## Overview

Components for the First / Previous / Next / Last navigation toolbar on the Journal Entry page, plus the unsaved-changes confirmation dialog shown before navigating away.

---

## Components

### JENavigationToolbar (molecule)

Horizontal toolbar with four navigation buttons. Part of the JEActionToolbar (CI-004).

| Prop           | Type     | Required | Default | Description                                    |
|----------------|----------|----------|---------|------------------------------------------------|
| isFirst        | boolean  | Yes      | —       | True when on the first entry in the result set |
| isLast         | boolean  | Yes      | —       | True when on the last entry in the result set  |
| isLoading      | boolean  | No       | false   | Disables all buttons while entry loads         |
| onFirst        | function | Yes      | —       | Navigate to first entry                        |
| onPrevious     | function | Yes      | —       | Navigate to previous entry                     |
| onNext         | function | Yes      | —       | Navigate to next entry                         |
| onLast         | function | Yes      | —       | Navigate to last entry                         |

**Children:** NavButton (×4 — First, Previous, Next, Last).

---

### NavButton (atom)

Single navigation action button with icon and accessible label.

| Prop       | Type     | Required | Default | Description                                    |
|------------|----------|----------|---------|------------------------------------------------|
| direction  | string   | Yes      | —       | "first" \| "previous" \| "next" \| "last"     |
| disabled   | boolean  | No       | false   | Disabled when at boundary or loading           |
| onClick    | function | Yes      | —       | Navigation handler                             |

Icon mapping: first → `|<`, previous → `<`, next → `>`, last → `>|`.

---

### UnsavedChangesDialog (molecule)

Confirmation modal shown when the user tries to navigate with unsaved changes.

| Prop        | Type     | Required | Default | Description                                    |
|-------------|----------|----------|---------|------------------------------------------------|
| isOpen      | boolean  | Yes      | —       | Controls dialog visibility                     |
| onSave      | function | Yes      | —       | Save then navigate                             |
| onDiscard   | function | Yes      | —       | Discard changes then navigate                  |
| onCancel    | function | Yes      | —       | Cancel navigation, remain on entry             |

---

## States

### NavButton States

| State    | Trigger                          | Visual                                                         |
|----------|----------------------------------|----------------------------------------------------------------|
| Default  | Navigation possible              | Icon button, `text.primary`, hover `neutral.100` background    |
| Disabled | At boundary (first/last)         | `text.disabled`, `cursor: not-allowed`, no hover effect        |
| Loading  | Entry loading after click        | Spinner overlay, pointer-events none                           |

### UnsavedChangesDialog States

| State  | Visual                                                                         |
|--------|--------------------------------------------------------------------------------|
| Closed | Not in DOM                                                                     |
| Open   | Modal with overlay, title "Unsaved Changes", three action buttons              |

## Accessibility

| Component              | Requirement                                                                               |
|------------------------|-------------------------------------------------------------------------------------------|
| NavButton              | `aria-label` = "First record", "Previous record", "Next record", "Last record"            |
| NavButton (disabled)   | `aria-disabled="true"` + `disabled` attribute                                             |
| JENavigationToolbar    | `role="toolbar"` with `aria-label="Journal entry navigation"`                             |
| Icons                  | All icons `aria-hidden="true"`; meaning conveyed by `aria-label` on button                |
| UnsavedChangesDialog   | `role="dialog"`, `aria-modal="true"`, `aria-label="Unsaved Changes"`                      |
| UnsavedChangesDialog   | Focus moves to first button (Save) on open; trapped inside; Escape triggers Cancel        |
| UnsavedChangesDialog   | Returns focus to the NavButton that triggered it on close                                 |
