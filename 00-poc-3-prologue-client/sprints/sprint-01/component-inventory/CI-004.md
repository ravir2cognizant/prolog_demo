# CI-004 -- Journal Entry Status and Posting Control

## Metadata

| Field        | Value        |
|--------------|--------------|
| ID           | CI-004       |
| Requirement  | RC-004       |

## Overview

Components for the posting lifecycle: the Post and Unpost action buttons, the Status/Posted read-only fields, and the inline error displayed when posting is blocked. These are part of the Journal Entry page action toolbar and header read-only section.

---

## Components

### JEActionToolbar (molecule)

Toolbar at the top or bottom of the Journal Entry page containing all primary actions: Save, Post, Unpost, and navigation controls (CI-006).

| Prop            | Type     | Required | Default | Description                                    |
|-----------------|----------|----------|---------|------------------------------------------------|
| entry           | JournalEntry | Yes  | —       | Current entry object                           |
| canPost         | boolean  | Yes      | —       | True when user has post permission             |
| canUnpost       | boolean  | Yes      | —       | True when user has unpost permission           |
| onSave          | function | Yes      | —       | Save handler                                   |
| onPost          | function | Yes      | —       | Post handler                                   |
| onUnpost        | function | Yes      | —       | Unpost handler                                 |
| isSaving        | boolean  | No       | false   | Shows spinner on Save button                   |
| isPosting       | boolean  | No       | false   | Shows spinner on Post button                   |

---

### PostButton (atom)

Primary CTA button for posting. Visible only when entry is Unposted and canPost is true.

| Prop      | Type     | Required | Default | Description                         |
|-----------|----------|----------|---------|-------------------------------------|
| disabled  | boolean  | No       | false   | Disabled when unbalanced or loading |
| loading   | boolean  | No       | false   | Shows spinner when posting          |
| onClick   | function | Yes      | —       | Triggers post action                |

---

### UnpostButton (atom)

Secondary action button for unposting. Visible only when entry is Posted and canUnpost is true.

| Prop      | Type     | Required | Default | Description                              |
|-----------|----------|----------|---------|------------------------------------------|
| disabled  | boolean  | No       | false   | Disabled when period is closed or loading|
| loading   | boolean  | No       | false   | Shows spinner when unposting             |
| onClick   | function | Yes      | —       | Triggers unpost action                   |

---

### JEStatusDisplay (molecule)

Read-only display of Status, Posted flag, Posted Date/Time, and Posted User ID within the header form.

| Prop    | Type          | Required | Default | Description         |
|---------|---------------|----------|---------|---------------------|
| entry   | JournalEntry  | Yes      | —       | Source of values    |

---

### PostingBlockedAlert (atom)

Inline error message displayed when the Post action is rejected. Receives the specific error message from the API.

| Prop      | Type    | Required | Default | Description              |
|-----------|---------|----------|---------|--------------------------|
| visible   | boolean | Yes      | —       | Show or hide             |
| message   | string  | No       | "Cannot post: journal entry is not balanced." | Error text |

## States

### PostButton States

| State     | Trigger                                 | Visual                                                 |
|-----------|-----------------------------------------|--------------------------------------------------------|
| Default   | Unposted entry, balanced                | `accent.500` bg, white text, semibold                  |
| Disabled  | Unbalanced or no post permission        | `neutral.300` bg, `neutral.500` text, cursor not-allowed|
| Loading   | Post in progress                        | Spinner icon, text "Posting…", pointer-events none     |
| Hidden    | Entry is Posted                         | Not rendered                                           |

### UnpostButton States

| State     | Trigger                                 | Visual                                                 |
|-----------|-----------------------------------------|--------------------------------------------------------|
| Default   | Posted entry, open period, canUnpost    | Outlined secondary button style                        |
| Disabled  | Period closed or no unpost permission   | `neutral.300` bg, `neutral.500` text                   |
| Loading   | Unpost in progress                      | Spinner, "Unposting…"                                  |
| Hidden    | Entry is Unposted                       | Not rendered                                           |

### JEStatusDisplay States

| Status field | Unposted                      | Posted                                   |
|--------------|-------------------------------|------------------------------------------|
| Status badge | Neutral badge "Unposted"      | Green badge "Posted" (`state.success`)   |
| Posted field | "No"                          | "Yes"                                    |
| Posted at    | — (empty)                     | Formatted timestamp in user's local timezone |
| Posted by    | — (empty)                     | User ID string                           |

## Accessibility

| Component          | Requirement                                                                           |
|--------------------|---------------------------------------------------------------------------------------|
| PostButton         | `aria-label="Post journal entry"` (button text alone may be ambiguous in context)    |
| UnpostButton       | `aria-label="Unpost journal entry"`                                                   |
| Buttons            | Keyboard accessible via Tab + Enter/Space                                             |
| Disabled buttons   | `aria-disabled="true"` AND `disabled` attribute so keyboard navigation skips them    |
| Loading state      | `aria-busy="true"` on button; spinner is `aria-hidden`; live region announces completion |
| PostingBlockedAlert| `role="alert"` for immediate announcement                                             |
| JEStatusDisplay    | Each field has a visible `<label>` or `<dt>` element; `aria-readonly="true"` on inputs|
| Status badge       | Text label in badge (not colour alone); WCAG 1.4.1 compliance                        |
