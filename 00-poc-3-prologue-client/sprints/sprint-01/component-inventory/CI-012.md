## Overview

Standalone screen for designing, running, and exporting custom GL financial reports. Two sub-views: the design builder and the report output view.

---

## Components

### FinancialReportDesignerPage (page)

Top-level page hosting either the DesignBuilder or the ReportOutput depending on route state.

**Children:** SavedReportsList, ReportDesignBuilder, ReportOutputView.

---

### SavedReportsList (molecule)

Left panel listing saved report designs. Selecting a design loads it into ReportDesignBuilder.

| Prop         | Type          | Required | Default | Description                                |
|--------------|---------------|----------|---------|--------------------------------------------|
| designs      | ReportDesign[]| Yes      | —       | From GET /report-designs                   |
| activeId     | string        | No       | ''      | Currently loaded design ID                 |
| onSelect     | function      | Yes      | —       | Load design into builder                   |
| onNewDesign  | function      | Yes      | —       | Create new blank design                    |

---

### ReportDesignBuilder (organism)

Builder UI for selecting report rows (accounts/groups) and period columns.

| Prop       | Type          | Required | Default | Description                                |
|------------|---------------|----------|---------|--------------------------------------------|
| design     | ReportDesign  | No       | null    | Current design; null = new                 |
| fiscalYears| FiscalYear[]  | Yes      | —       | Available fiscal years/periods             |
| onSave     | function      | Yes      | —       | Save design                                |
| onRun      | function      | Yes      | —       | Run and show output                        |

**Children:** ReportRowBuilder (add/remove account rows), PeriodColumnSelector, DesignNameInput, SaveButton, RunButton.

---

### ReportRowBuilder (molecule)

List of configured report rows with add/remove controls. Each row can reference an account or account group.

| Prop          | Type     | Required | Default | Description                            |
|---------------|----------|----------|---------|----------------------------------------|
| rows          | ReportRow[]| Yes   | —       | Current row definitions                |
| onRowsChange  | function | Yes      | —       | Full replacement callback              |

---

### PeriodColumnSelector (molecule)

Multi-select list of accounting periods to include as report columns.

| Prop           | Type     | Required | Default | Description                              |
|----------------|----------|----------|---------|------------------------------------------|
| fiscalYearId   | string   | Yes      | —       | Selected fiscal year                     |
| periods        | Period[] | Yes      | —       | All periods in the fiscal year           |
| selectedPeriods| string[] | Yes      | —       | Selected period IDs                      |
| onSelectionChange| function| Yes   | —       | `(periodIds: string[]) => void`          |

---

### ReportOutputView (organism)

Renders the generated report data as a table with accounts as rows and periods as columns. Export controls included.

| Prop      | Type        | Required | Default | Description                         |
|-----------|-------------|----------|---------|-------------------------------------|
| result    | ReportResult| Yes      | —       | From POST /report-designs/{id}/run  |
| onExport  | function    | Yes      | —       | `(format: 'pdf'|'xlsx') => void`    |
| onBack    | function    | Yes      | —       | Return to builder                   |

---

## States

### ReportDesignBuilder States

| State     | Visual                                                           |
|-----------|------------------------------------------------------------------|
| Empty     | No rows, no periods; Run/Save disabled                           |
| Valid     | At least 1 row and 1 period; Run/Save enabled                    |
| Saving    | Save spinner, disabled                                           |
| Running   | Run spinner; full-page loading overlay while POST in progress    |

### ReportOutputView States

| State     | Visual                                                           |
|-----------|------------------------------------------------------------------|
| Loading   | Skeleton table while report generates                            |
| Populated | Full report table with all rows and period columns               |
| Exporting | Export button shows spinner                                      |
