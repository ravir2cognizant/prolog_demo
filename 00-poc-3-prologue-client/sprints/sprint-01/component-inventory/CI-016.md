## Overview

Standalone screen for importing transaction batches from external source systems and downloading GL transactions. Import is asynchronous: the user uploads a file, the server processes it as a background job, and the UI polls for status. Completed imports show a summary panel with per-row validation errors.

---

## Components

### TransactionImportPage (page)

Top-level page for the Transaction Import and Download module.

**Children:** ImportPanel, DownloadPanel, ImportHistoryList.

---

### ImportPanel (organism)

Upload section for submitting a transaction import file and monitoring the job.

| Prop              | Type     | Required | Default | Description                                       |
|-------------------|----------|----------|---------|---------------------------------------------------|
| onUpload          | function | Yes      | —       | POST /transactions/import handler; returns jobId  |
| onPollStatus      | function | Yes      | —       | GET /transactions/import/{jobId}/status handler   |
| onFetchErrors     | function | Yes      | —       | GET /transactions/import/{jobId}/errors handler   |

**Children:** FileUploadInput, ImportProgressIndicator, ImportResultPanel.

---

### FileUploadInput (molecule)

File picker control with drag-and-drop zone. Accepts CSV and XLSX (pending OQ-042 resolution).

| Prop         | Type     | Required | Default | Description                              |
|--------------|----------|----------|---------|------------------------------------------|
| onFileSelect | function | Yes      | —       | Called with selected `File` object       |
| isUploading  | boolean  | No       | false   | Disables picker while upload is in flight|
| acceptedTypes| string   | No       | '.csv,.xlsx' | File filter for input[accept]        |

---

### ImportProgressIndicator (molecule)

Shows current job phase (Queued → Processing → Complete / Failed) and a progress bar when percentage is available.

| Prop        | Type    | Required | Default | Description                                            |
|-------------|---------|----------|---------|--------------------------------------------------------|
| jobStatus   | string  | Yes      | —       | "Queued" \| "Processing" \| "Complete" \| "Failed"     |
| progressPct | number  | No       | null    | 0–100 if server provides determinate progress          |
| totalRows   | number  | No       | null    | Total rows in file (shown during processing)           |
| processedRows| number | No       | null    | Rows processed so far                                  |

---

### ImportResultPanel (organism)

Post-import summary: success count, error count, and expandable per-row error list.

| Prop        | Type         | Required | Default | Description                               |
|-------------|--------------|----------|---------|-------------------------------------------|
| result      | ImportResult | Yes      | —       | From GET .../status when Complete         |
| errors      | ImportError[]| No       | []      | From GET .../errors; empty if all passed  |
| onReImport  | function     | Yes      | —       | Start a new import (reset state)          |

**Children:** ImportSummaryStats, ImportErrorList.

---

### ImportSummaryStats (molecule)

Two stat cards: "Imported" (success count, state.success colour) and "Failed" (error count, state.error colour).

| Prop         | Type   | Required | Default | Description            |
|--------------|--------|----------|---------|------------------------|
| successCount | number | Yes      | —       | Successfully imported rows |
| errorCount   | number | Yes      | —       | Rows with validation errors |

---

### ImportErrorList (molecule)

Scrollable list of per-row import errors. Each row shows row number, field, and error message.

| Prop   | Type          | Required | Default | Description                    |
|--------|---------------|----------|---------|--------------------------------|
| errors | ImportError[] | Yes      | —       | From GET .../errors            |

---

### DownloadPanel (molecule)

Controls for exporting GL transactions. Date range and company selectors scope the export.

| Prop        | Type       | Required | Default | Description                                  |
|-------------|------------|----------|---------|----------------------------------------------|
| companies   | Company[]  | Yes      | —       | Available companies                          |

**Fields:** Company (SelectField), From Date (DatePickerField), To Date (DatePickerField), Format (SelectField: CSV / XLSX).

---

## States

### ImportPanel States

| State       | Trigger                              | Visual                                                           |
|-------------|--------------------------------------|------------------------------------------------------------------|
| Idle        | No active job                        | FileUploadInput prominent; history list shown below             |
| Uploading   | File selected, POST in flight        | Upload progress on FileUploadInput; button disabled             |
| Processing  | jobStatus = "Processing"             | ImportProgressIndicator with progress bar; polling every 3s     |
| Complete    | jobStatus = "Complete"               | ImportResultPanel with success/error summary                    |
| Failed      | jobStatus = "Failed"                 | Error alert with retry option                                   |

### ImportProgressIndicator States

| State       | Visual                                                                     |
|-------------|----------------------------------------------------------------------------|
| Queued      | Indeterminate spinner, "Queued for processing…" text                       |
| Processing  | Determinate progress bar if pct available; "{n} of {total} rows processed" |
| Complete    | Hidden (ImportResultPanel takes over)                                      |
| Failed      | Error icon, "Import failed" message                                        |

### ImportErrorList States

| State       | Visual                                                    |
|-------------|-----------------------------------------------------------|
| No errors   | Hidden (not rendered)                                     |
| Has errors  | Scrollable list, max-height with overflow-y: auto         |

## Accessibility

| Component               | Requirement                                                                                        |
|-------------------------|----------------------------------------------------------------------------------------------------|
| TransactionImportPage   | `<main>`, `<h1>` "Transaction Import and Download"                                                 |
| FileUploadInput         | `<input type="file">` with `<label>`; drag-drop zone `role="button"` with keyboard activation     |
| ImportProgressIndicator | `role="progressbar"` with `aria-valuenow`, `aria-valuemin="0"`, `aria-valuemax="100"`; indeterminate state omits `aria-valuenow` |
| ImportProgressIndicator | `aria-live="polite"` on status text so screen readers announce phase transitions                   |
| ImportResultPanel       | `role="status"` on summary stats so counts are announced on completion                             |
| ImportErrorList         | `role="list"` with `role="listitem"` per error; each item includes row number and field name       |
| ImportSummaryStats      | Success/error distinction not by colour alone — text labels "Imported" / "Failed"                  |
| DownloadPanel           | All selects and date pickers labelled; Export button `aria-label="Export transactions"` or `aria-busy="true"` when exporting |
| ImportHistoryList       | `<table>` with `<caption>` "Import History"; column headers `<th scope="col">`                    |
