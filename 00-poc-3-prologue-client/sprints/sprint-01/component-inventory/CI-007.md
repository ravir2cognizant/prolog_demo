## Overview

Components for displaying the edit audit trail fields (Edit Date/Time, Edit User ID, Created Date/Time, Created User ID) in the journal entry header. These are always-visible read-only fields. Server sets them; client never allows editing.

---

## Components

### JEAuditTrailFields (molecule)

Displays four read-only audit fields: Edit Date/Time, Edit User ID, Created Date/Time, Created User ID. Always visible in the header form (RC-001 / CI-001).

| Prop    | Type          | Required | Default | Description                        |
|---------|---------------|----------|---------|------------------------------------|
| entry   | JournalEntry  | Yes      | —       | Source of audit field values       |

**Children:** AuditFieldDisplay (×4).

---

### AuditFieldDisplay (atom)

Single labelled read-only field for one audit value.

| Prop       | Type   | Required | Default | Description                                      |
|------------|--------|----------|---------|--------------------------------------------------|
| label      | string | Yes      | —       | Visible field label                              |
| value      | string | No       | ''      | Field value; empty string when not yet set       |
| isDateTime | boolean| No       | false   | When true, formats value as local date/time       |

---

## States

### JEAuditTrailFields States

| State       | Visual                                                                    |
|-------------|---------------------------------------------------------------------------|
| New entry   | Edit Date/Time and Edit User ID empty; Created fields also empty          |
| After save  | Edit Date/Time shows current timestamp; Edit User ID shows current user ID|
| Read-only   | Always read-only; `field-readonly` CSS class applied; cursor: default     |

### AuditFieldDisplay States

| State     | Visual                                                                   |
|-----------|--------------------------------------------------------------------------|
| Empty     | Greyed placeholder dash "—"                                              |
| Populated | Value in `text.primary`; timestamp formatted per user's local timezone   |

---

## Accessibility

| Component          | Requirement                                                                   |
|--------------------|-------------------------------------------------------------------------------|
| JEAuditTrailFields | Group with `<fieldset>` and `<legend>` "Audit Information" or equivalent      |
| AuditFieldDisplay  | Each field uses `<label>` + associated read-only `<input>`; `aria-readonly="true"` |
| DateTime display   | Value rendered as human-readable formatted date/time, not raw ISO string      |
| Read-only cursor   | `cursor: default` and `user-select: text` so values can be copied             |
| Screen reader      | Audit fields visible in tab order with descriptive labels                     |
