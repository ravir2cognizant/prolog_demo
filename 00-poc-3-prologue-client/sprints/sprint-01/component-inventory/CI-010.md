# CI-010 -- Accruals and Prepaid Journal Entry Management

## Overview

Standalone screen for managing accrual/prepaid journal entry schedules: create, view, edit, and cancel recurring entry schedules, and view the list of generated entries per schedule.

---

## Components

### AccrualsPrepaidPage (page)

Top-level page for the Accruals/Prepaid module. Shows list of schedules with create action.

**Children:** AccrualScheduleList, CreateScheduleButton.

---

### AccrualScheduleList (organism)

List of all accrual/prepaid schedules with status and entry count.

| Prop         | Type               | Required | Default | Description                         |
|--------------|--------------------|----------|---------|-------------------------------------|
| schedules    | AccrualSchedule[]  | Yes      | —       | Loaded from GET /accrual-schedules  |
| isLoading    | boolean            | No       | false   | Shows skeleton while loading        |
| onView       | function           | Yes      | —       | Navigate to schedule detail         |
| onCancel     | function           | Yes      | —       | Cancel a schedule                   |

---

### AccrualScheduleForm (organism)

Form for creating or editing an accrual/prepaid schedule. Uses a modal or side panel.

| Prop       | Type              | Required | Default | Description                             |
|------------|-------------------|----------|---------|-----------------------------------------|
| schedule   | AccrualSchedule   | No       | null    | Existing schedule for edit; null = new  |
| onSave     | function          | Yes      | —       | POST or PUT handler                     |
| onClose    | function          | Yes      | —       | Close form                              |
| companies  | Company[]         | Yes      | —       | Available companies                     |

**Fields:** Description (TextInputField), Schedule Type (SelectField: Monthly/Quarterly/Custom), Start Date (DatePickerField), End Date (DatePickerField optional), Base Entry (embedded JE header + lines form, CI-001 / CI-002 components reused).

---

### AccrualScheduleDetail (organism)

Detail view for a single schedule: header metadata + list of generated entries.

| Prop     | Type             | Required | Default | Description                      |
|----------|------------------|----------|---------|----------------------------------|
| schedule | AccrualSchedule  | Yes      | —       | Schedule data                    |
| entries  | JESum[]          | Yes      | —       | From GET /accrual-schedules/{id}/entries |
| onCancel | function         | Yes      | —       | Cancel this schedule             |
| onEdit   | function         | Yes      | —       | Open edit form                   |

---

## States

### AccrualScheduleList States

| State    | Visual                                                           |
|----------|------------------------------------------------------------------|
| Loading  | Skeleton rows                                                    |
| Populated| Schedule rows with status badge (Active/Cancelled)              |
| Empty    | EmptyState: "No accrual schedules defined"                       |

### AccrualScheduleForm States

| State       | Visual                                                          |
|-------------|-----------------------------------------------------------------|
| Empty (new) | All fields blank, Save disabled                                 |
| Valid        | Save button enabled                                             |
| Saving       | Save button shows spinner, disabled                             |
| Error        | Field-level validation messages                                 |

| AccrualsPrepaidPage    | `<main>`, `<h1>` "Accruals and Prepaid Management"                                  |
