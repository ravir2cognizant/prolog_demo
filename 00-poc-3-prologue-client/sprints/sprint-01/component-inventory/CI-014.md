## Overview

Standalone screen for managing GL data consolidation: configure source connections, run consolidation, and view run history and per-source error reports.

---

## Components

### ConsolidationPage (page)

Top-level page for the GL Data Consolidation module.

**Children:** ConsolidationSourceList, AddSourceButton, RunConsolidationPanel, ConsolidationRunHistory.

---

### ConsolidationSourceList (organism)

List of configured consolidation source connections with status and last-run timestamp.

| Prop      | Type     | Required | Default | Description                                  |
|-----------|----------|----------|---------|----------------------------------------------|
| sources   | Source[] | Yes      | —       | From GET /consolidation/sources              |
| isLoading | boolean  | No       | false   | Skeleton while loading                       |
| onAddSource| function| Yes      | —       | Open add-source form                         |

---

### AddSourceForm (molecule)

Form for adding a new consolidation source. Rendered in a side panel or modal.

| Prop     | Type     | Required | Default | Description                             |
|----------|----------|----------|---------|-----------------------------------------|
| onSave   | function | Yes      | —       | POST /consolidation/sources handler     |
| onClose  | function | Yes      | —       | Close form                              |

**Fields:** Name (TextInputField), Source Type (SelectField: Database / File).

---

### RunConsolidationPanel (molecule)

Panel with fiscal year selector and Run Consolidation button.

| Prop        | Type        | Required | Default | Description                             |
|-------------|-------------|----------|---------|-----------------------------------------|
| fiscalYears | FiscalYear[]| Yes      | —       | Available fiscal years                  |
| isRunning   | boolean     | No       | false   | Shows progress indicator                |
| onRun       | function    | Yes      | —       | `(fiscalYearId: string) => void`        |
| lastRunStatus | string   | No       | ''      | Status of most recent run               |

---

### ConsolidationRunHistory (organism)

Paginated list of past consolidation runs with status and entry-count summary.

| Prop     | Type    | Required | Default | Description                                |
|----------|---------|----------|---------|--------------------------------------------|
| runs     | Run[]   | Yes      | —       | From GET /consolidation/runs               |
| onViewReport | function | Yes | —     | Open per-source error report for a run    |

---

### ConsolidationRunReport (organism)

Detail view for a single run: per-source results and error list.

| Prop   | Type    | Required | Default | Description                                |
|--------|---------|----------|---------|--------------------------------------------|
| report | RunReport| Yes     | —       | From GET /consolidation/runs/{id}/report   |
| onClose| function| Yes      | —       | Close report view                          |

---

## States

### RunConsolidationPanel States

| State     | Visual                                                           |
|-----------|------------------------------------------------------------------|
| Idle      | Run button enabled (if fiscal year selected)                     |
| Running   | Progress bar or spinner; Run button disabled; "Consolidation in progress…" |
| Completed | Status badge "Completed" or "Partial Success"; Run button re-enabled |
| Failed    | Error alert with link to run report                              |

### ConsolidationRunReport States

| State     | Visual                                                           |
|-----------|------------------------------------------------------------------|
| No errors | Per-source rows all show "Success" in green badge                |
| Partial   | Mixed success/failed rows; error rows expandable to show details |
| All failed| All rows show "Failed" badge and error details                   |

## Accessibility

| Component               | Requirement                                                                     |
|-------------------------|---------------------------------------------------------------------------------|
| ConsolidationPage       | `<main>`, `<h1>` "GL Data Consolidation"                                        |
| ConsolidationSourceList | `<table>` with column headers; keyboard-navigable                               |
| RunConsolidationPanel   | Progress indicator uses `role="progressbar"` with `aria-valuenow` if determinate |
| ConsolidationRunHistory | `<table>` with `<caption>` "Consolidation Run History"                          |
| ConsolidationRunReport  | `<table>` per-source; error lists use `role="list"`                             |
| Run button              | `aria-label="Run GL consolidation"` or `aria-busy="true"` when running          |
| Error badges            | Text labels not colour alone; "Failed", "Success", "Partial"                    |
