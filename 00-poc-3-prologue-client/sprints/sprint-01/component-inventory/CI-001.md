## Overview

This CI covers the Journal Entry header form: the top section of the Journal Entry page that captures Company ID, Entry Type, Transaction Date, Description, and related reference fields. RC-001 through RC-008 all live on this same page; CI-001 covers the header form organism and its reference-data dropdowns.

---

## Components

### JournalEntryPage (page)

Top-level page component. Composes the header form, lines grid, totals row, and action toolbar.

| Prop          | Type       | Required | Default  | Description                               |
|---------------|------------|----------|----------|-------------------------------------------|
| entryId       | string     | No       | undefined | Existing JE ID; undefined for new entry  |
| companyId     | string     | No       | undefined | Pre-selected company from context         |

**Events:** mounts → calls GET /journal-entries/{id} (edit) or initialises blank form (new).

---

### JournalEntryHeaderForm (organism)

Multi-field header form. Renders two rows of fields and a set of read-only audit fields.

| Prop           | Type          | Required | Default | Description                                    |
|----------------|---------------|----------|---------|------------------------------------------------|
| entry          | JournalEntry  | Yes      | —       | Current journal entry object                   |
| isPosted       | boolean       | Yes      | —       | When true, all fields are read-only            |
| onFieldChange  | function      | Yes      | —       | `(field, value) => void`                       |
| companies      | Company[]     | Yes      | —       | Available company list (from GET /companies)   |
| entryTypes     | EntryType[]   | Yes      | —       | Available entry types                          |
| sourceDocuments| SourceDoc[]   | Yes      | —       | Available source document types                |
| allocationMethods | AllocMethod[] | Yes | —      | Available allocation methods                   |

**Children:** CompanyDropdown, EntryTypeDropdown, DatePickerField (×2), TextInputField, SourceDocumentDropdown, AllocationMethodDropdown, ReadOnlyAuditFields

## States

### JournalEntryHeaderForm States

| State          | Trigger                               | Visual Change                                                        |
|----------------|---------------------------------------|----------------------------------------------------------------------|
| New entry      | entryId = undefined                   | All editable fields blank; Status = "Unposted"; ID field empty       |
| Editing        | entry loaded, isPosted = false        | All fields editable; save/post actions available                     |
| Posted (locked)| isPosted = true                       | All fields read-only (`field-readonly` class); Post button hidden; Unpost shown |
| Saving         | save in progress                      | Submit button shows spinner, disabled; fields remain visible         |
| Validation error| save attempted with invalid fields   | Fields with errors show `border.error` border + error message below  |

### Dropdown States

| State    | Visual                                                                      |
|----------|-----------------------------------------------------------------------------|
| Default  | White bg, `border.default` border, placeholder text in `text.placeholder`  |
| Focus    | `border.focus` (`primary.500`) 2px outline                                  |
| Open     | Dropdown panel below with `shadows.md`, `radii.md`, filtered list           |
| Selected | Value shown in field; no placeholder                                        |
| Disabled | `neutral.100` bg, `text.disabled` text, no hover/focus change               |
| Error    | `border.error` border, error message below                                  |

### DatePickerField States

| State    | Visual                                                                      |
|----------|-----------------------------------------------------------------------------|
| Default  | White bg, `border.default`, calendar icon in `accent.500` on right          |
| Focus    | `border.focus` outline on input                                              |
| Open     | Native or custom calendar panel                                              |
| Disabled | `neutral.100` bg, calendar icon muted (`neutral.400`)                        |
| Error    | `border.error` border, error message below                                  |

## Accessibility

| Component             | Requirement                                                                                 |
|-----------------------|---------------------------------------------------------------------------------------------|
| JournalEntryHeaderForm| `<form>` element with `aria-label="Journal Entry Header"`                                   |
| All dropdowns         | Use `<select>` or ARIA combobox pattern (`role="combobox"`, `aria-expanded`, `aria-controls`)|
| All dropdowns         | Support type-ahead keyboard search within open dropdown                                     |
| DatePickerField       | `<input type="date">` or labelled trigger button; calendar icon is `aria-hidden="true"`     |
| DatePickerField       | Date value readable by screen reader as formatted date, not ISO string                      |
| TextInputField        | `<label for>` association required; never rely on placeholder as only label                 |
| ReadOnlyAuditFields   | Each field has a visible label; `aria-readonly="true"` on read-only inputs                  |
| Error messages        | `role="alert"` or linked via `aria-describedby` so screen readers announce on appearance    |
| Focus order           | Logical top-left to bottom-right: Company → Type → ID → Status → TxDate → AutoRevDate → Description → SourceDoc → AllocationMethod → Routing |
| Keyboard navigation   | Tab between fields; Enter/Space to open dropdowns; Escape to close                          |
| Contrast              | All label text meets 4.5:1 vs background (`text.primary` on white = 16:1+)                  |
