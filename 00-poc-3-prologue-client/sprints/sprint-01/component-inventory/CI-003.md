## Overview

Components for the totals row below the journal entry lines grid and the inline balance validation messages. Totals (Total Debit, Total Credit, Difference) are calculated client-side from line data. Server-side validation is documented in ED-003. RC-003 is primarily a display concern; these components are rendered as part of the Journal Entry page.

---

## Components

### JEBalanceTotalsRow (molecule)

Sticky totals row rendered below the lines grid. Displays computed Total Debit, Total Credit, and Difference. Updates without a save action.

| Prop          | Type    | Required | Default | Description                                    |
|---------------|---------|----------|---------|------------------------------------------------|
| totalDebit    | number  | Yes      | —       | Sum of all line debit amounts                  |
| totalCredit   | number  | Yes      | —       | Sum of all line credit amounts                 |
| difference    | number  | Yes      | —       | totalDebit minus totalCredit                   |
| isBalanced    | boolean | Yes      | —       | true when difference === 0                     |

**Children:** TotalsCell (×3), BalanceIndicator.

---

### TotalsCell (atom)

Single labelled numeric cell in the totals row. Renders label + formatted value.

| Prop      | Type    | Required | Default | Description                                   |
|-----------|---------|----------|---------|-----------------------------------------------|
| label     | string  | Yes      | —       | "Total Debit", "Total Credit", or "Difference"|
| value     | number  | Yes      | —       | Numeric value                                 |
| isError   | boolean | No       | false   | True for Difference cell when unbalanced      |

---

### BalanceIndicator (atom)

Visual indicator displayed alongside the Difference cell. Green check when balanced; red warning icon when unbalanced.

| Prop       | Type    | Required | Default | Description                    |
|------------|---------|----------|---------|--------------------------------|
| isBalanced | boolean | Yes      | —       | Controls icon and colour       |

---

### BalanceValidationMessage (atom)

Inline banner shown when a save or post is blocked due to an unbalanced entry.

| Prop      | Type    | Required | Default | Description                                      |
|-----------|---------|----------|---------|--------------------------------------------------|
| visible   | boolean | Yes      | —       | Shows or hides the message                       |
| message   | string  | No       | "Journal entry is not balanced. Total debits must equal total credits." | Message text |

## States

### JEBalanceTotalsRow States

| State      | Trigger              | Visual Change                                                           |
|------------|----------------------|-------------------------------------------------------------------------|
| Balanced   | difference === 0     | Difference cell: `text.primary`, no warning; BalanceIndicator green     |
| Unbalanced | difference !== 0     | Difference cell: `state.error` text on `state.errorLight` bg; red icon  |

### TotalsCell States

| State   | Visual                                                            |
|---------|-------------------------------------------------------------------|
| Default | Right-aligned, semibold, monospace, `neutral.100` row background  |
| Error   | `state.errorLight` background, `state.error` text (Difference only)|

### BalanceValidationMessage States

| State   | Visual                                                            |
|---------|-------------------------------------------------------------------|
| Hidden  | `display: none` (not in DOM or height 0)                          |
| Visible | `state.errorLight` bg, `state.error` text, warning icon, `radii.md`|

## Accessibility

| Component               | Requirement                                                                              |
|-------------------------|------------------------------------------------------------------------------------------|
| JEBalanceTotalsRow      | Rendered as a `<tfoot>` row inside the lines `<table>` for correct screen reader grouping|
| TotalsCell              | `<th scope="row">` for labels; `<td>` for values; `aria-label` includes label + value   |
| BalanceIndicator        | Icon is `aria-hidden="true"`; state communicated via text and colour, not icon alone     |
| BalanceValidationMessage| `role="alert"` so screen readers announce the message immediately on appearance          |
| Difference (unbalanced) | Must not use colour as the sole indicator; icon + text "Unbalanced" label also present  |
| Contrast                | `state.error` (#C62828) on `state.errorLight` (#FFEBEE) meets 4.5:1 minimum             |
| Live region             | Wrap totals row in `aria-live="polite"` region so recalculations are announced           |
| Motion reduction        | No animation on value updates; updates are instant per RC-003 NFR                        |
