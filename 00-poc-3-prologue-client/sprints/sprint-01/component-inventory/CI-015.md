# CI-015 -- Fiscal Year and Accounting Period Control

## Overview

Standalone screen for finance administrators to define fiscal years, open/close individual accounting periods, and perform year-end close. Provides an at-a-glance calendar view of all period statuses.

---

## Components

### FiscalYearControlPage (page)

Top-level page for Fiscal Year and Period Control.

**Children:** FiscalYearList, FiscalYearDetail (selected year), YearEndCloseButton.

---

### FiscalYearList (molecule)

List/select of defined fiscal years. Selecting a year loads its periods.

| Prop           | Type         | Required | Default | Description                              |
|----------------|--------------|----------|---------|------------------------------------------|
| fiscalYears    | FiscalYear[] | Yes      | —       | From GET /fiscal-years                   |
| selectedId     | string       | No       | ''      | Currently selected fiscal year ID        |
| onSelect       | function     | Yes      | —       | `(fiscalYearId: string) => void`         |
| onCreateNew    | function     | Yes      | —       | Open create-year form                    |

---

### FiscalYearDetail (organism)

Shows period calendar grid and individual period open/close controls for the selected fiscal year.

| Prop        | Type         | Required | Default | Description                           |
|-------------|--------------|----------|---------|---------------------------------------|
| fiscalYear  | FiscalYear   | Yes      | —       | Selected fiscal year data             |
| periods     | Period[]     | Yes      | —       | From GET /fiscal-years/{id}/periods   |
| canEdit     | boolean      | Yes      | —       | True if user has finance-administrator role |
| onOpenPeriod | function    | Yes      | —       | `(periodId: string) => void`          |
| onClosePeriod| function    | Yes      | —       | `(periodId: string) => void`          |

**Children:** PeriodCalendarGrid, PeriodRow (×n), YearEndCloseButton.

---

### PeriodCalendarGrid (molecule)

Visual calendar showing all periods with colour-coded Open/Closed status badges.

| Prop     | Type     | Required | Default | Description                             |
|----------|----------|----------|---------|-----------------------------------------|
| periods  | Period[] | Yes      | —       | Ordered list of periods                 |
| canEdit  | boolean  | Yes      | —       | Shows open/close buttons when true      |

---

### PeriodRow (molecule)

Single period row: period name, date range, status badge, and open/close action button.

| Prop         | Type    | Required | Default | Description                                |
|--------------|---------|----------|---------|--------------------------------------------|
| period       | Period  | Yes      | —       | Period data object                         |
| canEdit      | boolean | Yes      | —       | Shows action button when true              |
| onOpen       | function| Yes      | —       | Open this period                           |
| onClose      | function| Yes      | —       | Close this period                          |

---

### YearEndCloseButton (atom)

Initiates year-end close for the selected fiscal year. Only enabled when all periods are closed.

| Prop       | Type     | Required | Default | Description                                 |
|------------|----------|----------|---------|---------------------------------------------|
| disabled   | boolean  | Yes      | —       | Disabled when any period is still open      |
| loading    | boolean  | No       | false   | Shows spinner during year-end close process |
| onClick    | function | Yes      | —       | Opens confirmation dialog before proceeding |

---

### CreateFiscalYearForm (organism)

Form for creating a new fiscal year. Rendered in a modal.

| Prop     | Type     | Required | Default | Description                              |
|----------|----------|----------|---------|------------------------------------------|
| onSave   | function | Yes      | —       | POST /fiscal-years handler               |
| onClose  | function | Yes      | —       | Close modal                              |

**Fields:** Year Name (TextInputField), Start Date (DatePickerField), End Date (DatePickerField), Period Count (SelectField: 12/13).

---

## States

### PeriodRow States

| State   | Trigger           | Visual                                                         |
|---------|-------------------|----------------------------------------------------------------|
| Open    | period.status = "Open"  | Green "Open" badge; "Close Period" button visible         |
| Closed  | period.status = "Closed" | Neutral "Closed" badge; "Open Period" button visible      |
| Loading | Action in progress | Action button shows spinner                                    |

### YearEndCloseButton States

| State    | Trigger                     | Visual                                          |
|----------|-----------------------------|--------------------------------------------------|
| Disabled | Any period still Open       | `neutral.300` bg, `neutral.500` text, cursor not-allowed |
| Enabled  | All periods Closed          | `accent.500` bg, white text                     |
| Loading  | Year-end close in progress  | Spinner, disabled                                |

## Accessibility

| Component               | Requirement                                                                      |
|-------------------------|----------------------------------------------------------------------------------|
| FiscalYearControlPage   | `<main>`, `<h1>` "Fiscal Year and Period Control"                                |
| FiscalYearList          | `<nav>` or listbox; `aria-selected` on selected year                            |
| PeriodCalendarGrid      | `<table>` or `role="grid"` with period columns and accessible labels            |
| PeriodRow               | Open/Close button `aria-label="Open period {name}"` / `"Close period {name}"`  |
| YearEndCloseButton      | `aria-disabled="true"` and `disabled` when periods open; confirm dialog before action |
| Status badges           | Text labels "Open" / "Closed" — not colour alone                                |
| Confirm dialog          | `role="dialog"`, `aria-modal`, focus trap, `aria-label="Confirm Year-End Close"` |
