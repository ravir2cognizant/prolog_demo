# CI-009 -- Journal Entry Financial Review

## Overview

Standalone screen for reviewing journal entries before period close. A filterable list with date range, company, type and status filters. Opens full JE detail on row click.

---

## Components

### FinancialReviewPage (page)

Top-level page for the Journal Entry Financial Review screen.

**Children:** FinancialReviewFilters, JEReviewList, ExportButton.

---

### FinancialReviewFilters (molecule)

Filter panel with date range, company, entry type, status, and open-questions toggle.

| Prop           | Type     | Required | Default | Description                              |
|----------------|----------|----------|---------|------------------------------------------|
| filters        | object   | Yes      | —       | Current filter values                    |
| companies      | Company[]| Yes      | —       | Available companies                      |
| entryTypes     | EntryType[]| Yes   | —       | Available entry types                    |
| onFiltersChange| function | Yes      | —       | `(filters) => void`                      |
| onApply        | function | Yes      | —       | Trigger list refresh                     |
| onReset        | function | Yes      | —       | Reset all filters to defaults            |

**Children:** DateRangeFilter, SelectFilter (×3: company, type, status), CheckboxFilter (open questions), ApplyButton, ResetButton.

---

### DateRangeFilter (molecule)

Two DatePickerField components (From Date, To Date) with validation that toDate >= fromDate.

---

### JEReviewList (organism)

Paginated/scrollable list of journal entry summaries. Each row links to the full JE detail.

| Prop          | Type     | Required | Default | Description                              |
|---------------|----------|----------|---------|------------------------------------------|
| entries       | JESum[]  | Yes      | —       | Journal entry summary objects            |
| isLoading     | boolean  | No       | false   | Shows skeleton rows while loading        |
| onRowClick    | function | Yes      | —       | `(entryId: string) => void`              |
| totalCount    | integer  | Yes      | —       | Total matching entries for pagination    |

**Children:** JEReviewRow (×n), LoadingSkeleton (loading state), EmptyState, Pagination.

---

### JEReviewRow (molecule)

Single row showing: Entry ID, Transaction Date, Description, Entry Type, Total Debit, Total Credit, Status badge, open-question indicator.

| Prop       | Type    | Required | Default | Description                              |
|------------|---------|----------|---------|------------------------------------------|
| entry      | JESum   | Yes      | —       | Journal entry summary                    |
| onClick    | function| Yes      | —       | Navigate to detail                       |

---

### ExportButton (atom)

Triggers download of the filtered list. Opens a format picker popover (CSV / XLSX).

| Prop      | Type     | Required | Default | Description                    |
|-----------|----------|----------|---------|--------------------------------|
| disabled  | boolean  | No       | false   | Disabled when list is loading  |
| onClick   | function | Yes      | —       | `(format: 'csv'|'xlsx') => void` |

---

## States

### JEReviewList States

| State     | Trigger               | Visual                                              |
|-----------|-----------------------|-----------------------------------------------------|
| Loading   | Filters applied, fetching | Skeleton rows in place of real rows            |
| Populated | Data received         | Real rows rendered                                  |
| Empty     | No matching entries   | EmptyState: "No journal entries match your filters" |
| Error     | API error             | Error alert with retry action                       |

### JEReviewRow States

| State        | Visual                                                               |
|--------------|----------------------------------------------------------------------|
| Default      | White row, hover `primary.50` background                             |
| Open question| Small flag icon in last column, `state.warning` colour              |
| Selected     | `primary.100` background, left border `primary.500`                  |

## Accessibility

| Component            | Requirement                                                                              |
|----------------------|------------------------------------------------------------------------------------------|
| FinancialReviewPage  | `<main>` with `<h1>` "Journal Entry Financial Review"                                    |
| FinancialReviewFilters | `<form>` with `aria-label="Filter journal entries"`                                    |
| JEReviewList         | `role="table"` or `<table>` with `<caption>` and column headers `scope="col"`           |
| JEReviewRow          | `role="row"` or `<tr>`; Enter/click navigates to detail                                  |
| JEReviewRow          | `aria-label` includes entry ID and date for screen reader row identification             |
| Open question flag   | `aria-label="Has open questions"` on flag icon; not colour alone                         |
| Pagination           | `aria-label="Journal entry list pagination"`; current page announced                    |
| ExportButton         | `aria-label="Export journal entry list"`; popover is `role="menu"`                       |
| Loading skeleton     | `aria-busy="true"` on list container while loading                                       |
| EmptyState           | Accessible `<p>` message; no `aria-hidden`                                               |
