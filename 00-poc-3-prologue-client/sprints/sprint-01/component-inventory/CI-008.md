# CI-008 -- Journal Entry Routing and Approval Workflow

## Metadata

| Field        | Value        |
|--------------|--------------|
| ID           | CI-008       |

## Overview

Components for the routing/approval workflow: the Routing field in the header, routing status indicator, submit-for-approval action, and the separate approval queue screen. Approval queue is a standalone page route.

---

## Components

### RoutingField (molecule)

Dropdown or text input in the JE header for selecting a routing rule. Part of JournalEntryHeaderForm (CI-001).

| Prop          | Type          | Required | Default | Description                                    |
|---------------|---------------|----------|---------|------------------------------------------------|
| value         | string        | No       | ''      | Selected routing rule ID                       |
| options       | RoutingRule[] | Yes      | —       | Available routing rules from GET /routing-rules|
| disabled      | boolean       | No       | false   | Read-only when posted or pending approval      |
| onChange      | function      | Yes      | —       | `(ruleId: string) => void`                     |
| optional      | boolean       | No       | true    | Routing is optional                            |

---

### RoutingStatusBadge (atom)

Badge displayed in the JE header showing the current approval/routing state.

| Prop   | Type   | Required | Default | Description                                         |
|--------|--------|----------|---------|-----------------------------------------------------|
| status | string | Yes      | —       | "Unposted" \| "PendingApproval" \| "Approved" \| "Posted" |

Status → badge colour mapping:
- PendingApproval → `state.warningLight` + `state.warning`
- Approved → `state.successLight` + `state.success`
- Unposted / Posted → neutral

---

### SubmitForApprovalButton (atom)

Action button to submit the JE to the routing workflow.

| Prop      | Type     | Required | Default | Description                                      |
|-----------|----------|----------|---------|--------------------------------------------------|
| disabled  | boolean  | No       | false   | Disabled when no routing rule selected           |
| loading   | boolean  | No       | false   | Shows spinner during submission                  |
| onClick   | function | Yes      | —       | Calls POST /journal-entries/{id}/submit-for-approval |

---

### ApprovalQueuePage (page)

Standalone page listing journal entries pending approval for the current user.

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| — (data loaded by page itself via GET /journal-entries?pendingApproval=true) | | | | |

**Children:** ApprovalQueueFilter, ApprovalQueueList, ApprovalQueueRow.

---

### ApprovalQueueRow (molecule)

Single row in the approval queue list showing entry summary and Approve/Reject actions.

| Prop       | Type          | Required | Default | Description                              |
|------------|---------------|----------|---------|------------------------------------------|
| entry      | JournalEntry  | Yes      | —       | Journal entry summary                    |
| onApprove  | function      | Yes      | —       | Calls POST /journal-entries/{id}/approve |
| onReject   | function      | Yes      | —       | Opens rejection reason dialog            |
| onView     | function      | Yes      | —       | Navigate to full entry detail            |

---

### RejectionReasonDialog (molecule)

Modal dialog prompting the approver to enter a mandatory rejection reason before rejecting an entry.

| Prop       | Type     | Required | Default | Description                              |
|------------|----------|----------|---------|------------------------------------------|
| isOpen     | boolean  | Yes      | —       | Controls dialog visibility               |
| onConfirm  | function | Yes      | —       | `(reason: string) => void`               |
| onCancel   | function | Yes      | —       | Close without rejecting                  |

## States

### RoutingField States

| State           | Visual                                                          |
|-----------------|-----------------------------------------------------------------|
| Empty           | Placeholder "Select routing rule (optional)"                   |
| Rule selected   | Rule name shown in field                                        |
| Pending/Posted  | Field disabled (`field-readonly`), no dropdown                 |

### RoutingStatusBadge States

| Status          | Badge Colour                                                    |
|-----------------|-----------------------------------------------------------------|
| Unposted        | `neutral.100` bg, `text.secondary`                             |
| PendingApproval | `state.warningLight` bg, `state.warning` text, clock icon      |
| Approved        | `state.successLight` bg, `state.success` text, checkmark icon  |
| Posted          | `state.successLight` bg, `state.success` text                  |

### RejectionReasonDialog States

| State           | Visual                                                          |
|-----------------|-----------------------------------------------------------------|
| Closed          | Not in DOM                                                      |
| Open, empty     | Textarea empty, Confirm button disabled                        |
| Open, filled    | Confirm button enabled                                          |
| Submitting      | Confirm button shows spinner                                    |

## Accessibility

| Component               | Requirement                                                                           |
|-------------------------|---------------------------------------------------------------------------------------|
| RoutingField            | `<label>` "Routing (optional)"; combobox or `<select>` pattern                       |
| RoutingStatusBadge      | Text label in badge not colour-only; `aria-label="Approval status: {status}"`         |
| SubmitForApprovalButton | `aria-label="Submit journal entry for approval"`                                      |
| ApprovalQueuePage       | `<main>` landmark with `<h1>` "Approval Queue"                                        |
| ApprovalQueueRow        | Approve/Reject buttons have `aria-label` including entry ID                            |
| RejectionReasonDialog   | `role="dialog"`, `aria-modal="true"`, `aria-label="Rejection Reason"`                 |
| RejectionReasonDialog   | Focus on textarea on open; focus trap; Escape triggers Cancel                         |
| Rejection textarea      | `aria-label="Rejection reason (required)"`, `aria-required="true"`                    |
