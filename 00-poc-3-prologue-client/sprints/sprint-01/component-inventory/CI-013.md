## Overview

Standalone screen for viewing, editing, importing, and exporting GL budget data. Budget amounts are displayed in an accounts × periods grid. Supports inline editing, bulk paste, file import, and export.

---

## Components

### BudgetManagementPage (page)

Top-level page for the Budget Management module.

**Children:** BudgetFilters, BudgetGrid, BudgetImportButton, BudgetExportButton.

---

### BudgetFilters (molecule)

Company and fiscal year selectors that scope the budget grid.

| Prop           | Type       | Required | Default | Description                              |
|----------------|------------|----------|---------|------------------------------------------|
| companies      | Company[]  | Yes      | —       | Available companies                      |
| fiscalYears    | number[]   | Yes      | —       | Available fiscal years                   |
| selectedCompanyId | string  | Yes      | —       | Current company selection                |
| selectedFiscalYear| number  | Yes      | —       | Current fiscal year selection            |
| onCompanyChange| function   | Yes      | —       | `(companyId: string) => void`            |
| onYearChange   | function   | Yes      | —       | `(year: number) => void`                 |

---

### BudgetGrid (organism)

Spreadsheet-like editable grid. Rows = GL accounts; Columns = accounting periods.

| Prop           | Type            | Required | Default | Description                               |
|----------------|-----------------|----------|---------|-------------------------------------------|
| rows           | BudgetRow[]     | Yes      | —       | Account rows with period budget amounts   |
| periods        | Period[]        | Yes      | —       | Period column definitions                 |
| isLoading      | boolean         | No       | false   | Shows skeleton while loading              |
| onCellChange   | function        | Yes      | —       | `(accountId, periodId, amount) => void`   |
| onBulkPaste    | function        | Yes      | —       | Handles spreadsheet paste event           |

**Children:** BudgetGridHeader, BudgetGridRow (×n), LoadingSkeleton.

---

### BudgetGridRow (molecule)

One editable account row: account code + description in first column, BudgetAmountCell per period.

---

### BudgetAmountCell (atom)

Inline editable numeric cell for a single budget amount.

| Prop        | Type     | Required | Default | Description                            |
|-------------|----------|----------|---------|----------------------------------------|
| value       | number   | Yes      | —       | Current budget amount                  |
| onChange    | function | Yes      | —       | `(amount: number) => void`             |
| isModified  | boolean  | No       | false   | Visual dirty indicator (unsaved)       |

---

### BudgetImportButton (molecule)

File upload button with format info tooltip. Opens a file picker for CSV or XLSX. Shows import results (ImportResultPanel) after completion.

| Prop     | Type     | Required | Default | Description                         |
|----------|----------|----------|---------|-------------------------------------|
| companyId| string   | Yes      | —       | Target company for import           |
| fiscalYear| number  | Yes      | —       | Target fiscal year for import       |
| onImportComplete | function | Yes | —  | Refresh grid after import           |

---

### ImportResultPanel (molecule)

Shows import summary: success count, error count, and per-row error list.

| Prop        | Type     | Required | Default | Description                        |
|-------------|----------|----------|---------|------------------------------------|
| result      | ImportResult | Yes | —     | From POST /budgets/import response |
| onClose     | function | Yes      | —       | Dismiss panel                      |

## States

### BudgetGrid States

| State     | Visual                                                          |
|-----------|-----------------------------------------------------------------|
| Loading   | Skeleton rows for all accounts                                  |
| Populated | All cells editable inline                                       |
| Modified  | Modified cells show subtle `primary.50` background             |
| Saving    | Save button spinner; cells remain editable                      |
| Empty     | EmptyState: "No budget data for selected company/year"          |

### BudgetAmountCell States

| State     | Visual                                                          |
|-----------|-----------------------------------------------------------------|
| Default   | Value formatted with commas; right-aligned; monospace           |
| Focused   | `border.focus` outline; raw number editable                     |
| Modified  | Light `primary.50` background (unsaved indicator)              |
| Error     | `border.error`; non-numeric input rejected                      |

## Accessibility

| Component           | Requirement                                                                       |
|---------------------|-----------------------------------------------------------------------------------|
| BudgetManagementPage| `<main>`, `<h1>` "Budget Management"                                              |
| BudgetGrid          | `<table>` with `<caption>` "Budget Data"; `<th scope="col">` for periods; `<th scope="row">` for accounts |
| BudgetAmountCell    | `<input type="text" inputmode="decimal">` with `aria-label="Budget amount, {account}, {period}"` |
| BudgetGrid          | Full keyboard navigation (Tab/arrow keys between cells)                           |
| BudgetImportButton  | File input with visible label; `aria-label="Import budget file"` on trigger       |
| ImportResultPanel   | `role="status"` for success count; error list uses `role="list"` with per-row `role="listitem"` |
| Modified indicator  | Not colour alone; tooltip or text indicator "Unsaved"                             |
