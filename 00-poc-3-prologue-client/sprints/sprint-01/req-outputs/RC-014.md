## User Story
As a group finance manager,
I want to import and consolidate GL data from multiple entity databases into a single consolidated reporting view,
So that I can produce group-level financial reports that combine data from all entities without manually re-entering data.

## Functional Requirements
1. The system must provide a GL Data Consolidation module accessible from the General Ledger navigation.
2. Users must be able to define connections to one or more source databases or data files for consolidation.
3. Users must be able to run a consolidation process that imports and merges GL data from the defined sources.
4. The consolidated data must be stored in a separate consolidation database or reporting layer, distinct from the operational GL data.
5. The system must support inter-company elimination entries to remove intra-group transactions from the consolidated view.
6. The consolidated data must be available as the data source for Financial Report Designer (RC-012) reports.

## Acceptance Criteria
1. Given a user configures two source databases, when they run the consolidation, then GL data from both sources is combined into the consolidation view.
2. Given a consolidation run completes, when a user opens the Financial Report Designer, then the consolidated database is selectable as a data source.
3. Given inter-company elimination rules are defined, when the consolidation is run, then the intra-group transactions are eliminated and do not appear in the consolidated output.
4. Given a consolidation run encounters a data error in one source, when the run completes, then the error is reported to the user and the consolidation result for that source is marked as partial/failed.

## Non-Functional Requirements
| Category      | Requirement                                                              |
|---------------|--------------------------------------------------------------------------|
| Performance   | Consolidation of up to 5 entities must complete within 30 seconds.      |
| Security      | Consolidation requires group finance manager role.                       |
| Accessibility | WCAG 2.1 Level AA compliance required; consolidation controls must be keyboard-accessible. |
| Usability     | Consolidation run must display clear progress and status indicators; errors must be reported per source entity. |
| Other         | Supported source connection types are pending confirmation; see Open Question OQ-037. |

## UI Components Affected
- GL Data Consolidation screen
- Source database/file configuration panel
- Consolidation run action and progress indicator
- Consolidation run history/log
- Error report view

## BFF Endpoints Needed
- GET /consolidation/sources -- list configured consolidation sources
- POST /consolidation/sources -- add a consolidation source
- POST /consolidation/run -- execute the consolidation process
- GET /consolidation/runs -- list consolidation run history
- GET /consolidation/runs/{id}/report -- consolidation run report/errors
