## User Story
As a GL auditor,
I want to see who last edited a journal entry and the exact timestamp of that edit displayed in the entry header,
So that I have a reliable, tamper-evident audit trail of all changes to GL journal entries.

## Functional Requirements
1. The journal entry header must display two read-only audit fields: Edit Date/Time (timestamp of the most recent save) and Edit User ID (the user ID of the person who performed the most recent save).
2. The system must update Edit Date/Time and Edit User ID automatically on every save -- the user must not be able to set these fields manually.
3. Edit Date/Time must be stored and displayed with date and time precision (not date only).
4. Both fields must be visible in the form at all times (not hidden behind a detail or audit panel).
5. The system must also record the original creation date/time and creation user, distinct from the edit audit fields.

## Acceptance Criteria
1. Given a user saves a journal entry, when the save completes, then Edit Date/Time shows the current date and time and Edit User ID shows the current user's login ID.
2. Given a different user edits and saves the same entry, when they save, then Edit User ID updates to that user's ID and Edit Date/Time updates to the new timestamp.
3. Given a user attempts to manually type in the Edit Date/Time or Edit User ID fields, when they click the fields, then the fields are non-editable (read-only).
4. Given a user views a journal entry, when the form loads, then Edit Date/Time and Edit User ID are always visible without requiring any additional action.

## Non-Functional Requirements
| Category      | Requirement                                                              |
|---------------|--------------------------------------------------------------------------|
| Performance   | Audit fields must be updated synchronously as part of the save operation.|
| Security      | Audit field values must be set server-side only; client cannot override. |
| Accessibility | Audit fields must have visible labels readable by screen readers.        |
| Usability     | Edit Date/Time must be displayed in the user's local timezone.           |
| Other         | Audit log must be stored persistently and not modified by any user action.|

## UI Components Affected
- Edit Date/Time field (read-only, header)
- Edit User ID field (read-only, header)
