## User Story
As a finance administrator,
I want to open and close fiscal years and individual accounting periods,
So that I can control which periods accept new journal entry postings and prevent accidental entries into closed periods.

## Functional Requirements
1. The system must provide a Fiscal Year / Period Control screen accessible from the General Ledger navigation.
2. Users must be able to define fiscal years with a start date, end date, and the number of accounting periods.
3. Each accounting period within a fiscal year must have a status of Open or Closed.
4. Users must be able to open or close individual accounting periods.
5. The system must prevent posting of journal entries to a closed accounting period.
6. The system must prevent posting of journal entries with a Transaction Date outside any defined fiscal year.
7. Users must be able to perform a year-end close process that closes all periods of a fiscal year and carries forward balances.

## Acceptance Criteria
1. Given an accounting period is Closed, when a user attempts to post a journal entry with a Transaction Date in that period, then the system blocks the action and displays "Cannot post: accounting period {period} is closed."
2. Given a finance administrator opens a previously closed period, when the status is changed to Open, then journal entries with dates in that period can be posted.
3. Given a user creates a journal entry with a Transaction Date outside all defined fiscal years, when they attempt to post, then the system rejects the action and displays an appropriate message.
4. Given a user initiates year-end close for a fiscal year, when all periods in the year are confirmed as closed, then balance sheet account balances are carried forward to the opening balance of the next fiscal year.

## Non-Functional Requirements
| Category      | Requirement                                                              |
|---------------|--------------------------------------------------------------------------|
| Performance   | Period status check during post must add no more than 100ms to the post operation.|
| Security      | Opening/closing periods requires finance administrator role.             |
| Accessibility | WCAG 2.1 Level AA compliance required; all period open/close controls must be keyboard-accessible. |
| Usability     | Period calendar view should give an at-a-glance view of all period statuses.|
| Other         | Year-end close must be reversible within a configurable window before it becomes permanent. |

## UI Components Affected
- Fiscal Year / Period Control screen
- Fiscal year definition form
- Period list (with Open/Closed status per period)
- Open/Close period actions
- Year-end close wizard

## BFF Endpoints Needed
- GET /fiscal-years -- list fiscal years
- POST /fiscal-years -- create a fiscal year
- GET /fiscal-years/{id}/periods -- list periods for a fiscal year
- PUT /fiscal-years/{id}/periods/{periodId}/open -- open a period
- PUT /fiscal-years/{id}/periods/{periodId}/close -- close a period
- POST /fiscal-years/{id}/year-end-close -- initiate year-end close
