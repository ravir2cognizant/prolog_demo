## User Story
As a financial manager,
I want to review journal entries for financial accuracy and completeness before period close,
So that I can identify and correct any errors in the GL before financial statements are produced.

## Functional Requirements
1. The system must provide a Journal Entry Financial Review screen accessible from the General Ledger navigation.
2. The review screen must allow filtering of journal entries by criteria including: date range, company, entry type, status, and posted/unposted.
3. The review screen must display journal entries in a list/grid with summary information (entry ID, date, description, total debit/credit, status).
4. The user must be able to open any entry from the review list to view its full detail.
5. The review screen must indicate entries that are flagged or have open questions.

## Acceptance Criteria
1. Given a user navigates to Journal Entry Financial Review, when the screen loads, then a filterable list of journal entries is displayed.
2. Given a user sets a date range filter, when they apply the filter, then only entries with Transaction Dates within that range are shown.
3. Given a user clicks on a journal entry row, when the row is selected, then the full journal entry detail view opens.
4. Given a journal entry has an unresolved open question, when it appears in the review list, then a visual indicator distinguishes it from entries without open questions.

## Non-Functional Requirements
| Category      | Requirement                                                              |
|---------------|--------------------------------------------------------------------------|
| Performance   | Review list must load within 3 seconds for up to 1,000 entries.         |
| Security      | Users see only entries for companies they have access to.                |
