## User Story
As a financial reporting manager,
I want to design and run custom financial reports (income statements, balance sheets, analysis reports) based on GL data and allocation outputs,
So that I can produce the financial reports required by management and regulatory bodies without relying on developers or pre-configured exports.

## Functional Requirements
1. The system must provide a Financial Report Designer accessible from the General Ledger navigation.
2. Users must be able to design report layouts by selecting GL accounts or account groups as rows and accounting periods as columns.
3. Users must be able to save named report designs for reuse.
4. Users must be able to run a saved report design to produce the report with current GL data.
5. Report output must reflect allocated amounts as produced by the Account Balance Allocation module (RC-011).
6. Reports must be exportable in at least one standard format (e.g. PDF or Excel).

## Acceptance Criteria
1. Given a user opens the Financial Report Designer, when the screen loads, then they can create a new report design or open an existing saved design.
2. Given a user selects accounts and periods for a report, when they run the report, then the output displays the correct GL balances for those accounts and periods.
3. Given a user saves a report design with a name, when they return to the designer later, then the named report appears in the saved reports list.
4. Given a user runs a report and clicks Export, when the export completes, then a downloadable file in the selected format is provided.

## Non-Functional Requirements
| Category      | Requirement                                                              |
|---------------|--------------------------------------------------------------------------|
| Performance   | Report generation for up to 100 accounts across 12 periods must complete within 15 seconds.|
| Security      | Report designer access requires financial reporting manager role.        |
| Accessibility | WCAG 2.1 Level AA compliance required; report builder controls must be keyboard-accessible. |
| Usability     | Report builder must provide an intuitive drag-and-drop or selection-based layout experience; see Open Question OQ-032 for specific report type requirements. |
| Other         | Report output must be deterministic -- running the same design twice against the same data must produce identical results. |

## UI Components Affected
- Financial Report Designer screen
- Report layout builder (account/period selector)
- Saved reports list
- Report output view
- Export action

## BFF Endpoints Needed
- GET /report-designs -- list saved report designs
- POST /report-designs -- save a new report design
- PUT /report-designs/{id} -- update a report design
- POST /report-designs/{id}/run -- execute a report and return data
- GET /report-designs/{id}/export?format={pdf|xlsx} -- export report

## Intra-sprint Dependencies
