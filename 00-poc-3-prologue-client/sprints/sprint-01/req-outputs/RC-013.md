## User Story
As a finance manager,
I want to view and edit budget amounts by account and period, and import or export budget data in bulk,
So that I can maintain the GL budget data and keep it synchronised with external budget planning tools.

## Functional Requirements
1. The system must provide a Budget Management screen accessible from the General Ledger navigation.
2. Users must be able to view budget amounts by GL account and accounting period in a grid layout.
3. Users must be able to edit individual budget amounts inline in the grid.
4. Users must be able to import budget data from an external file (accepted formats pending confirmation; see Open Question OQ-035).
5. Users must be able to export the current budget data to an external file.
6. The system must maintain budget data separately from actual GL balances but allow comparison of budget vs actuals.

## Acceptance Criteria
1. Given a user opens Budget Management, when the screen loads, then budget amounts are displayed in a grid of accounts (rows) by periods (columns).
2. Given a user edits a budget amount in a cell, when they save, then the updated amount is stored and reflected immediately in the grid.
3. Given a user imports a budget file, when the import completes, then the imported values replace or merge with the existing budget data (behaviour -- replace or merge -- is pending confirmation; see Open Question OQ-036).
4. Given a user clicks Export, when the export completes, then a downloadable file containing all budget data is provided.

## Non-Functional Requirements
| Category      | Requirement                                                              |
|---------------|--------------------------------------------------------------------------|
| Performance   | Budget grid for 200 accounts across 12 periods must load within 5 seconds.|
| Security      | Budget management requires finance manager role.                         |
| Accessibility | WCAG 2.1 Level AA compliance required; all grid cells and import/export controls must be keyboard-accessible. |
| Usability     | Budget grid must support bulk editing (paste from spreadsheet).          |
| Other         | Budget import must validate data types and reject rows with non-numeric amount values with a specific per-row error message. |

## UI Components Affected
- Budget Management screen
- Budget grid (accounts x periods)
- Import budget action (file upload)
- Export budget action

## BFF Endpoints Needed
- GET /budgets?companyId={id}&fiscalYear={year} -- retrieve budget data
- PUT /budgets -- update one or more budget amounts
- POST /budgets/import -- import budget data from file
- GET /budgets/export?companyId={id}&fiscalYear={year} -- export budget data
